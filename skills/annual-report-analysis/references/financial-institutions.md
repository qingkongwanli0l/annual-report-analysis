# 金融机构：从报表到信用判断的操作程序

用于银行、寿险/财险/再保险、证券/资管、交易所/中央对手方（CCP），以及非银放贷、融资/经营租赁、AMC、融资担保和信托等金融服务。金融集团按法律实体和业务分别执行，再处理集团内交易、资本与现金转移；不把工商企业的营运资本、净债务/EBITDA模板直接套在存款、保单负债、客户款或保证金上。金融控股、集团支持及复杂融资责任另接[特殊信用结构](special-credit-structures.md)。此文件给出分析程序，不提供外部评级、监管认证或经校准的违约概率模型。

本参考包含独立安装后可用的程序、官方出处和数值例。开发仓库的`examples/financial-institutions/analysis.md`保存可选扩展案例，不是安装后的执行依赖。方法记录更新至2026-10-05；生产时更新适用文件。2026年发布/修订的方法不自动适用于2025年评级行动或财报。

## 先建立可运算的事实范围

每个余额和比率保存：实体、合并/母公司/监管并表、报告日期、流量期间、准则、币种、单位、是否重述、原始URL、公布/批准/取得日期、PDF物理页及印刷页、表名和行列。监管资本与会计权益、母公司净资本与合并债务分别建表。未取得公布日时明确缺口，不能用于“当时可知”的回测。

先取年报及附注，再取同日第三支柱/监管资本/偿付能力/PFMI披露、真实评级意见与募集说明书。内部贷款台账、精算模型、客户存管对账和压力测试仅在获授权后使用。不能访问时先完成公开资料可支持的部分，再列到具体字段的资料请求。评级报告所载数据保留“评级机构整理”来源属性，不冒充直接核验过的审计原表。

工作底稿采用“事实→计算→判断→反证→追加程序”。一项判断要回答：发生了什么；通过何种收入、损失、资本或现金机制影响信用；什么证据会使判断改变。来源缺失记为空值及原因，不填0；不以所有程序均完成作为出报告的前提，而是把未完成事项及对结论的影响一起交付。

下面的复核动作用于独立重做关键分析；算术复算不能单独证明模型或结论适用。

## 银行：B1 → B5 → B3/B2 → B4 → B6/B7 → B8

### B1 经营环境、商业模式与暴露

1. 从分部、贷款行业/地区、证券投资、存款客户和同业业务取规模、收入、风险暴露；对分部合计与报表差额记录内部抵销。
2. 建“环境变量—暴露—传导”表：例如当地房地产销售下降→开发贷现金回款/抵押品→违约迁徙与LGD→ECL及资本。行业和地域重叠项不能相加为总风险。
3. 计算同范围业务增速、份额、集中度；把量增与定价、客户风险变化并列。集中度的分母写明贷款、信用风险暴露或收入，不能互换。

**反证与补证：** 收入增长同时信用成本上升、单一政策客户依赖或低价吸存，均挑战“竞争力增强”。向业务/风险负责人索取前十大关联集团、行业迁徙和客户分层定价，公开资料缺失时只判断可见集中度。**产品/复核：** 暴露传导表；复核人选最大暴露重追来源，并检验同一冲击是否在利润、准备和资本中重复计损。

### B5 量价、拨备前利润与成长质量

1. 从平均余额/收益率表复算`利息净收入=利息收入−利息支出`、`净息差=利息净收入/同口径平均生息资产`。年内口径按实际天数年化；优先用已披露日均/月均余额，不静默用期初期末均值代替。
2. 对每类资产或负债，使用未舍入隐含收益率`r=利息/平均余额`。按固定顺序分解`Δ利息=(V1−V0)×r0+V1×(r1−r0)`；负债支出在净利息收入桥取负号。该顺序分配交互项，必须披露，不能声称唯一归因。
3. 从收入逐项扣业务费用、税金、其他经营成本，得到自定义且明确命名的“减值前营业利润”；再扣信用/其他减值，加营业外，扣所得税，核对净利润及少数股东损益。
4. 将手续费、投资损益、资产出售、税项和拨备转回单列。只有能够证明金额及税影响时才给可比调整；同时保留报告利润，不把“经调整”当事实替代。

**反证与补证：** 收入增长可能来自卖债或更高风险承受，利润减少可能来自主动补拨。索取产品定价、新客账龄、贷款批次损失和费用归属；缺失则不能断言新增业务已经成熟盈利。**产品/复核：** 量价桥、拨备前至归母利润桥；复核人用未调整利润表闭合，再挑战最大调整。

### B3 准备滚动与ECL

1. 先从实际政策区分CAS/IFRS 9、US GAAP ASC 326及资产类别；不适用的阶段分类不能列成公司资料缺失。按贷款/债券/同业/表外承诺分别勾稽：`期末准备=期初准备+当期净计提−核销及转出+直接进入准备的回收±其他`。符号及回收记账位置以原表为准；有的回收进损益，不能再加一次。总准备与摊余成本贷款抵减项存在FVOCI、应计利息或范围差别时另做桥。
2. 对采用三阶段模型的CAS/IFRS 9资产，按Stage 1/2/3分别计算`准备/对应账面毛额`及阶段占比；以当期同类资产净计提/平均同类资产毛额计算信用成本。期末准备增减不是信用成本。不良覆盖率使用匹配的贷款准备和不良贷款余额。
3. 取得模型后，固定资产池和情景，区分规模、适用的阶段迁徙、参数、情景权重、管理层叠加、核销回收及汇率影响。采用PD/LGD折现法且符合适用规则时，逐笔ECL可按`Σ情景权重×Σ时间段[边际违约概率×EAD×LGD×贴现因子]`重算；若输入是条件PD，先乘存活概率，不能把各年累计PD直接相加。该式不要求其他合适损失率方法强制改成PD模型。
4. 三阶段法中，Stage 1限制的是未来12个月内可能发生的违约事件，事件引起的现金短缺仍涉及整个存续期；Stage 2使用存续期，Stage 3按适用政策核对现金流短缺与贴现。POCI等特殊资产另按准则处理。验证原始/适用实际利率、担保回收时点、抵押处置费用与实现概率；同一风险不得同时计入模型和overlay。
5. **CECL分支：** 对按摊余成本计量的贷款、HTM债券、租赁净投资及适用表外敞口，取合同剩余期、提前还款/适用续期条件、相似风险分池、合理可支持预测期及其后历史损失回归的方法和期间。先用公开政策及两期披露核对模型、历史池、支付分配和定性调整的变更，再将参数影响与组合/核销变化分开；没有逐笔数据时不倒推完整损失模型。AFS债券按ASC 326-30另核信用/非信用损失，准备不超过摊余成本高于公允价值的差额；有出售意图或很可能在成本收回前被迫出售时，另核直接减记至公允价值的路径，不套贷款CECL或三阶段法。购买资产另核实际采用的规则与过渡安排。依据为[美国四监管机构ACL政策声明](https://www.federalreserve.gov/frrs/guidance/interagency-policy-statement-on-allowances-for-credit-losses.htm)的Scope、Contractual Term、Reversion及AFS章节，不将其当作全部现行ASC全文。
6. 只有汇总公开表时，执行滚动、覆盖、方向一致性及情景挑战，结论标为“公开数据合理性分析”，不能写“模型验证完成”或“准备充足”。

**真实公开分支例：** [Synchrony 2025年报](https://investors.synchrony.com/filings-regulatory/sec-filings/all-sec-filings/content/0001601712-26-000006/syf-20251231.htm)的Allowance for Credit Losses及附注2/5披露2025年改用逐账户PD/EAD模型并改变历史回归方法，预测期12个月、回归期6个月。先记录方法变化及公司所称实施期影响不重大，再核两期准备/信用成本与组成；这不能用Stage 2占比验证，也不能据变化本身认定准备不足。逐账户损失、支付分配及变更影响测算才是继续补证的对象。

**反证与补证：** 经济恶化而适用的Stage 2下降、叠加大额转回、抵押估值过旧均需追加。三阶段业务向风险模型/财务索取SICR规则、迁徙矩阵及参数；CECL业务索取合同期/支付分配、预付、预测与回归依据及模型变更测算。两者均按实际模型补期限结构、情景、回收及overlay记录，不索取不适用的字段。**产品/复核：** 准备桥和参数归因表；复核人从毛额和模型输入独立选取重大样本重算，不能只复核公式相加。

### B2 资产质量、分类与处置

1. 各建五级分类、阶段分类、逾期天数表，分别核对总额。正常贷款可能包含正常类及关注类；不能按表面名称重复相加。
2. 复算`不良率=(次级+可疑+损失)/贷款毛额`。列关注、90天以上逾期、重组/展期/无还本续贷，各自有范围与重叠标记。
3. 有迁徙台账时做`期末不良=期初+新形成+购入/范围变化−现金收回−核销−转让−上调±其他`；只有净余额时不反推“新生成不良”。对转让核查价格、追索、继续涉入，核销不代表借款人风险消失。
4. 只有逐笔ID或可核对的交叉披露时，才把Stage 2/3与关注/不良/逾期交叉。按同一借款集团聚合表内外信用资产，检查不良是否藏在债权投资、资管计划或应收款。

**反证与补证：** 分母快增或核销可降低不良率；还款来自新增借款不证明偿债改善。索取逾期合同、重组前后偿付计划、转让回款及期后履约，追最大异常资产池。**产品/复核：** 分类差异表、不良形成处置桥；复核人重算比率，选一笔跨分类和一笔核销/转让回穿合同及现金。

### B4 会计权益、监管资本与RWA

1. 从权益至监管资本逐项列普通股/留存、OCI、少数股东、商誉/递延税等扣减、其他一级及二级工具；记录监管并表与会计并表差别。账面“其他权益工具”不自动是CET1。
2. 分信用、市场、操作风险核对RWA，复算CET1、一级、总资本比率及监管杠杆率。对两期资本率`c=K/R`，精确分解`Δc=(K1−K0)/R0+K1×(1/R1−1/R0)`；前者资本金额贡献，后者分母贡献，尚不等于业务量/模型变化的进一步归因。
3. 向第三支柱取RWA变化来源、风险权重/内部模型、过渡安排。用同实体、同日期、已核实的总要求`h`计算金额余量`K−h×RWA`，分别处理各层资本约束；不抄固定监管红线，也不将一个资本层级余量代表所有约束。
4. 压力中先把减值、市场/OCI、税与监管扣除传至资本，再按风险迁徙、规模和适用权重重算RWA。分红、资本发行、到期减额逐项进入；未批准或未到账的资本措施另列条件情景。最后算各资本率、金额余量与约束最紧项。

**反证与补证：** 比率上升可由低RWA资产替换、模型变化或其他一级工具驱动，未必由核心留存增强。索取RWA桥、ICAAP、发行到账及分红计划；没有参数只给静态敏感性，不能称完整监管压力测试。**产品/复核：** 权益—资本—RWA—压力桥；复核人移除未落实措施重算，检查资本损失与ECL是否重复。

### B6 资金来源、流动性与可融资性

1. 复算LCR的HQLA/净流出、NSFR的可用/所需稳定资金；两者口径直接来自适用披露。先区分期末比率、日比率的简单平均、平均分子除平均分母，后三者通常不相等；平均LCR需要匹配日序列才能闭合，不能把差异判为错报或倒填“其他”。监管加权金额、会计余额及无条件可用现金分列。
2. 按法律实体、币种和日内/日/周/月建立来源用途表。存款按保险覆盖、客户集中、期限、渠道与价格敏感度分组；债券、同业存单、回购及同业拆借逐笔记录到期和续作条件。
3. 每一期间计算`期末可用现金=期初+可靠流入+该期可执行融资−到期付款−流失−保证金/承诺提用`。资产出售/质押融资扣处置折价、已有质押和执行时滞；同一资产只选一种资金来源。生存期是首次可用余额为负的时点，并同时报告最小余额。
4. 压力设定需有历史流失、客户结构、合同或监管依据，显示基础/压力的变化原因；信用额度按承诺性、先决条件及提供方相关风险筛选，跨币种换汇也需可执行。

**反证与补证：** 高期末LCR不能否定日内、单币种或大客户提款缺口。索取日度峰值、前十大存款、抵押资产台账和备用额度合同。**产品/复核：** 时间阶梯与应急动作表；复核人检查最大流入是否可在付款前到账，并删除重复担保品。

### B7 IRRBB、债券浮亏与ALM

1. 从第三支柱分别取ΔEVE、ΔNII，写明币种、曲线、冲击、期限、是否静态资产负债及行为假设；2026国际参数须先确认本地实施和报告期适用性。
2. 取得重定价现金流后按情景重新折现资产/负债及表外现金流，算`ΔEVE=EVE压力−EVE基准`；按约定预测窗口逐期重算利息收付，算ΔNII。无现金流时使用原披露敏感性，不用总资产×利率变化伪造结果。
3. 分AC/FVOCI/FVTPL及套保，将价值变化映射至损益、OCI、资本和抵押/被迫售损。存款beta、提前还款与无到期存款行为期限各做可解释改变；不要把ΔEVE与当期会计亏损相加。

**反证与补证：** AC未实现亏损不入当期损益仍可影响变现；历史存款稳定不保证未来beta。索取重定价梯级、提前还款/存款回测及套保有效性。**产品/复核：** EVE/NII与现金联动表；复核人验证冲击符号、对冲边界和行为假设，VaR不能替代该程序。

### B8 自身实力、支持与债项层级

1. 先汇总B1–B7形成自身偿债能力判断，再分别取支持方的能力、意愿、历史行为、合同及制度。持股比例、系统重要性或名称均不是自动支持承诺。
2. 逐项读取存款、优先债、处置债、T2/AT1条款，登记发行主体、清偿顺位、担保覆盖、减记/转股触发、利息取消/递延、赎回批准和法定到期。
3. 如需对标某机构，锁定该机构在该行动日适用的完整方法，从其自身评估到支持、主体、债项依次解释；不可拼接S&P的资本指标、Moody’s的支持框架和Fitch的级差生成自有评级。

**反证与补证：** 救机构可能不保护资本工具；首个赎回日不是到期。索取正式支持/保证及最终发行条款，缺失就保留支持或债项判断条件。**产品/复核：** 实体—债项责任表；复核人逐条定位合同，不能沿用别行固定级差。

#### S&P银行资本：预计RAC到资本与盈利因素

使用上表2026-05-05重发的94页金融机构方法；本小节的PDF页码及段号均指该文件，下文RAC计算程序的段号另指RAC HTML。B4的监管资本桥继续保留；S&P的TAC和风险加权资产依分析日及法域生效的RAC方法另建。现行[Risk-Adjusted Capital Framework Methodology](https://spratings.spglobal.com/ratings/en/regulatory/article/-/view/type/HTML/id/3610675)为2026-05-05初发、含2026-07-13附录8出版校正的正文及八附录；计算接下文程序，2024版不能混用，需当地注册的法域另核生效。混合资本资格/限额、保险RBC、IRB/长期PD及具体机构输入仍有独立来源要求；正式正文可读不等于这些依赖和模型均已执行。公开模型仍须外部输入TAC，不能以监管资本或会计权益直接填入；050526公开版内置主权/BICRA/经济风险参数截至2025-12-31，须核分析时点变化，其输入和计算范围也不等同分析师版本。

1. **先判许可资本约束（p18、20–21，¶79–88/表8）。** 核维持牌照的各项最低资本指标，分别列审慎缓冲要求；较高缓冲线是否构成许可约束，仍核违反后是否会导致撤牌，不能一律排除。预计仍合规但余量狭窄且可能在合理不利变化下违规时，按原表判断at risk：SACP最高bb+，资本与盈利至多constrained。属表8的监管宽容或违规时，SACP最高b-、资本与盈利weak，CCC情形另核；预计短暂违规且有监管同意的可信近期补资计划时，可按at risk判断。100bp是通常判断线索，存在保守计算和压力稳定等例外，不作机械触发。已适用上限时不再执行后两步，除为辨别constrained或weak。
2. **形成预计多元化前RAC（p21–22，¶93–95/表9）。** 银行从最新完整财务/监管口径接入新信息，预测通常未来1–2年的盈利、留存、资产负债规模/组合和资本管理，重建预计TAC及S&P RWA。保留现期与预计、预测假设及其证据，不能用当前监管资本率或多元化后RAC代替。已核输入的预计RAC按`>15%`、`(10%,15%]`、`(7%,10%]`、`(5%,7%]`、`(3%,5%]`、`≤3%`依次形成very strong、strong、adequate、moderate、constrained、weak初始档；用未舍入值判断边界。不能把缺失风险暴露填0，也不假定四表足以复现RAC。
3. **决定最终资本与盈利档（p24–26，¶104–118）。** 依资本质量、管理与灵活性及盈利能力/质量，说明初始档是否实质高估/低估吸损力，才考虑上下一类别调整。结合混合资本、监管缓冲、集团资本转移、持续留存和较长期资本政策。B7的AFS转HTM累积OCI及HTM浮亏实现风险接回¶106的具体条件，不一律加回或扣除。可用的earnings buffer为剔除一次性项后的拨备前营业利润减RAC正常化信用损失，再除S&P RWA；银行通常平均最近财年、当年预计、次年预计的年度指标。正常化损失按现行RAC表23–25及实际类别/国家敞口形成，不同于当年计提或准备余额变动；原表参数可取不证明公司组合及盈利缓冲已复算，缺适用版、分类或输入时不冒算。
4. **连接风险地位和SACP（p12表3、p28–32 ¶130–145）。** 多元化/集中、实际损失相对RAC假设、风险偏好及复杂度继续进入风险地位，区分收入多元化与暴露分散；不设未经原法支持的固定集中度扣档或重复计损。最终资本因素按银行锚点所在列查表3，再与其他因素及上限共同形成SACP，之后接[金融机构结论形成分支](corporate-credit.md#113-金融机构的结论形成分支)的支持、主体和债项路径。资料缺失时写清受影响的是TAC、哪类暴露/权重、正常化损失或预测，并给证据可支持的资本档分支；不能直接产出唯一机构等级。

**构造例。** 假设TAC和S&P多元化前RWA已按有效RAC规则核实，当前120/1000=12%，预计125/1300=9.6154%，资本金额虽增长，预计比率仍下降。银行锚点bbb、监管不在险、资本质量/盈利不另调、其他因素及可比调整均中性时，误用当前比率会得到strong及表3的+1资本作用，推出bbb+；按预计比率应为adequate及0作用，得到bbb。两者是同一假设例的输入比较，最终主体仍须另接支持。预计100/1000恰为10%也属adequate。此例只验证形成逻辑，不声称已复现某行RAC。

#### S&P非银行资本：先选度量，再定档

采用同版金融机构方法时，证券、finco及BDC接下列分支；银行短节不替代这些条件。保存选法依据、排除的替代方法、原始输入及调整桥、初始档、资本/盈利调整和SACP作用。

1. **先核许可与BDC覆盖（p18–21，¶79–92）。** 有许可资本要求的非银按适用监管定义判断；无该要求者记录不适用，不自设监管线。BDC另核实际采用的资产覆盖要求：通常200%–220%或已采用150%要求后的150%–165%范围属于在险线索，SACP通常最高bb+；违反适用覆盖要求通常最高b+，不套银行的b−或监管宽容分支。若需大量出售组合资产才恢复合规且成交前景不确定，另核¶92的b−/更低上限及weak资本。保留预计覆盖、资产变现和法律要求的依据，不由一个期末比率替代判断。
2. **证券度量（p21–22，¶93–96/表9–10）。** 通常从最近RAC接显著前瞻变化及重大盈利缓冲不足。只有信用/市场风险很有限、可以在无合并有形权益情况下持续经营、且表9初始档为moderate或更低这三项均满足时，才核表10债务/EBITDA分支；表9已adequate或更好时不用表10。表10倍数`<3`、`[3,4)`、`[4,6)`、`≥6`对应adequate、moderate、constrained、weak；分母非正不按正常倍数落档。
3. **finco与BDC度量（p22–23、74，¶97–103、354–355/表11）。** 与当地银行资产风险相近者通常用RAC，显著更高风险者通常用债务/ATE；审慎监管、核销与正常化损失关系、重大表外暴露及次级证券化持仓等仍须按原文检查，不能仅因名称或较好分数选法。同一细分业务的可比对象保持选法一致，BDC用杠杆。ATE从适用TAC、一般准备及各项加减项建立桥；BDC剔除公允价值调整导致的未实现升贬值，finco及结构载体权益扣除与低杠杆finco例外按¶355核实。表11按未舍入倍数查档，TAC或调整明细缺失时不以会计权益替代。
4. **初始档到资本作用（p24–28，¶104–129）。** 再核资本质量、管理、可转移性及盈利吸损力是否支持上下一类别调整；finco上调条件需同时满足，不能只看到比率接近边界。证券盈利缓冲通常取三个历史年度，finco通常不算，不能搬用银行的历史加预测窗口。证券非风险杠杆按实际衍生品毛额/交易对手净额列报选择¶123的ACE分母；毛额分支扣90%衍生应收是方法近似，不证明法律抵销。最后依表3的银行锚点列及适用上限形成SACP作用，继续风险、资金流动性、支持和债项；转引方法、时点参数或公司输入未齐的RAC分支仍未完成。

#### S&P RAC：从报表资本和暴露到风险加权结果

使用[Risk-Adjusted Capital Framework Methodology](https://spratings.spglobal.com/ratings/en/regulatory/article/-/view/type/HTML/id/3610675)（2026-05-05，现行文本含2026-07-13附录8的EU CVA例子校正）时，逐项执行正文及八个附录，再接上述银行/非银行形成程序。历史时点保留当时适用版本和当地注册生效事实，不能将当前修订文本冒作未经修改的5月快照。RAC以`TAC/S&P RWA`计，8%的校准压力不等于发行人评级为A，RAC也不覆盖全部风险。

1. **先建同日同范围输入地图（¶56、142–152）。** Basel机构从Pillar 3取各类/地域EAD，美国机构另核控股监管报告，非Basel和非银从财报表内外暴露接入；会计账面额、违约时暴露与监管RWA分别保存。按原文扣具体损失准备，信用卡已提款加未提款承诺的10%等专门转换与普通承诺CCF分开，不把已含CCF的EAD再转换；银行账簿权益也有Pillar 3 EAD例外。保险子公司资产、AUM及已经从RAC资本扣除的对应项目按具体分支去重，不能将监管资本扣除的证券化一并排除，其1250%分支仍须执行。对地域总额/风险分类/报表总额做覆盖和残差表，方法允许的代理取值须标原规则及依赖，资料缺失不能任意填零。
2. **普通股权益→中间ACE→ACE（¶16–55/表2–3）。** 将少数资本分为可支持合并经营金融子公司的普通股、优先/混合及保险/不承担集团损失的资本，不按报表少数权益全加。核待分配股利、现金流套期储备、商誉及非服务型无形的相关税、利息剥离条带、退休福利已入账/未确认/可实现部分、自身信用重估、重大未并表金融及保险投资、其他虚增资本事项和两类DTA。服务型MSR不沿用普通无形扣除，而另按375%加权。2026版不再去除AFS税后浮动储备，汇兑和其他市值变动各按原规则，不能把所有OCI统一加回。先完成其他资本调整及未来盈利依赖净DTA扣除，得到中间ACE `I`；令不可及时转换的时间性净DTA为`N`、可及时转换者为`L`，通常`D=max(N−0.10I,0)`、`ACE=I−D`，留存DTA的`RWA=3.75(N−D)+2.50L`。`L`不进入10%池，DTL不重复分配给商誉/退休福利和DTA；净DTL不产生额外资本。及时转换须有立即、无延迟兑付政府现金或流动债的法律条件，并核政府意愿与能力，未来抵税或清算兑付不能冒作及时转换。更高监管扣除且反映实际风险等例外单列，不用最终ACE重算门槛；非正`I`等原文未完整裁决的情形保留未决，不由上述通常式造负的留存DTA。类别取实际税务性质，不据会计亏损单独推定税损结转。
3. **ACE→TAC及保险投资两端（¶8、41–48、附录6）。** 优先及混合工具至少须有intermediate equity content，再按独立混合资本方法的资格/限额加入TAC；本RAC正文未提供全部认定参数，不能自填固定限额或把监管资本总额、全部会计优先股直接加上。保险投资扣除基数含初始投资和后续累计储备、配对已扣商誉等；不是只扣历史成本。重大保险风险另核substantial压力下的集团对应份额：缺额使RWA增加`3.75×集团缺额`，可转移盈余按条件使RWA减少`3.75×集团盈余`。若取完整子公司金额先按集团持股份额折算，已经是集团份额者不再乘一次。此重大风险分支中，母公司持有但未被保险子公司TAC认可的监管资本工具才另按非上市权益加权，不能扩大到所有保险债；认可部分与扣资本对应，非监管资本保险债另走信用风险。不同时全扣资本又全加同一工具RWA。10%量级比较不是唯一重大性判断，少数持股、战略地位和补资承诺分别取证；不得用保险监管偿付率代替保险RBC模型。
4. **信用分类→原表权重（¶59–78、94–101/表4–8）。** 政府、金融、工商、零售及证券化分别映射，保留主体/工具评级尺度、所在地及经济风险/BICRA。政府通常用主权外币评级，已知中央政府本币国内证券另用本币；央行现金及央行逆回购等现金例外按原规则，不把高评级政府债一律设零。金融暴露通常取金融表与相应主权权重中较高者，技术性主权违约另核；政府相关公司不因支持标签直接套主权权重。工商建设/开发与一般企业、零售细分类及Lombard分流；未披露时仅在原文明确允许且条件已核时使用代理。证券化依全球工具评级、可合理推导评级、最高优先/次级及未知分支；未评级但层级可得的次级通常375%，评级及层级均不足通常250%且可按证据提高，监管扣资本等分支1250%，不能把这些条件混为“全部未评级1250%”。政府支持单层pass-through另核。权重施于名义额扣已入损益减记；资本费用率`c`先转`RW=c/0.08`再乘暴露`E`，货币资本费用`K`转`RWA=12.5K`，原本已是RWA者不再乘12.5。境内AAA不等于全球AAA。
5. **缓释两端与下限（¶102–109/表9）。** 从真实抵押/保证/CDS及期限匹配建立覆盖前后暴露；财务抵押采用相应监管方法折扣或原表，非财务抵押不能任意减额。在表9 RAC haircut适用的Lombard分支，先取`U=max(E−C(1−haircut),0)`，再取`RWA=max(U×RW_unsecured,E×原表floor_RW)`；金额同币种，haircut及RW用小数率，下限基数是整笔贷款`E`。其他监管haircut/covered exposure分支按¶104，不据此加统一floor。ER5股票抵押原例按表列下限20%，与文字102%/5=20.4%的舍入差异另留，不自行选更有利值。保证代偿须符合可替换资格。合格工商CDS从原RWA减`0.50×CDS名义额`，同时增加保护方全名义额信用暴露，不先从原企业EAD减全名义额；合格权益对冲减对应权益暴露75%，匹配较差/不明分支50%，并保留等价对冲方暴露。净公允价值不能代名义额，不只保留有利一端。
6. **对手违约与CVA分开（¶79–93、附录8）。** CCP的交易/初始保证金与违约基金分开；总CCP资本费上限以交易加初始保证金对应的金融机构费用为比较基数，不把违约基金再加进上限基数。监管和非监管披露不足的代理分别使用实际IFRS毛额或US GAAP净额基础。CVA通常先核应收衍生品/资产是否超过IFRS BICRA1–4的3%、BICRA≥5的5%或US GAAP的0.5%，且预期CVA对总RWA重大。¶90预计平均持续低于门槛的零费用分支单列；¶92少量未清算OTC及¶93多数至少A的对手方且具有强CSA的零费用例外，仅用于不受监管CVA收费且超过门槛的相应机构，不能凭强CSA将受监管银行的CVA置零。适用监管CVA及银行特定豁免分支时，`K_CVA=K_reg×m_base×[1+(1+a)(1−p)/p]`，`p`为非豁免OTC份额，`a`及`m_base`取适用附录时点；缺拆分仅用原文允许的样本代理。当前修订Basel III例1.5、64%、45%得约4.5067（原文展示4.5），与正文2017例1.3、38%、45%得约3.4927（展示3.5）不互换。满足第89段重大性判断、且不适用零费用例外的未报监管CVA/回退分支，当前应收代理为US GAAP或等效净额应收×11%、IFRS或等效毛额应收×2%；所得是资本费用，转RWA另乘12.5。`p=0`及恰等重要性门槛的未决不自造兜底。图2下方判断框将¶90/¶93的零费用条件接到Yes估计分支，与对应条款冲突；保存具体框、条款、两种结果及影响，未取得适用解释前不据有利分支给零，也不反转整个图。
7. **市场风险与证券VaR（¶110–130/表10–12、附录2）。** 先核实施法域、监管方法/批准与所披露组成，在监管交易组件分支取`K_reg_trading=Σ(K_reg,k×m_k)`再乘12.5转RWA，不能共用一乘数。修订Basel III标准SBM当前乘1.6，已拆违约及残余费用各乘1；没有拆分时整项乘SBM系数，参数时点另核。其他Basel/旧VaR方法分别回原表，不混取系数。非监管批准但高质量VaR按`VaR_t×√(260/t)×目标/原置信分位数比×尾部加成`缩放；10日99%到一年99.9%的原例采用√26×1.33×1.5约10.2。可靠性另乘`1+所选追加比例`，通常33%、99%等价回测例外>5改50%、>10改100%，不把三者累计；其他置信度先换例外数。缺监管市场费用的原方法把交易资产重新按银行账簿风险分类，不能只填市场风险0而遗漏全部头寸。权益按地域市场组、上市/非上市及公允/账面取值，基金有穿透与无穿透另判，不自选最低权重。
8. **运营风险及剩余资产（¶131–140/表13–14、附录5）。** 收入取过去三年最高年度，逐业务记录`收入×表13 RW`；现金及货币市场基金AUM另按6.25%加权，未拆该类时通常用总AUM×20%作基数。AUC逐档只对该档增量乘表14权重，保留各档金额，不以最高档权重乘全额。托管已单列代理收入按原法从一般收入扣除，托管上限以资本费用比较监管操作费用×10，不能与RWA混单位。未覆盖资产继续纳入other items，超过原文5%条件时拆现金、在途支票和固定/残值等。经营租赁出租人账面`B`及披露残值`V`对应`RWA=(B−V)×RW_lessee+V×RW_other`；未披露残值时整项`B×RW_other`，融资租赁应收另按承租人信用，不把出租人式移作承租人债务调整。
9. **分散、集中与单一名称（¶141、附录1/3）。** 先得多元化前RWA，再分别核行业、地域、业务及最大20个工商暴露。令`v_i=K_iC_i`，按适用矩阵`K_adj=√(vᵀRv)`，资本费调整为`K_adj−K_before`，再乘12.5；若全程用已是RWA的同次齐次运算，不再乘12.5。保留适用基数、分类、集中因子和矩阵；表22业务矩阵对角95%与示意主图1不互换，行业/地域示例矩阵不代表全部组合齐全。业务规模图为`0.5254−0.0453ln(最高三年收入的百万美元值)`，但所述0%/15%增量与主式`C_i`乘数的衔接、收入超出样本的边界未明确，不能将0当全部风险乘数，也不自行补+1、floor或cap。整体多元化好处通常不超过30%，不是每项固定折扣。单名依完整式、top20及IRB/长期PD输入；缺top20时原文净合格金融抵押后工商暴露的1%代理保留资本费用/RWA单位解释及其推断身份，不偷换成总资产或工商RWA的1%。缺行业拆分时105%是调整后工商资本费用水平，相对原费用增量为5%，不是另加105%；该代理与其他路径分别列，不视为完全分散；转引参数未齐就保留受影响节点。
10. **正常化损失、盈利及形成（¶153–163、附录4/表23–25）。** 用实际资产类别、地域/主权尺度与年率bp形成`年度正常化损失=Σ(E_j×bps_j/10000)`，供拨备前盈利缓冲使用；此年度指标不乘三年，也不以当期ECL计提替代。校准表的三年累计损失与信用卡单年峰值是不同用途，已校准RWA不再扣一遍正常化损失，N.M.不填0。保留多元化前/后RAC和预计TAC/组合，各自进入资本与风险地位的正确节点；资金、银行账簿利率/汇率、声誉、战略及养老金波动继续依其他因素分析，不因RAC未计就删去。监管许可约束、资本/盈利最终档、风险地位、SACP、支持和债项继续按独立金融机构及相关方法形成；本RAC原文核阅不验证这些外部规则。没有完整输入或专门模型运行，不把底稿基础比率称作完整RAC引擎。

#### Fitch银行2026版：从输入口径到主体和债项

使用上表银行原件，以下PDF与印刷页码一致。B1–B7的事实与压力分析接入本路径；银行、控股公司、分行和融资实体先按p21–23辨认，依赖银行股利和估值偿债的杠杆收购载体不能仅因持有银行就套本方法。VR衡量自身生存能力，IDR衡量指定高级义务的违约风险，两者不是同一事件。日常经营支持可以进入VR，恢复生存能力所需的特别支持才进入GSR/SSR（p46–47）。不得把保险的IFS、资本/CSM、ROE或债项规则套入银行，也不以S&P资本指标或联合时间权重代替下列定义。

**先与原表对接（p7、14–15、52–54）。** 先算各期同定义指标，再形成可得四年均值用于隐含因素类别；资本和杠杆因素使用最新可得时点。资料不足时披露实际覆盖与可比性，不臆补缺年。四年观察、单期分母平均和因素权重是三件事。

1. **运营环境→六项因素→VR（p3、6–15、55–58）。** 先用人均GDP和BMI Operational Risk Index的相应排名基准得运营环境隐含类别，再核宏观、监管及地域差异得到assigned环境分。BMI等实际输入并非仅凭公开方法就已取得；可采用注明时点与来源的已公布机构环境分，或另列有证据的研究假设和敏感性，不能仅凭年报/人均GDP伪造唯一机构环境分。除定性风险概况外，业务、资产质量、盈利、资本、资金流动性的隐含类别由assigned环境分与各自核心指标查矩阵，隐含类别最多高于环境一个大类；之后依据补充指标、同业、周期及前瞻证据确定类别内细档或有理由的类别调整。保留implied类别、调整事项、assigned细档三列。将六项assigned细档按业务20%、风险10%、资产质量20%、盈利15%、资本25%、资金流动性10%加权；环境已经影响各项，不能再加一项环境权重。p8按aaa=1、aa+=2依次编码，合成数就近取整，恰为半档时取较小数/较高等级，得到implied VR；再核尚未被因素充分反映的业务/风险长期影响、环境/主权约束或最弱财务环节，才形成assigned VR。不能把最弱项固定当一档扣分，也不能仅凭加权通过就认定最终级别。
2. **支持和集团边界（p4–5、16–23）。** 通常选更可靠的政府或股东支持来源，分别验证能力和意愿；GSR先判断该国典型系统重要银行支持，再判断本行差异，政策银行另核政策角色及法律保障。可信的债权人自救处置机制可使GSR为“no support”，国有身份不自动带来支持增益。银行特定负债结构的负向判断还需支持“高级债权人受损在政治上可接受且不威胁金融稳定”的因果链；企业存款或批发融资占比高本身不够。资本债PONV减记不能替代高级债支持证据；无控股股东也不等于所有权因素负向。逐项记录相对典型D-SIB的差异，正负描述均不适用时取中性；证据不足的额外扣档列假设分支，并与中性路径并列，不能当作已核实调整。SSR通常从母行IDR出发；母行所含政府支持不能下传时改从VR，母行处置缓冲是否保护子行债权人也决定用IDR还是VR。核相对救助规模、集团角色、转移限制、历史行为及承诺。承受同一失败风险的核心银行按group VR分析，不再叠加同集团SSR；其他子行才分别分析自身VR与SSR。控股层另核双重杠杆、自身现金和上划限制，不能把集团资产都当控股公司资源。
3. **取高与处置例外（p24、26–29、36）。** 长期IDR通常取已确定VR与适用GSR/SSR对应级别的较高者，随后核国别约束、有效处置缓冲及低评级例外；支持不是在VR上固定加档。有效发达处置制度下，缓冲必须可持续、可实际吸损并匹配处置集团RWA；银行自身的高级处置债/T2/AT1与控股结构中可下拨高级债分别核，不能把CET1或全部TLAC金额直接当“处置债务缓冲”。p24及p28的通常IDR保护为`10%≤缓冲/RWA<15%`一档、`≥15%`两档，仍受法律顺位、需被减记的债层、主权及缓冲有效性约束；低于10%但高级无担保债不需或不能用于满足处置要求等情形另读原页。子行已通过SSR享受母行缓冲保护时，不能再以同一缓冲抬升一次。**构造例：** 已确定VR=bbb、SSR=bbb−，且无缓冲、国别或低评级例外，长期主体对应BBB；SSR升至bbb仅使两项共同决定BBB，不能因“有支持”改为BBB+。
4. **锚点→不履约风险→损失程度（p25–34）。** 无发达处置机制时，高级无担保债通常以IDR为锚；次级/混合工具通常以VR为锚。普通无付息灵活性的T2基准减两档反映损失程度，不能把主体支持抬升自动传给它；AT1另有票息取消/递延、减记转股等额外不履约风险。具体级差回到p32的条款与例外，不以工具名称固定扣档。只有支持确会延伸至该债层时才考虑支持锚及相关上限。发达处置机制改接p26–29的VR/适用SSR锚、债层和缓冲；存款评级针对最高风险的重大未保险存款类别，DCR衡量受评银行对第三方非政府交易对手的衍生品合同义务的违约风险（p25脚注5、p41），法律优先权需逐项核实。保证及时性不足可能只改善回收；证券化、担保债券等复杂结构另用专门方法。低等级、已不履约和清算回收走p30–33、43–48，VR的失败不等于所有高级债已违约。
5. **前瞻和改变条件（p6、49–51）。** 将B1–B7所得18–24个月预测/适用压力连接因素变化、assigned VR、支持、IDR及各债层，分别写足以改变判断的证据与边界。支持已决定主体时，自身改善可能只改变VR；支持方恶化、资本/流动性紧张或处置债层耗减则可能同时改变主体及债项。评级余量、展望和观察不由历史均值自动产生。只有公开数据时仍可完成有证据的判断及条件范围；资料不足以落档的环节明确未决，不假装获得机构未公开数据或评级委员会结论。

**资本工具的实体与金额复核（p32）。** 检查停息风险时，将实际发行人单体和集团的资本要求、缓冲、可分配项目及监管限制分列；不能用单体利润配集团资本率替代发行人测试。方法所举薄缓冲数值是追加判断线索，不是合同自动触发器。判断大额T2+T1债务缓冲能否降低损失程度时，从真实工具余额、合格范围、赎回及监管摊销重建；总监管资本减CET1既可能含非债务项，也可能已扣减债务，不能普遍当作债务余额上界。需要保守上界时列出实际工具及高估假设；没有达到方法举例的大缓冲，不等于排除了部分支持、及时介入或处置实践等其他降低损失的依据。

## 保险：业务 → 合同负债/利润 → 资本 → ALM/再保/流动性 → 责任层级与方法判断

在产品/渠道分析前，从许可、业务分部及重大交易识别持续承保、停止新业务后的存量管理、持续收购遗留负债、自保保险及分仓结构。同一集团可同时存在多种模式；对实际出现的主体调用对应程序，不能统一用保费增长或合并资本代表其履约能力。

**停止新业务与遗留负债收购。** [AM Best Run-Off方法2024-09-05](https://www3.ambest.com/ambv/ratingmethodology/OpenPDF.aspx?rc=209765)PDF3–7/印刷2–6要求区分两类。停止新业务者按保单批次连接未来赔付、费用尾部、准备恶化、再保回款、投资到期和可释放资本；寿险仍可能收到续期保费，不把全部保费现金设零，也不预设所有run-off流动性必然恶化。稳定盈利可能来自没有新业务获取费用，须与存量义务风险及未来费用分摊分开；集团抽取资本及低战略重要性可能改变支持判断。

持续收购遗留负债者另取每次组合定价、折现/费用假设、卖方动机、尽调质量和后续准备发展；把拟收购的风险、资本和现金与旧组合并排压力，检查新增收购是否削弱对旧组合的有限支持。不能把买入旧保单形成的规模扩张直接与持续承保行业保费增速比较，管理层以往收购盈利须有组合后续赔付和费用证据。输出各批次现金/资本释放表、收购假设与实际兑现表；缺少尾部明细时明确影响哪项准备、现金或支持结论。

**自保保险与分仓结构。** [AM Best Captives/ART 方法2025-08-28](https://www3.ambest.com/ambv/ratingmethodology/OpenPDF.aspx?rc=197659)须与BCRM共同使用，以下页码为PDF页码（正文印刷页少1）。先用执照、章程、保单及分仓协议确定实际承保人与责任财产；把单一母公司自保、团体自保、风险自留集团（RRG）、自保基金及分仓公司分开。单一母公司自保也可能承接第三方风险，不能仅凭股权结构认定是纯自保；产业集团客户融资公司不适用这套保险方法。分仓名称不能替代法人、许可及责任隔离判断（p2–4）。

- **对象与级别传递（p4–6）。** 未独立法人分仓结构（UCC）中，UCC本身是持牌法人，受评对象是UCC整体，不给各未独立法人仓UC独立机构评级；逐仓按BCRM分析并连同核心及其所有人评价，以最弱仓约束整体。仓数增加可能使整体再降低至少一子级，但不是按仓数固定扣分；各仓通常达aa−以上、存在再保/pooling安排或资本维持等额外支持、各仓资本和业务概况大体一致，属于原文分别允许不作该额外扣档的情形，须有对应事实。保险集团所有分仓均关联时，仍从最弱环节出发；只有按常规保险公司整体经营且各仓预计获得均等支持，才可能合并视作单一评级实体。非保险集团自设分仓承接其自身风险则另按纯自保判断，不能把两种例外混成“关联即可合并”。
- **独立分仓及共同服务（p6、9–12）。** ICC或混合MCC内独立法人且持牌的IC可单独分析、评级；不把MCC的未独立法人仓也赋独立评级。IC隔离资金、压力资本与补资机制单独取数，同时把核心管理、行政和风险管理服务依赖接入业务及ERM判断。核当地法律、破产与解散规则、隔离争议、混合仓相互交易、fronting/再保合同和抵触条款；管理分账不证明破产隔离。发行结构化融资工具的UCC或IC，AM Best明确不赋FSR；应继续定位相应工具方法，不能由其保险许可推断可赋FSR。
- **资本与母公司连接（p7–10）。** 分仓净自留、毛净PML、赔款及IBNR、信用暴露和跨仓支持义务逐项连接资本压力；单次事故净累计限额超过可用资本10%是可能削弱评价的风险线索，不是法定限额或自动扣档。LOC通常按债性看待；考虑BCAR资本认可时，原文要求通常符合所列多数或全部特征：不受其他授信协议约束的独立性、自动续期、除各方事先书面同意外不可撤销，以及高信用银行安排。银行项还核对存放于银行的支持资产及不足额风险由银行承担的安排，不能只看银行评级。符合条件者可能获得最高100%认可，并可能不受通常占总可用资本20%的门槛约束；这不是每份LOC全额认可或自动豁免上限。符合条件的纽约Regulation 114信托另核。向母公司回贷须检查监管认可、公平交易合同、母公司信用、现金波动和集中度，并合看回贷及LOC占资本的规模。非保险最终母公司对lead rating unit的影响进入lift/drag；最终母公司为保险控股公司时，其影响进入资产负债强度，不把同一影响重复调整。
- **经营目的与治理（p3、9–12）。** 自保业务常以保障与资本维持为目的，分析保单持有人/股东分红前后收益、精算所需保费、准备发展及多年大额损失，不因净利润偏低直接否定经营。业务概况通常不高于Neutral；客户绑定可改善竞争和渠道控制，但仍须核险种、客户、地区集中。单一母公司自保ERM结合母公司风险管理，团体自保/RRG结合自身能力；RRG所有权与补资来源、自保基金的连带责任及订户账户须逐项辨明。各仓共同管理不能替代对其不同风险、资产隔离和声誉传染的检查。

形成“承保/发行实体—责任财产—损失暴露—可用资本—合同支持—核心服务依赖”的对应表，把最弱仓、额外扣档、整体例外和独立IC路径分别记录理由。未取得合同或压力资本时保留该环节未决，不以合并权益或机构已公布级别反推已完成逐仓分析。

只有取得适用原文和实体材料后才形成相应机构档差；其他专门模式须继续定位实际适用方法，不能将本段的模式举例作为保险范围上限。业务识别改变时，更新评级对象、同业基准、现金和资本分析，而非只改行业名称。

### I1 新业务、续期与风险价格

1. 寿险按产品/渠道取新单、续期、趸交/期交、继续率、退保、保证和分红条款；保费现金、保险服务收入、APE、NBV、新业务CSM各立定义及计算范围。财险/再保按险种取暴露量、单价、条款、限额和分出比例。
2. 同口径拆规模变化和价格/结构变化；新业务利润率只用发行人定义的分子分母。将增长同获取成本、保证成本、新业务资本耗用及客户留存配对；不能把NBV计入会计利润。
3. 将股权控制、治理独立性、关联交易、风险偏好、内控缺陷和整改证据连到具体经营决策；以历年计划兑现检验发展规划所需的渠道、人才、资本和现金。市场份额须核行业分母、地区与产品边界，不能仅凭保费增速判断竞争地位。相同事项进入I9时标出基础因素及后续调整，避免重复。

**反证与补证：** 趸交冲量、低价承保或高佣金可带来规模而非价值。索取保单批次、续期现金及定价利润测试；缺失时把“增长”与“成长质量未验证”分别写。**产品/复核：** 产品/渠道增长收益表；复核人在一产品上重算量价/利润率并核对定义。

### I2 准备、CSM、服务与金融损益

1. 确认适用CAS/IFRS 17或其他准则及过渡方法，按GMM/VFA/PAA、原保险/持有再保险、剩余保障/已发生赔款分表。PAA及不适用该准则的业务不能强造CSM。
2. 使用合同组原始调节表：`期末CSM=期初+新增+利息±未来服务估计/适用金融变动±汇兑/转入−服务释放`；亏损合同的损失组成部分、风险调整RA、履约现金流另滚动。不能把所有估计变动都归为未来服务，VFA与GMM处理需按政策辨认。
3. 核对CSM释放的保障单位、当期服务量和未来服务期间；若只知道释放/摊销前CSM，可给描述性释放率，不能反推所有合同组实际摊销因子。
4. 将保险服务收入、服务费用、再保险净结果连接服务业绩，再单列计入损益的保险金融及投资结果、其他收入费用和所得税，勾稽净利润。计入OCI的保险金融及投资变动另与净利润连接至综合收益和权益变动，不加进净利润。投资成分不作为保险服务收入；服务费用之差不自动等于最终保险服务结果。
5. 向精算取得现金流/折现/死亡疾病发生/退保/费用/赔款通胀假设和经验分析，分假设改变、经验偏差、亏损合同和RA释放。无合同现金流时只完成桥和方向挑战，不能确认准备充分。

**反证与补证：** CSM增减可能由金融假设、汇兑或收购驱动；CSM不是现金或可直接分配权益。**产品/复核：** 合同负债与CSM桥、服务/投资/金融利润桥；复核人检查一合同组的释放和负债滚动及最大假设变动，不能只看总额闭合。

### I3 财险/再保承保与赔款发展

1. 分事故年/日历年、毛额/净额、险种和长短尾建立已付/已发生赔款三角；把最新对角线与赔款准备/已付余额核对，记录收购、汇率、再分类。
2. 仅在费用率、赔付率同范围同分母时复算综合成本率；拆本事故年、往年准备金发展及巨灾贡献。保险服务费用/保险服务收入通常不能替代披露综合成本率。
3. 数据适用时以累计赔款`C(i,j)`计算量加权发展因子`f(j)=ΣC(i,j+1)/ΣC(i,j)`，各和使用相同事故年；逐步推终极赔款，`未付准备=终极赔款−累计已付`。已发生三角与已付三角不能混算；不稳定业务、结构变化、负发展、稀疏巨灾或长尾需要另择方法与专家判断，不能默认链梯法适用。
4. 尾部因子、通胀和大案按证据设敏感性；将估计区间与已计准备比较，解释方法与参数不确定性，不能将单一差额直接确认为会计少提。

**反证与补证：** 较低成本率可能依赖往年释放或有利再保。索取事故年三角、大案清单、结案速度和司法变化。**产品/复核：** 承保归因与赔款发展底稿；复核人用相同数据独立重算因子，并挑战尾部/业务稳定性。

### I4 会计权益、监管资本与评级资本

1. 从同实体偿付报告取核心资本、实际/综合资本、最低资本及风险类别，与会计权益做准则、估值、限额、工具和扣除桥。
2. 复算适用的核心/综合充足率；按原制度核对最低资本聚合、分散效应和控制风险调整，不把各项资本简单相加替代监管公式。
3. 把新业务、留存利润、分红、利率/市场、信用、再保、工具和过渡政策分别传导至分子和分母，再算压力比率及金额余量。只拥有敏感性时报告局部冲击范围，不假称整体ORSA。
4. 另从同日同实体权益建立评级可用资本桥，逐项列会计已体现部分、经济调整、税、损失吸收及转移限制。按适用方法处理资产估值、准备差额、长期业务价值、未赚保费获取成本、商誉/无形、混合工具和未来亏损；CSM、RA或内含价值不得全部自动加回，未来利润、DAC及资产增值不得重复认可。分别给调整前、调整后及删除最大正向调整的结果。
5. Global BCAR的非寿险准备调整同时影响资本和准备风险基数。先对齐账面已含折现、终极未付赔款及支付时点，再计算经济准备；账面准备减经济准备形成资本调整，同一经济准备继续承接不利偏差风险。已入账的追溯再保时间价值不得再次认可。**假设例：** 忽略税及其他调整，账面未折现准备100、独立估计未付120、给定现值因子0.9，经济准备108，原资本100调整为92；若仅为演示假设风险因子20%，风险额为21.6而非20。−8与21.6分别反映已有经济缺额和进一步偏差；20%不是机构通用参数。寿险死亡风险另接扣除准备及再保后的净风险保额、在保规模和险种，年金/养老金准备另测长寿改善影响；不能套用上述非寿险算例代替寿险风险模型（PDF第19–22页）。
6. 使用Global BCAR时记录模型、置信水平及各风险暴露与参数，复算`(可用资本−净所需资本)/可用资本`并以百分数表示。按原件PDF第4页的聚合式核根号范围和交叉项，不能直接相加风险额或套普通平方和；非正资本不按正常比率解释。缺完整参数时交付可证实的资本桥与情景，不能将监管偿付率换名为BCAR或由BCAR单独推出信用等级。上述资本分桥与准备衔接依据该方法PDF第3–6、19–29页。
7. 采用Fitch保险2026版时，p45的基础评级资本由股东资金及指定准备、少数股东权益等调整构成，IFRS 17下包括税后CSM；p49的IFRS 17 ROE却使用报告期间平均股东资金，分子净利润和分母均排除相应少数股东份额，已排除的不再扣一次。**假设例：** 无少数股东及其他调整，期初/末股东资金90/110，CSM均40，适用税率25%，净利润10；期末方法资本为140，ROE为10/100=10%，不能误用含CSM的平均资本130算成7.6923%。每个指标各建定义桥；这一IFRS 17规定不能自动扩大到CAS，CSM认可也不证明其可用于偿债或分红。

**反证与补证：** 比率改善可能依靠资本债、过渡安排或最低资本下降。索取偿付资本明细、ORSA/计划及下拨限制。**产品/复核：** 权益—资本—最低资本桥；复核人排除未落地措施、核对受限性。监管风险综合评级“BB”等是另一体系，不作为外部信用级别。

### I5 投资与资产负债匹配

1. 分保险人承担/保户承担投资风险的账户取投资、信用等级、期限、币种、流动性、关联/另类及估值层次，核对穿透后暴露与账面额，未知穿透部分保留未知。
2. 与保证、分红、满期、赔付及保单选择权现金流配对。先做逐期现金流缺口，再用同口径资产/负债价值与久期分析；线性近似`Δ净值≈−DA×VA×Δy+DL×VL×Δy`仅用于小幅平行利率敏感性，不适用非线性选择权、曲线变化或不匹配口径。
3. 一致情景分别计算投资损益、OCI、保险金融损益/OCI及监管资本变化；把对冲追加担保品需求送入I7，不能把账面盈利当现金。
4. 关联资产先区分并表内部项、未并表保险人、非保险经营公司、投资载体及公司间贷款，再决定抵销、独立风险或穿透。Global BCAR对计入借入方可用资本的公司间贷款，从借出方可用资本和投资中扣除相同获认可金额，避免同一资金在多个评级单位重复认可。套保要匹配风险、情景和期限；若模型因此减少对应风险的所需资本，同时从可用资本扣除该衍生品资产价值。投机头寸不自动享有分散收益（PDF第12–14、25–26页）。

**反证与补证：** 久期相近仍可能现金时点/币种错配。索取资产穿透、负债现金流、套保及保证收益测试。**产品/复核：** 投资暴露与ALM双视角表；复核人追最大集中和最大不匹配，检查同一损失不会重复入资本。

### I6 再保险的实际风险转移

1. 将毛承保风险、分出条约、再保险资产/负债、净暴露逐项连接；再保佣金、摊回赔款及持有再保CSM按适用政策单列，不从原保险负债随意净掉。
2. 对重大条约读取免赔、限额、除外、复效保费、经验账户、追索/recapture、抵押及争议条款，计算`可摊回=按条约约定作用于各次/累计损失的赔付`，按层扣免赔和限额，而非统一损失×分保比例。
3. 检查再保应收账龄、对手集中、信用损失及抵押可用性；分别设置对手不履约和回款延迟，重算净损失、资本和现金。资产密集型/关联再保核对资产控制及撤回风险。
4. 巨灾情景保留暴露/模型日期、单次或年度累计、重现期、毛损失、净损失、复效保费及税。事件后滚动未付准备、再保应收、已耗限额和恢复保障，不能继续使用事前的全额保障。准备摊回与已付摊回按对手、账龄和到账期限拆开；资金扣存、信托、信用证及担保分别核执行条件，风险资本抵减不等于已经收到现金。

**反证与补证：** 降低账面资本耗用不证明经济风险已转出。索取原条约及结算/抵押证明；没有条约不确认压力时可回收金额。**产品/复核：** 毛—分出—净损失及回款桥；复核人挑一个大赔案逐层重做，检查同向风险。

### I7 退保、满期、巨灾与现金生存期

1. 寿险从保单现金价值和满期分布估算退保/保单贷款现金需求，财险/再保从大案、巨灾付款曲线及摊回时滞取用途；赔付准备账面额不等于本期现金付款。
2. 按实体、币种、时间段使用B6的现金余额递推；把资产折价、衍生品保证金和I6回款压力同步加入。退保冲击先验证适用保单群、现金价值和基准行为，不能对全部负债任乘统一退保率。
3. 将最小现金余额、首次缺口与可执行资产出售/融资/业务措施并列；偿付能力充足不是现金测试的结论。
4. 毛赔款按付款日列支，再保按可收性及到账日列入，净经济损失不能代替支付峰值。**假设例：** 现金50，第10天支付80、第60天收再保60，无备用融资，最低余额−30、期末30；直接扣净赔款20会漏掉缺口。Global BCAR财险被迫出售风险所用毛巨灾需求，与巨灾风险额所用税前净损失及复效保费口径不同（PDF第15–18、26页），同一情景分别连接资产折价、净损失和现金；未能证明实现的税利益不能提前计现金。

**反证与补证：** 利率上升可同时引发退保和债券浮亏，巨灾付款可能先于再保。索取现金价值群组、支付峰值和回款历史。**产品/复核：** 现金阶梯；复核人检查回收先后与资产重复融资。

### I8 保单责任、主体与资本工具

1. 把保单履约能力、经营公司发行人、控股公司发行人和次级资本债分开；读取保户保护/清偿规则、上游分红及资本限制。

把每项证据、同业比较及因素判断连接至隐含IFS，再依据公司特征的持续影响、最弱环节及行业/主权等约束形成调整后IFS，另处理外部支持，接保单履约IFS、发行人IDR及具体债项。权重表不提供完整数值映射、舍入和委员会判断；缺口须定位到因素或后续节点，不填零、不自造字母等级数轴，也不套工商方法的加权调和均值。用I4/I8的各自口径重做一个主导因素及其不利情景，再追到受影响的结论节点。

**从实体到债项（p33–38）：** 控股公司与经营公司先分别形成IDR，核资本/盈利能否及时上划及所用监管环境；少数不适宜建立IFS的控股业务可按p33–34直接以控股IDR为起点，不能强造保险经营主体。债项以实际发行实体IDR为基础，先按受偿顺位与回收判断调整；混合工具再单独评价递延、取消或减记等非履约风险。记录两步的理由及原表单元格，不能把资本认可比例直接变成级差。无担保债常规回收假设适用于IDR为BB−及以上的分支；B+及以下和有抵押等担保物的债项通常需要专门回收分析，担保物优先权还可能降低剩余无担保债回收。保证担保另核保证人的相应义务级别、保证顺位与覆盖，不能混同担保物优先权。分别处理经营公司清算、经营公司困境使控股公司失去上划，以及控股公司自身困境但子公司仍经营的路径，不能一律按集团合并账面资产分配。

**受损事件与跟踪（p36–38）：** 混合债项的监管环境按发行人法域判断；控股IDR因资本/盈利受限采用Ring Fencing，不意味着混合债项自动使用同一分支。实际触发损失吸收时，按恢复付款可能性和经济损失走非履约工具路径，另核是否触发发行人违约；不能仅凭合同允许递延就维持原债项结论，也不能把任何延付都写成主体D。到期未付须核合同应付款和宽限期，该方法一般取合同宽限期与30个自然日中的较短者，未约定及付款不可抗力的分支另核。困境交换同时检验条款实质减损和避免破产、支付违约或监管介入的动机。宣布、实施和完成后评级动作分别记录，不能把自愿接受交换等同不存在困境。上述均使用该方法国际尺度，不能直接换成境内AAA至C序列。

该版p15的混合工具在资本结构中的占比上限、p16的财务灵活性及p31的集团资金抽回条件存在措辞方向疑点；取得官方适用解释前，不据其建立无上限抵免、融资或支持加档规则。上述路径不替代Prism、完整支持/债项方法或法律条款；已知部分继续分析，未决部分保留具体影响。

### I11 AM Best经营、业务及ERM的形成步骤

采用[BCRM 2024-08-29](https://www3.ambest.com/ambv/ratingmethodology/OpenPDF.aspx?rc=250950)时，资本起点之外继续执行PDF55–84/印刷53–82的经营、业务、ERM及综合调整；不同因素各保留原件、事实、反证、判断和对初步评估（尚非最终ICR）的作用。先列齐本评级单元适用的原文章节及子项，以下动作不代替完整覆盖。

1. **经营口径与同业（PDF55–60）。** 将承保、投资及总体盈利分别接到原始报表基准，保留会计/监管及研究调整桥。基准按险种、长短尾、地区、股份制/相互制和风险暴露选择；相互制保单持有人股利及长尾投资收益会影响比较，不能只按综合成本率排序。多业务可用多个基准；同业太少时直接逐家比较，不制造统计代表性。选用寿险NOG/资产时，分子为对应税后NOG、分母为期初末平均认可资产，不能直接换成IFRS净利润/会计总资产。
2. **持续盈利到C.1（PDF57–62）。** 连接可得历史、最近趋势和有依据预测，拆一次性事项、事故年/日历年、保费/存款与准备金变化及投资承担的风险；十年历史可得时纳入，近期战略或风险偏好变化单列。按实际重要性解释各指标为何支持或反对C.1档位，不平均比率或按一项阈值自动定档。盈利预测须接未来资本形成，不能以过去盈利证明未来仍可持续。
3. **业务事实到D.12（PDF63–72）。** 逐项读取D.1–D.11并取证：市场分母及份额增长的盈利性、竞争与进入壁垒、渠道控制及集中、定价/数据能力、管理层计划兑现、产品/地域相关性、产品条款及损失风险、监管/事件/市场/国家影响、创新实际收益。美国产品风险分类不能照搬境外同名产品；技术投入本身不证明竞争优势。各子项记录正/中/负及证据，按对未来偿付力的重要性形成整体业务档，不能等权投票；一个决定性不利因素可能压过其余有利项。
4. **RIW到E.2（PDF73–83）。** 分开检查ERM框架、实际风险暴露与管理能力，再形成整体判断。沿原文列齐框架及风险评价子项，把已使用的限额、超限上报/纠正、压力与未建模风险、决策和激励接到真实事件与结果；制度存在或管理层自述不证明控制有效。用本指南I1–I7的暴露、准备、再保、投资、资本及付款证据挑战能力是否适配，另接法律/运营风险；按规模、性质与复杂度判断，不因系统简单自动降档。已开发框架和经外部压力证实嵌入的框架分别取证；缺运行证据保留影响及具体请求，不用模型精细程度替代E.2判断。
5. **组合上限、综合调整与形成链（PDF26、54、84）。** 各因素按其原表及已核判断作用于中间结果，保存未决分支和更改档位的条件。PDF26/印刷24及PDF54图要求：业务Very Favorable的+2与ERM Very Strong的+1同时成立时，两者正向合计最多+2，不能算+3；该组合上限不作用于经营因素或F.1，也不改变负向调整。例如已核baseline为bbb、经营及综合调整均0，这一组合得到初步评估a−而非a；这是构造例，仍须后续支持/拖累判断。综合调整另列前序已捕捉贡献、仍未捕捉的特殊强弱、同业依据及最多一档的作用理由，不借此补齐未知参数或随意调到目标字母；之后继续支持/拖累、最终ICR、FSR及I8债项，不跳过评级单元或发行法人。

**复核产物：** 经营口径与同业表、原文子项覆盖及判断表、RIW证据/补证记录、逐步ICR形成记录。复核人重取决定性口径，并挑战更换同业、删除最大有利调整及控制失效后的判断；没有实际执行的内部程序单独保留。

### I12 AM Best可用资本、杠杆与保险控股资金

采用[Available Capital and Insurance Holding Company Analysis](https://www3.ambest.com/ambv/ratingmethodology/OpenPDF.aspx?rc=266915)（2025-09-18）时，与I4、I7、I8及BCRM共同执行。以下PDF页码对应35页文件（正文印刷页比PDF页小1）；历史评级先核该行动披露表和适用版本，不以文件生成日期决定生效。

1. **评级单元与控股双桥（PDF2–5、19–28）。** 从各受评实体的财务报表起算，并列评级单元实际持有资本与控股/合并资本。控股发债后实际以现金认股下拨，经营单元按收到的资本分析，控股债务和偿付义务仍存在；未下拨或仅由管理层称可支持的工具不自动成为经营单元可用资本。EPS下高级债的合并BCAR认可另须证明单体监管、上划限制、强结构性后偿及实际下拨，不能因集团属于EPS就给全部高级债资本抵免。
2. **权益至经济可用资本（PDF19–23）。** 按适用会计、险种和法域逐项核未赚保费获取成本、准备经济价值、资产市值、均衡准备、参与分红基金盈余、长期业务净经济价值、无形资产、未来亏损和自身信用重估。准备与追溯再保时间价值沿I4成对处理；均衡准备需独立准备评估及可转移性证据。长期业务价值须有稳定、永久及持续盈利记录、市场认可并经独立审阅的计量框架，先扣已认可DAC、资产增值及参与基金盈余等；通常以净值50%为认可起点，再按市场敏感性、稳定性和可转移性调整，不直接将全部CSM加资本。商誉/无形剔除，自身信用恶化带来的税后债务重估收益另核扣除；未作预测时的未来亏损调整看全公司净经营亏损及一次性因素，不逐亏损分部重复扣。列税前、税、税后及已入账部分，并重看依赖正向调整前后的资本。
3. **财务杠杆权益认可（PDF5–14/图B.1）。** 从真实发行条款分别判断永久性、支付及顺位，各维度通常最多30%，三者基线最多90%；图中位置是指引而非自动打分。首赎/回售、票息跳升、投资者预期及同金额同特征替换的能力/历史影响实际期限；累积与非累积、任意或强制递延、违约加速、保单优先和资本结构顺位分别取证，再按复杂度、管理意图、监管处理及融资能力调整。高级债在此不获权益认可；仅符合普通股实质的特殊工具才可能全额认可且不占一般20%总资本限额，不以会计列权益或监管合格直接认定。
4. **BCAR工具资格及期限（PDF23–27/图C.2）。** 与上一步分开：须核保单后偿、不得具有加速付款或加重财务压力的条款、可递延支付及监管资本认可。通常预期偿还剩余15年以上全额、5年至15年线性递减（5年33.3%）、不足5年不认可；有充分证据证明持续同类再融资意图和能力的情况另按原文判断，不能只取合同最终到期。合格工具的比例仍受限额与发行人/工具组合审查，不把杠杆的60%认可直接作BCAR的60%。
5. **先资格，后各自限额（PDF3–4、23–29）。** 财务杠杆的一般权益认可限额按总资本，BCAR按最终可用资本；EPS合并BCAR中的合格高级和混合债共用20%限额，不各获20%。保留限内候选认可额、限额基数、认可与超额。仅有正的非限内资本E和合格候选H这两类组成时，`x=min(H,0.20×(E+x))=min(H,E/4)`，最终可用资本为`E+x`，不是未限额资本的20%。原文例E=3、H=1.5时x=0.75、资本3.75；E=18、H=8时x=4.5、资本22.5。其他资本及限额存在时重建实际组成，不套这两个数。或有资本按设施资助、触发、行权和发行主体分流；put由IHC持有时，数量认可另须可执行合同承诺下拨至经营人，经营人直接行权不要求不存在的IHC下拨。put安排涉及经营公司层面拟发行混合证券时，可用资本的候选认可比例回用本方法Financial Leverage部分的因素（PDF23），仅拟证券具普通股性质时才可能达到100%；不能代用普通已发行混合工具的BCAR期限认可比例。合格充分预筹设施在发布BCAR中行权前给予pro forma数量信用时，拟发行证券已进入财务杠杆评估，再按其自身权益信用处理；此发布认可受总可用资本10%限额。未充分资助或管理自主触发、仅获定性或压力量化信用的路径，证券在实际发行前不进入财务杠杆。两条路径分别保存资本、拟证券债务处理与现金到位时点，不把未行权额度视为现款，不因进入杠杆评估就认定票面全额留在债务分子。
6. **经营杠杆资格与总量（PDF15–19）。** 对匹配资产融资、非保险业务融资及非经济准备融资逐笔核对应现金覆盖本息、ALM/投资能力、期限错配、还款及流动性风险、投资政策、控制和契约，利差业务还需正利差；名称或非追索不能单独证明合格。FHLB用于营运/资本备用通常属财务杠杆，合格利差活动另判；XXX/AXXX信用证剩余不足5年按财务杠杆，有追索/追加担保触发或闭块变现另核。VIE穿透债务与投资损失责任，合并但无追索且损失仅限投资的情况才按原文剔除。合并层合格经营杠杆超过合并负债扣除separate-account负债后的30%时，超出部分继续计财务杠杆，不扣一般信托或隔离资产充当该负债，不把全额移除，也不免除集中及现金风险。
7. **杠杆、覆盖与双重杠杆（PDF15、29–31）。** 分列调整前后债务/总资本、债务/有形资本；有形资本另剔除无形项，各自记录工具认可。按本方法重建经营EBIT、利息与非权益优先工具支付、固定费用，不能搬用Fitch的税前股利公式或将部分权益认可等比例削减实付息费。`双重杠杆=控股对子公司投资/控股调整后自身权益`；高于100%提示投资有债务融资，追实际资金和股息依赖，不以合并权益为分母。服务型非保险业务重大时加强现金、稳定盈利、分红能力及债务/盈利分析，不仅凭有形资本比率下结论。图D.1是资本、流动性与覆盖的综合情景指引，不是强制分档表；不存在的边界/空档不自行补齐。
8. **控股现金先后顺序（PDF31–34）。** 按法人、币种和付款日核控股现金/证券、可依法上划的股息、短期融资与备用安排；核股息限制及压力下保险子公司和最终母公司的双向调用。用途除本息、优先/普通股分配和回购外，逐项接债权人回售、衍生/商品保证金、repo与借券结算、表外责任、诉讼、担保、投资承诺及子公司缺口。资金市场关闭、上划减少/停止与资本调用同时发生的情景重做现金阶梯；评级高、银行关系或资本额度不等于付款日可提款。

**复核产物：** 单元/控股资本双桥、工具条款及两套认可记录、最终分母限额复算、匹配融资与超额表、杠杆/覆盖及控股现金阶梯。复核人重取最大正向资本调整、最早赎回和最大上划来源，并在不再融资/不收股息下重算；所得继续进入BSS、支持及I8发行法人/债项形成，不由资本抵免直接生成级差或完整评级。

### I13 Takaful双基金：资本、费用与支持

采用[Rating Takaful Companies](https://www3.ambest.com/ambv/ratingmethodology/OpenPDF.aspx?rc=197661)（2026-05-14）时，与适用BCAR、I1–I8、I11–I12及BCRM共同执行。以下页码为12页PDF的物理页；不把普通保险合并资本或利润直接当作参与者基金的偿付资源。

1. **契约、基金与权属（PDF2–5）。** 先识别一般/家庭业务、Mudharabah、Wakalah、Waqf或混合模式，逐项取报酬、盈余所有权及分配条款。分别保存参与者基金与运营者/股东基金的报表、准备金、权益、投资和现金。窗口业务是同一法律实体内的圈定基金，子公司另有法人边界；Waqf及其他结构按实际权利处理，不强行套同一种双基金分红关系。圈定名称不证明清盘时的隔离、追索或转移权。

3. **两阶段资本及非对称支持（PDF6–8）。** 第一阶段列参与者基金各置信水平的可用资本、净所需资本和资本余缺；第二阶段重做两基金合并资本与风险，抵销内部项，保留一致时点、单位和实际范围。较强合并结果能否改善参与者强度，须核可执行支持、监管和转移时点；较弱合并结果不机械覆盖较强参与者结果，另证运营者不能提取其盈余的保护及实际失效路径。不得简单取两者最小值、平均或公司总权益替代判断。缺NRC只保留该资本比率分支，不关闭基金权属、资本桥和现金分析。
4. **双方费用与盈余持续性（PDF8–10）。** 分列贡献、索赔及准备变化、投资回报、运营者费用/利润分成、参与者分配与各自管理成本，权责发生与现金分别接回。比较运营者收入对管理及资本成本的覆盖、费用相对贡献减索赔的负担，以及双方费用/分配后盈余和连续缺口；贡献减索赔不正时不包装成正常费用率。合并盈利或高运营者覆盖率不能消除参与者持续耗损，监管和支持证据充分时的合并经营判断仍展示双方失衡及修复条件。
5. **受限资产、再保与付款（PDF8–9）。** 逐基金连接投资允许范围、资产/地域/对手集中、长短业务ALM、流动性和再保可收性。Retakaful与获准常规再保按真实合同及信用质量分析，不因名称自动升降风险。把索赔、费用、分配、Qard和所有者追加资金放到实际付款日；现金较多或股东支持意向不证明可及时支付。
6. **业务、治理及法律不确定性（PDF9–11）。** 核市场位置、客户/渠道/产品集中、历史和规模，并以运行证据挑战双基金定价、准备、风险限额及资本管理。分别读取监管、清盘、Shari’a board与经营目标的约束或冲突，明确需法律/监管原件支持的条件；Takaful标签不构成竞争优势或固定业务档位，也不代表本次作出Shari’a合规裁定。支持可信度另取所有者资源、发股/发债及历史投入。
7. **共同底稿与评级形成。** 基金原始事实保留原scope；跨基金资本/现金桥记录抵销和实际执行的专门结果，不通过改写原scope绕过比较限制。两层资本、双方经营、业务、ERM及国家风险分别进入I11和BCRM的形成链，再处理适用支持/拖累及I8实际发行人/债项；本方法未给出的因子或级差继续读对应原文，基金资本余量不能直接变成整体信用等级。

**复核产物：** 契约及双基金权属表、Qard对账与资本/现金桥、两阶段资本记录、双方费用/盈余趋势、付款压力与ICR形成依据。复核人重取最大费用及支持划转，在未动用承诺不到账、运营者不能提取参与者盈余及费用持续失衡下分别挑战判断；原件或必要法律/风险参数不足时保留具体未决分支。

## 证券与资管：客户边界 → 盈利 → 交易风险 → 资本和现金

[华泰证券2025工作例](../../../examples/huatai-2025/analysis.md)将分部和重述、金融资产风险、客户权属、融资口径及监管资本接成真实分析链；按案例标明的信息截止日与方法版本使用。

### S1 客户资金、受托资产与自有资产

1. 从客户银行存款、结算备付金、保证金、代理买卖证券款、应付客户结算款与基金合并附注建立权属表；分别列“谁拥有、谁可用、用途限制、对应负债、托管/存管方”。
2. 先算自有与非自有资产负债的报告口径桥，再用同客户群、同币种、同时点存管对账，核`客户权属资产及合法在途项目−对应客户义务`。相关附注不齐时不能以两个总科目之差断言挪用或安全。
3. 自有流动性扣全部客户/受托及受限款；客户证券借贷、抵押和合并基金逐项读取合同和控制依据。不能用客户现金冲减公司债务。

**反证与补证：** 看似净现金可能来自客户交易高峰；净额科目可能隐藏在途差。索取存管确认、客户分类账、未达账和期后清算。**产品/复核：** 权属/可用资金桥；复核人双向追客户总账与银行/结算机构证据，公开披露不足就保留未核对结论。

### S5 收入质量与资本效率

1. 将经纪、投行、资管、自营和利息业务分开；按成交额×净费率、平均收费资产×费率、平均融资余额×净息差解释收入。注意商品贸易等低毛利总额收入，不能直接用总收入比较券商规模。
2. 自营实现/未实现及一次性处置分列；费用按可变与固定证据拆分，核对分部抵销和集团净利润。
3. 将增长同自有头寸、融资、净资本耗用配对；只有分部资本分配方法可验证时计算分部资本回报，不自造分母。

**反证与补证：** 市场上涨、并购或业务出售可改变同比；收入增速快于资本不必然提高风险调整回报。索取量价、项目确认及资本分配。**产品/复核：** 收入和资本效率桥；复核人挑战最大一次性项目及合并范围变更。

### S2 融资融券、回购与衍生品保证金

1. 逐对手/净额协议连接融出、买入返售、借券、卖出回购、衍生品、质押/再质押与到期。名义本金、会计公允价值和信用暴露分别列示。
2. 回购/逆回购根据实际抵押条款算合格抵押价值`Σ市场价值×(1−适用折扣)`；融出风险与折扣后担保差额分列，净额仅在法律和操作均可执行时适用。
3. 压力同时冲击担保品价格、折扣和续作。融资追加担保品/现金需求按合同重算；衍生品按CSA的门槛、最低转移额、初始/变动保证金和结算时点计算，不拿名义本金直接算损失。

**反证与补证：** 高质量国债仍有折扣上升、期限错配；对手和抵押物可同向恶化。索取CSA、净额法律意见和逐笔头寸。**产品/复核：** 交易—抵押—融资联表；复核人追单一最大对手的毛额、净额、担保及现金路径。

### S3 市场风险、估值与尾部

1. 按利率、信用利差、权益、汇率和波动因子归因；区分方向、做市、套利及对冲。将VaR日期、置信度、窗口、持有期和回测异常随数值保存，不能跨定义排名。
2. 有风险敏感度时按其单位和定义计算，如DV01/CS01以每1bp计，冲击必须用bp且核符号；非线性期权用重估或注明有效范围的delta/gamma近似，不把名义本金替代敏感度。
3. 对集中、拥挤、基差失效和不可快速变现头寸追加一致压力，另列第三层次估值、不可观察参数和报价时效；对冲只有在同一情景下才能抵减。

**反证与补证：** 低VaR或期末轻仓不证明尾部风险低。索取年内峰值、回测、限额超标及模型独立验证。**产品/复核：** 因子损失与估值不确定性表；复核人核敏感度单位、符号及对冲两端。

### S4 净资本、杠杆与流动性

1. 从同牌照监管表复算`净资本=核心净资本+附属净资本`、`风险覆盖率=净资本/风险资本准备合计`等适用指标。资本杠杆率的分子与分母均核专门定义：[2024年计算标准](https://www.csrc.gov.cn/csrc/c101954/c7507765/content.shtml)附件1第21页注2明确，该比率的核心净资本不扣担保等或有负债风险调整，不能直接照搬另一张净资本表的分子；分母取监管调整后的表内外资产，不可用集团总资产反推。未取得对应底表时保留披露值，不从舍入比率反推准确调整额。
2. 将净资产至核心/附属净资本扣减、次级工具合格性与业务风险资本准备变化列桥；同时对集团自有债务期限和资金可转移性做独立表。
3. 由S2/S3的损失与抵押需求重算自有净资产、监管扣减及风险资本准备，再执行现金阶梯。规则/阈值须按时点和类别核实，2025执行的新计算标准不能倒套2024原报指标；公司已按新口径重述比较值时，当前可比分析采用重述值并保留原报，历史时点研究仍用当时可得版本。

**反证与补证：** 次级资本增加可抬净资本但核心资本不变；季末压表可美化比率。索取监管计算表、日度峰值、受限头寸和融资合同。**产品/复核：** 净资本与现金双桥；复核人确认母公司/合并边界并排除客户资金。

### S6 资管人专用程序

1. 建`期末AUM=期初+净流入+市场变动+汇率+并购/其他`桥；收费AUM与非收费AUM、管理和顾问资产分列，未披露净流入不得从两期AUM直接推算。
2. 用同口径平均收费资产和管理费算隐含费率，业绩费按确认/回拨及高水位另析；拆客户、产品、分销和到期集中。
3. 产品赎回/资产变现问题先作用于产品，再据种子资本、担保、流动性支持、回购及赔偿承诺识别管理人现金/资本责任。基金杠杆不是自动等于管理人债务。

**反证与补证：** 行情推高AUM可掩盖净流出；业绩费不具稳定性。索取流量桥、费率合同、赎回及支持承诺。**产品/复核：** AUM—收费—管理人责任桥；复核人追一大客户和一项表外承诺。

### S7 许可、治理、合规与支持

1. 从最终处罚/诉讼/业务限制和年报事件识别生效日、责任主体、受影响业务与整改；将事件转成潜在赔偿、客户流失、融资或资本需求，已确认拨备与未决风险分开。
2. 小额罚款不能替代对系统性客户资产或销售控制缺陷的分析；支持按能力、意愿及可转移资源验证，不能仅看国有股东。

**反证与补证：** 事件已整改、诉讼撤回或客户留存可以削弱最初负面判断，应主动查期后。索取最终文书与整改证据。**产品/复核：** 事件传导及支持表；复核人区分事实、指控、情景和已发生损失。

#### Fitch非银2026版：从业务口径到主体与债项

依据为上述2026-09-25方法，以下为印刷页码。先按真实业务选择高/低表内占用，混合业务分别配对其债务、现金流或资本。SROE约束并解释因素，不另设权重。七个KRD形成隐含SCP后再解释调整：新版最弱因素通常使SCP相对隐含结果下一档，分差很大或已接近违约时可更多，不能把最弱因素机械设为统一上限。（pp.3–4、16–19）

**租赁和资本。** 一般将租赁负债（包括US GAAP融资租赁）列为其他负债；不计债时，把相关利息和使用权资产折旧转作经营成本。租入后再向第三方出租等直接收入资产、实体销售/分销网络的租赁通常计债；员工办公室和业务硬件通常不计债。按用途做债务及费用的一致调整桥；补充资本比率若更能反映损失吸收能力，说明其与核心比率不同的原因。（pp.16–18）

**构造例：** 统一虚构单位，只有贷款100、办公室融资租赁20、实体销售网点租赁30，报表债务150。报表EBITDA80已加回全部ROU折旧，利息10含办公室2和网点1；办公室ROU折旧6。调整债务为130，EBITDA为80−2−6=72，利息为8，债务/EBITDA为1.8056倍、覆盖为9倍。此例只展示用途及费用配对，不代表完整机构调整或实际公司评级。

**资管收益。** 分别保留披露收益、fee-related earnings、FEBITDA和adjusted FEBITDA。由fee-related earnings加回其中已扣的股权报酬、利息和折旧摊销，再扣非现金收入形成FEBITDA；未在起点扣除的费用不重复加回。核心利润率为FEBITDA/费用收入，核心杠杆及息费覆盖分别为总债务/adjusted FEBITDA、adjusted FEBITDA/利息。基准数值断点未变不代表旧分母仍可直接使用。（pp.39–41、79、83）

形成adjusted FEBITDA时逐类保留净额及认可依据：合同性基础管理费可全额；Part I激励费按现金流可预测历史为全额、半额或不计，永续载体最高半额；基金或监管较弱关联的利息股息按稳定性为全额、半额或不计；高监管关联的净分配和费相关绩效净收入最高半额；已实现激励及投资损益不进入核心分母，可在分开的补充比率中体现。p40脚注规定的利息股息、净分配、绩效及已实现收益等按滚动四年平均，管理费和Part I不机械套该脚注。相关报酬、资本回投和同笔收益的归属先净额及去重。（pp.39–40）

**资管的保险关联。** 全资或控制保险公司，或单一保险伙伴贡献至少15%管理费（排除SMA）时，分析保险资本、分红和追索。Prism资本低于资管评级对应水平时，方法假设注资，按对资管财务比率不利程度最低的债务、现金或FEBITDA组合体现；Prism等效资本与保险资本化/杠杆因素是不同测试。后者低于资管评级时不认可保险上游股息；符合条件时纳入扣资本回投后四年平均净上游股息的一半。（pp.41–43）

p40通用分配表要求连续四年净分配为正；pp42–43保险专项要求多数年份及四年累计为正。适用保险专项时说明采用条款和条件性影响，不静默合并为同一连续四年门槛。保险债务对资管有追索时纳入对应债务；直接保险投资账面值扣有形权益，通过基金持有则区分基金及投资者和资管自身权益。通常不简单合并保险与资管；高双重杠杆或实质提供保险融资、流动性、资本支持时研究混合分析。（pp.42–43）

**投资公司与基金。** 单一持股投资公司可有有限或开放期限，核经营实体隔离、债权追索、全期偿债准备金及不可取消的合格流动性支持。资本结构稳定且有持续依据时以现有结构分析；未来结构不确定时，可按假设次级债务类别而非当前高级类别评估级差，不据此假定已决定新增次债。债权人可追索经营实体时按实际商业模式合并分析；无追索的假设合并视图只服务于潜在杠杆、顺位和回收判断。（pp.43–44）

开放式基金把持仓流动性、长短仓和衍生品杠杆、保证金融资与赎回条款联动；除长仓加短仓/NAV外，重大现金抵押、应收和逆回购等可使总资产/投资资本更有解释力。单项投资超过总值15%等集中情形，同时核标的信用与上游现金可靠性，并据实际风险调整资金覆盖。（pp.45–47、80）

养老基金仅在外部非养老金负债无优先权的司法辖区适用特殊支付时序分支：gross debt包括衍生品负债，分母为权益加养老金负债、减适用期间养老金支付。无重大外部非养老金负债通常取五年；有相关债务时对齐实际/预期最长债期且不少于五年。预测缴款不覆盖支付时，方法可将相关期间支付总额加入分子，不是仅加入支付减缴款的差额。逐项保留顺位、期限、缴款与支付假设。（p46）

**支持。** 区分集团整体分析、自身实力加支持与有限的自下而上支持，分别判断提供方能力、意愿和子公司实际取得支持的条件。母行IDR因处置缓冲高于VR时，核子公司处置范围、预置资源及获接受的处置安排，再选择IDR或VR锚点。自下而上的支持通常受最保守自上而下隐含结果限制；新版不沿用旧脚注额外强制下一档，多层支持还需避免重复折扣。控股公司SSR不计来自本集团的上游支持。（pp.19–24、48）

**债项。** 先识别法人、担保、抵押、合同顺位和不履约条款；非hybrid的普通次级债按本方法，hybrid及银行/保险式审慎监管工具分别接其适用方法。一般高级债以IDR为锚，次级/hybrid常以SCP为锚并按条件调整；股东贷款依据实质和适用Corporate方法认定债性/权益。（pp.51–58）

BB类别使用p54新表：超优先循环额度、资产支持贷款和第一类第一顺位，在BB+/BB/BB−下通常分别为+1/+2/+2且隐含RR1；第二类第一顺位分别为+1/+1/+2且隐含RR2；第二顺位/无担保通常0且RR4；普通次级通常−1且RR5；深度次级通常−2且RR6。先按表内条件区分优先于该债的融资、子公司股权抵押与子公司债务、少数股权/难估抵押品、非美国借款人或主要资产、杠杆与业务条件；司法辖区、保证差异和结构顺位仍可影响结果。BBB及以上、B+及以下另走适用路径，不凭“有抵押”给固定级差。（pp.53–56）

**重组与回收。** DDE同时考察条款实质减损与避免很可能发生的违约/破产等目的；列原新合同本金、息费、期限、抵押、顺位和支付桥，并考虑流动性、融资和法律过程。正常履约企业因市场价格、多余现金等调整不自动构成DDE。普通公共融资、系统支持和针对特定机构的持续特别支持分别判断。（pp.67–69）

回收区分持续经营、清算及法人瀑布。持续经营从最近适用期收益解释违约后可维持EBITDA，20%–40%压力指引结合永久/周期冲击、破产制度及同业证据使用；估值倍数另有业务与市场依据，不把两个中点直接相乘。受限资产与对应债务配对，证券化余值保留到账延迟；循环额度提款及新增可回收资产、管理费、按当地法律的拒租和其他请求一并进入实体债权瀑布，母公司仅取得可上划剩余。（pp.55、85–87）

**时间尺度与气候。** 通常18–24个月前瞻情景用于评估评级余量；Climate.VS为更长期筛查，分物理/转型风险，按业务相关的行业、地域及资产持有方式解释其对既有KRD的影响。现有缓释与未来计划分开。Climate.VS不是独立KRD、实际预测或自动调级，更不能直接映射违约概率；现金流压力使用有证据的业务影响。（pp.70、92–94）

## FMI：公司经营与清算资源分别计算

### F1 业务地位与收入

1. 分交易、清算、存管、数据/指数取量、费率、未平仓量和收入；核清算投资收益中归会员与归公司的分配，只有公司保留部分进入经营分析。
2. 将经常订阅与交易周期收入、产品/会员集中、替代场所和技术支出连接经营利润与公司自由现金流；并购债务按公司融资分析，不把会员往来作为普通营运资本。

**反证与补证：** 波动带来的量增可掩盖份额下降或收费压力。索取分产品量价、客户流失及收入分配。**产品/复核：** 量价与公司现金流桥；复核人检查会员本金和交易配对资产未进入公司盈利/自由现金。

### F4 公司资产、会员资金与用途受限资源

1. 按公司运营现金、初始保证金、变动保证金、违约基金、会员结算款列权属、资产形式、对应义务、法律实体、币种、使用条件及可用时点。
2. 复算清算资产/负债及各分项；配对交易余额可相等，但其他净差额仍需解释。账面差额不是自动损失或资金挪用证据。
3. 从公司现金扣法定/合同/监管受限、质押和不能上划部分，才得到可用于公司债务的现金。用于某CCP服务的资本和会员担保品均不能跨用途自由调用。

**反证与补证：** 合并现金高可能主要是会员款；净现金计算会被夸大。索取清算账、结算在途、银行/托管确认及资金用途法律依据。**产品/复核：** 会计余额—权属—偿债可用额桥；复核人逐项找资产对应责任，不允许用保证金消除公司债务。

### F2 服务级违约瀑布：先定义损失，再逐层消耗

1. 从同日规则簿及适用披露确定资源的顺序、币种、金额及触发条件。先确定法人、服务、基金、账户和成员类别五层边界。一个基金可以承接多项服务，同一服务内也可能因客户隔离、代理担保、组合保证金或会员类别有不同权利。依实际规则分别建立“可动用资源图”及“非违约成员损失分摊顺序”：违约成员的跨业务剩余基金可以与非违约成员的服务限定基金有不同权利。不得依据营销服务名称推定基金完全隔离，也不得依据集团合并或共享基金推定每个账户完全可互用。
2. 定义`L0`为该情景的平仓/拍卖损失及适用成本，说明是否已经扣除保证金。若披露的是“超过保证金的压力损失”，从下一层开始，不能再扣保证金；违约成员基金已含在总基金内时，从可用共同基金扣除该成员份额，避免重复。
3. 对每层可用资源`Rk`递推：`本层使用Uk=min(max(L(k−1),0),Rk)`；`剩余损失Lk=max(L(k−1)−Uk,0)`。资源先按合同权利、抵押折扣、可变现性及同日汇率调整。逐层递推损失之前区分市场变动、对冲、拍卖、交收、投资和借款成本，核同一资源是否已经用于更早的业务或拍卖批次；当合同按投标行为、组合风险或成员类别改变先后顺序时，使用相应顺序，不能统一按基金份额摊给全部成员。担保品实现价值须满足可执行权利和实际变现条件；缺资料可以保留条件式，但不能把一份总基金数当成完整逐成员结果。
4. 对追缴和补足分别记录触发、参考日、金额基数、同事件累计上限、滚动期事件次数、通知日、付款日、退会生效及重算条件。列“已缴本金、应收追缴、实际到账、已消耗、尚余返还义务”，不要把预缴损失重复记录成当日现金流，也不要把应收追缴全部计为初始资源。另一成员未缴时，更新关联违约集合，而非仅打一个折扣。恢复基金下限、重新计算全额基金、每日保证金与损失分配是不同责任，不以一个追缴倍数概括成员总风险。结合相关成员同时违约、抵押物同向风险及市场深度重算。
5. 输出“层/原金额/资格调整/可用金额/使用/剩余/时点/法律依据”。缺成员损失、保证金、其基金份额或汇率时保留变量和请求，停止给覆盖倍数；仍可完成公开资源与顺位核验。

**反证与补证：** 大额担保品总数不代表服务级压力覆盖；Cover 1/2按适用制度与CCP类型确认，不固定为一个通用阈值。索取同日定量披露、成员压力损失、集中/流动性折扣及规则版本。**产品/复核：** 实际规则驱动的瀑布；复核人选一个情景逐层消耗，查重复基金和跨服务误用。


### F3 日内、币种与结算流动性

1. 将F2信用损失另置；按支付币种、结算窗口记录到期义务与可收资金，信用资源足够不代表能按时付款。
2. 用时间递推现金余额，压力包含会员违约、VM峰值、结算银行不可用、抵押品变现/外汇兑换延迟。额度提供方也是潜在违约成员时联动失效，不能当独立缓释。
3. 分别报告日内最低余额、峰值支付、合格流动资源、到账时间及替代通道。年度/季度最大值不同日发生时不能拼成一个未经说明的联合情景。

**反证与补证：** 基金债券未必能在付款前变现，央行安排可能有资格条件。索取支付日志、承诺额度合同及演练。**产品/复核：** 币种/时点现金表；复核人按真实到账时间重排，不能把恢复工具算即时现金。

季度披露的实体级汇总流动资源不自动属于某服务或某付款币种；保留每条记录的ReportDate、报告层级、币种、折扣和脚注变更。不同成员、不同日产生的币种峰值不能拼为同一联合违约。将回购/借款与抵押物原资源连接：融资可改善时点，但不增加同一资产的损失吸收额，本息及折扣损失回到最终瀑布。已签主协议与已承诺额度不同，央行账户与可依赖央行信贷不同；不得把自评“可使用工具”填作已获额度。

### F5 模型、运行、恢复与反向压力

1. 取得保证金模型回测、压力模型验证、拍卖/违约管理和灾备演练；区分设计文件、执行记录、异常和整改关闭。
2. 从F2/F3寻找令资源首次不足的可解释组合：成员损失、抵押折扣、市场深度或支付延迟。反向压力是边界条件，不是估计发生概率；不可用历史零违约给出安全结论。
3. 把系统/网络/外包中断连接错过支付、违约处置失败、赔偿及客户流失，记录恢复步骤、责任人与实现时限。仅有制度则结论为设计已披露、运行有效性未验证。

**反证与补证：** 最近真实演练成功或失败与整改均可改变判断。索取独立验证、事件复盘及整改证据。**产品/复核：** 异常—现金/资本传导与恢复任务表；复核人重走一个失败路径及一项整改关闭。

恢复工具按账户及现金类型模拟累计损失分配、VM收益减记、部分/全部终止和关闭结算。区分触发复议阈值、真正损失上限、投票延长和终止日；不要看到“cap/trigger”就一律截断。关闭时重新计算旧应付、已分摊损失是否回入净债权、初始保证金返还、剩余基金、净额抵销和分期支付；不能把已消灭的请求权和替代请求权同时列入回收，也不能假设合同继续存续。年度自评中对制度设计的声明不能代替当期规则、付款日志、独立验证和演练结果。

### F6 从经营分析接到清算结算风险与评级建议

使用适用机构的真实FMI方法，而不是把工商杠杆或Cover2通过当成评级结论。以[S&P FMI专章](https://www.maalot.co.il/Publications/MT20251012123218.pdf)（2025-07-07方法、2025-09-26重发，PDF226–233）为例，先判断公司是否落在该行业定义及清算结算风险是否实质相关，再由业务和财务因素建立初始锚点，纳入清算结算风险，最后接资本结构、流动性、治理、集团/政府/主权与具体债项的适用方法。不能跳过先前因素而直接把清算资源映射到字母等级。

业务因素区分市场必要性/替代性、会员迁移成本、监管与技术表现，以及交易、清算、存管和支付各自量价指标；公司收入与会员本金/收益分配要分开。会员所有且近似公用事业、把盈余返还会员的机构，其低利润率不与上市利润最大化公司直接排名。该方法财务前瞻通常以前年20%、当年40%、次年40%形成三年加权，不能套另一行业的20/30/50；转型等调整需有理由，定性例外不能硬算。

清算结算因素分别判断成员资信和风险集中、风险管理与保障资源。成员资信按该方法的初始保证金权重评估，会员人数不替代风险集中，字母等级也不能擅自编码求算术均值。保存所用的成员评级/内部判断、时点和正式映射依据；证据不足就保留该因素未定。风险管理以适用PFMI及执行证据核查，尤其信用、抵押、保证金、流动性及一般经营风险。原方法PDF231矩阵的行是成员质量、列是风险管理；例如两者均Adequate为0级差，Adequate成员/Weak风险管理为−4，其余未覆盖的严重保障或银行系统缺陷还可能增加负面调整。不得把PFMI自评全符合直接写成Strong、把公式算对直接写成风险管理有效，也不得为凑外部评级倒推因素。

成员明细、专门资本/支持/债项方法或实际结算证据未取得时，明确影响到哪个因素和最终结论；不宣称完整复现任何机构委员会评级。

[公开规则与金额工作例：LCH SwapClear](../../../examples/lch-2026/analysis.md)区分真实披露、合同要求及分析者反事实；逐条规则仍须按具体成员和事件适用。

## 非银信贷与租赁：业务责任 → 资产现金 → 损失/残值 → 资本和融资

先按现金和风险承担者分流：收取利息并承担借款人风险用N1；融资租赁应收用N2；持有实物出租并承担剩余价值风险用N3；折价收购不良资产用N4；担保责任用N5；受托收费及可能自营/支持的信托或平台用N6。Mortgage REIT走N1及抵押融资分析，出租物业型REIT走[行业参考](sector-analysis.md)。有存款/金融牌照的租赁公司还需适用的资本和监管资金程序；名称相似不等于风险相同。

[Fitch 2026-09-25非银方法](https://assets.fitchratings.com/downloadFile?reportType=report&sfReport=false&slug=corporate-finance%2Fnon-bank-financial-institutions-rating-criteria-25-09-2026)印刷27–31页区分融资/租赁、资产使用程度及债务收购，73–80页给出分业务指标定义；S&P 2025行业方法印刷234–241页有金融服务融资公司及特殊分支。以下保留这些业务差异，公式、示例和程序为本技能的分析设计；历史截止日和特定行动保留当时有效版本。A指年报和附注，E指已取得的外部公开文件，I指需授权的逐笔资料/合同模型；合同若已公开可归E，A未披露的字段不能补零。

### N1 非银放贷：规模、信用损失与融资必须同算

1. **取数与资产桥。** 从A取分产品贷款毛额、利息/费用、核销/ECL、出售资产与继续涉入、受限资产、借款到期；从E取融资/证券化披露。按产品做`期末贷款毛额=期初+放款/购入−本金回收−核销−出售±其他`，调整应计利息、汇兑/范围后对总账；I需逐笔放款/回款、账龄、客户集团、回购和担保。本金回收不是利息收入，核销不是现金流出。
2. **盈利与资本。** 按平均计息资产复算资产收益，借款成本用对应平均融资余额；以金额桥接利息/费收入、资金成本、信用损失、运营费用、税及利润，不直接相减不同分母的比率。分持有贷款与发起出售手续费，已出表资产的追索/继续涉入单列。ECL与迁徙沿B2/B3的适用部分，IFRS 9与CECL不共用阶段模型；资本用该牌照/方法的权益及调整，不能套银行RWA。
3. **逐期资金。** 将实际本金/利息收款、拟放款、债务本息、费用和保证金排期；融资按到期、抵押、借款基数、合格资产、折扣和提前终止条件复算。先算不新增未承诺融资，再算可执行融资；缩减放款可释放现金但会改变后续收益和组合年龄。

**判断与反证：** 收入快增须同时检查新客批次成熟度和损失；逾期下降可能来自资产出售/展期。压力联动违约、抵押折价、融资折扣与不续作，不能只升坏账率而保留原融资额度。**产物/补证：** 贷款和利润桥、批次表现、融资基数与时间缺口；缺I时只做公开组合分析，不能称逐笔授信或ECL验证完成。

### N2 融资租赁：应收现金与租赁物回收分别验证

1. A取租赁应收毛/净额、未实现收益、保证金、逾期/ECL、承租行业、融资及关联售后回租；I取合同支付表、租赁物权属/登记、承租集团、担保和回收条件。按原表口径滚动净投资：期初加新增净投资、当期确认融资收益，减收到的租赁付款、核销/转让，另列ECL抵减及其他；若净投资未扣ECL，不得再把减值混进该同名余额。
2. 将每笔付款拆利息、本金、保证金冲抵及残值回收；本金不是营业收益。按同类资产复算收益、信用成本和资本占用，再按币种/期限与融资本息匹配。承租人违约时分别核合同债权和租赁物回收，保证金、抵押物与追偿不能重复计入。
3. 对售后回租核资产真实存在、可执行权属、定价和用途；处置价值须扣取回、维修、运输、税费和出售时间。取出租物不能自动解决付款日前的缺口。

**判断与反证：** 不良率低但展期/保证金垫付多，可能掩盖真实收租质量；有实物不等于容易再租。压力联动承租违约、回收延迟、残值折损及融资不续。**产物/补证：** 租金本金/收益桥、租赁物净回收与时点、到期现金缺口；缺合同则不得声称租赁物提供足额保障。

### N3 经营租赁：残值和持续替换不能从偿债分析消失

1. A取租赁资产、租金、折旧/残值、减值、购置/出售、利用率、维修储备和采购承诺；E取同型二手价格及承租人披露；I取逐资产机龄/租约/维修/归还、复租成本及残值依据。做`期末资产账面值=期初+购入−折旧−出售账面值−减值±其他`，出售收入与出售损益分开。
2. 建租金现金、维修现金、购置、出售、税息和债务的逐期桥；出租率与租金率、短租与长期合同分别解释。对持续更新的机队/设备，明确经济耗损和替换支出；采用EBITDA或保留折旧的指标取决于选定方法，不允许只加回折旧却删掉更新现金。
3. 比较实际处置价与同资产出售前账面值，按资产类型/年龄分组；残值假设提高使折旧下降不等于现金增加。租赁与融资期限错配、停租维修期、承租人集中、订单未交付付款及再配置条件共同进入压力。

**原创算例：** 原值100、残值20、寿命5年，购入时直线折旧为16/年；同条件残值30时为14/年。利润相差2而租金现金未变。中途变更须按剩余账面值/年限重算，不能套此差额。**判断/反证：** 高收益率可能补偿弱承租人和老旧资产风险；处置带来现金也减少未来租金。**产物：** 资产滚动、租约到期/订单付款、残值和现金联动情景。

### N4 AMC与不良债务购买者：买入时已不良，重点在回收兑现

1. A取资产包购买价、面值、账面价值、现金回收、回收成本、估值/收益与融资；I取收购批次、债务人/抵押、预计回收曲线、诉讼时间和支出；E取抵押市场及公开处置进展。每批分开记录实际累计回收、累计成本、剩余预计回收和预测更新日期。
2. 将现金回收拆为本金/成本回收与会计收益，按适用计量政策解释账面价值及损益调整；POCI不机械套普通贷款三阶段。实际净回收倍数=`累计已收现金减已付收款成本`除购买价；若指标包含未来估计，要另命名并列，不与已实现倍数混比。
3. 比较相同持有年龄的批次回收与购入时预测，拆数量/金额偏差和时间偏差；将回收延迟、诉讼成本、资产折价、融资利息放在同一现金情景。新购资产可暂停与已有付款承诺分开。

**原创算例：** 买价20，累计回收12、收款成本3，实际净回收倍数为0.45；另预计未来净回收15时，总预计倍数为1.20。后者含预测且未体现时间价值，不能称已实现收益20%。**判断/反证：** 高不良率是资产购入属性，不自动证明业务弱；高预计倍数也可能在债务到期前没有现金。**产物：** 批次实际/预测回收桥、延迟与价格压力、现金缺口；缺I不输出精确回收率或模型验证结论。

### N5 融资担保：最大责任、准备与付款不是同一个数

1. A取在保责任、新增/解除、代偿、追偿、保费/准备、资本和集中；E取适用监管披露及正式保证条款；I取逐担保债务人集团、触发、额度、期限、除外、反担保、再担保及追偿。勾稽`期末在保=期初+新增−解除/到期−代偿对应退出±其他`，续保和已代偿未解除责任按实际条款处理。
2. 按批次对应保费赚取、准备、当期代偿现金与追偿回款；计算净代偿现金时用同期间现金，不把准备计提再扣一次。分可依法索赔的最大责任、已触发付款、估计损失和资本占用，不用一个主观概率将所有保函变为债务。
3. 压力按相关债务人/行业联合违约及付款日，再按回收时间、折扣、反担保/再担保可收性计算；支持方自身也承压时调整来源。已抵减敞口的保证金或反担保不能再次计为新增资金。

**判断与反证：** 低代偿可能因新保单未成熟；反担保与原债务人同源资产可能同时贬值。**产物/补证：** 在保与代偿/追偿桥、集中调用现金和资本影响；未取得限额/除外条款时保留保证责任边界，不能从评级或保证人名称推全额及时赔付。

### N6 信托、金融服务平台与受托业务：先识别责任再用程序

1. A取受托规模、收费、公司自有投资/融资、合并产品、关联方及预计负债；E取许可、产品/诉讼披露；I取受托合同、回购/差额补足、未缴出资、保底和流动性支持。分“产品资产与负债、管理人自有资产负债、已作支持承诺”，不把受托AUM计为管理人可支配资产。
2. 纯收费业务用S6的收费AUM、费率、净流量和收入桥；自营信用资产用N1，折价收购用N4，担保/补足用N5。基金合并不自动意味着管理人须偿还全部产品债；不合并也不代表没有合同追索，逐条标明责任人和额度。
3. 在同一市场冲击中同时计算管理费/业绩费减少、种子投资损失和可能支持调用；已发生支持记录用于判断未来意愿，不替代正式责任证据。诉讼、声誉和监管变化分别连接现金/资本/牌照后果。

**判断与反证：** 表外产品风险可能传导给管理人，但不能一律回表；承诺缺失时交付“无已证实承诺”及有条件支持情景，不写成绝无支持风险。**产物：** 责任地图、收费与自有风险桥、联合现金情景。信托专属指标须核对适用的现行方法全文，不采用未经核实的行业阈值。

## 写入共享底稿和交付

基础求和、差额、比率、量价乘积与滚动桥可用共享`workpaper.py`/`calculate.py`，把原事实、计算定义、期间规则、来源定位、判断、反证、追加程序和资料请求分别保存。百分数与小数选择一种内部口径并显式显示倍率，bp与百分点不得混用；金额先统一币种与倍率。

共享基础算术不能自动执行逐笔ECL期限结构、合同组CSM、非线性重估、日内现金调度或规则簿瀑布。上述任务应附可重做的专用表/计算步骤、来源和执行记录；未经实际执行的程序保留planned/awaiting_data/limited及原因。不要把人工专业模型的输出伪装成共享脚本已经验证的结果。

交付至少保留本次适用业务的：经营及盈利桥、关键准备/资本桥、资源权属与现金压力、支持/债项责任、影响结论的缺证清单。每个重大结论附能推翻它的证据条件。复核时重取最大风险项和一项反常项，核来源、边界、算式及解释；复算通过只说明该算式/勾稽成立，不证明信用安全、模型校准或全部行业参数已覆盖。
