# 金融机构：从报表到信用判断的操作程序

用于银行、寿险/财险/再保险、证券/资管及交易所/中央对手方（CCP）。金融集团按法律实体和业务分别执行，再处理集团内交易、资本与现金转移；不把工商企业的营运资本、净债务/EBITDA模板直接套在存款、保单负债、客户款或保证金上。此文件给出分析程序，不提供外部评级、监管认证或经校准的违约概率模型。

本参考包含独立安装后可用的程序、官方出处和数值例。开发仓库的`examples/financial-institutions/analysis.md`保存扩展案例，属于可选材料，不是安装后的执行依赖。研究日期为2026-10-02；生产时更新适用文件。2026年发布/修订的方法不自动适用于2025年评级行动或财报。

## 先建立可运算的事实范围

每个余额和比率保存：实体、合并/母公司/监管并表、报告日期、流量期间、准则、币种、单位、是否重述、原始URL、公布/批准/取得日期、PDF物理页及印刷页、表名和行列。监管资本与会计权益、母公司净资本与合并债务分别建表。未取得公布日时明确缺口，不能用于“当时可知”的回测。

先取年报及附注，再取同日第三支柱/监管资本/偿付能力/PFMI披露、真实评级意见与募集说明书。内部贷款台账、精算模型、客户存管对账和压力测试仅在获授权后使用。不能访问时先完成公开资料可支持的部分，再列到具体字段的资料请求。评级报告所载数据保留“评级机构整理”来源属性，不冒充直接核验过的审计原表。

工作底稿采用“事实→计算→判断→反证→追加程序”。一项判断要回答：发生了什么；通过何种收入、损失、资本或现金机制影响信用；什么证据会使判断改变。来源缺失记为空值及原因，不填0；不以所有程序均完成作为出报告的前提，而是把未完成事项及对结论的影响一起交付。

下面的复核动作用于独立重做关键分析；算术复算不能单独证明模型或结论适用。

### 随包数值例：民生银行2025年

原始来源：[2025年报](https://ir.cmbc.com.cn/media/ivmptvr1/%E4%B8%AD%E5%9B%BD%E6%B0%91%E7%94%9F%E9%93%B6%E8%A1%8C2025%E5%B9%B4%E5%B9%B4%E5%BA%A6%E6%8A%A5%E5%91%8A.pdf)。报告期2025-01-01至12-31，批准日2026-03-30（PDF第2页），取得日2026-10-02；首次披露日未单独核实，不用于当时可知信息回测。下列金额均人民币百万元；经营/贷款为集团，资本为监管并表集团。

1. **利润（印刷28页/PDF第30页）：** 收入142,865减业务及管理费51,006、税金及附加1,701及其他业务成本2,604，得本例自定义减值前营业利润87,554；扣信用减值53,950、其他减值761、营业外净支出584、所得税1,677，得集团净利润30,582；扣少数损益19得归母30,563。逐步桥残差0；小计定义随式保存，不冒称所有机构通用指标。
2. **准备（印刷41页/PDF第43页）：** 期初93,129加净计提47,901，减核销转出52,477，加已核销回收7,759、其他−2,346，得期末93,966，残差0。附注印刷196页/PDF第198页把后两项合列5,413，`7,759−2,346=5,413`，不得重复计入。准备仅净增837，不代表当年信用成本837。
3. **资产质量（印刷37页/PDF第39页）：** 贷款毛额4,430,610、不良66,154、关注121,195；不良率`66,154/4,430,610=1.4931%`、关注率2.7354%、准备覆盖`93,966/66,154=142.0413%`。这些分类不能自动映射Stage 2/3。
4. **资本（印刷41页）：** CET1净额563,554、RWA6,011,048，复算9.3753%，原表9.38%；上年分别546,689、5,842,716。按B4的固定顺序，资本金额贡献+0.288650个百分点，RWA贡献−0.270108个百分点，合计+0.018542个百分点。资本额增加几乎被分母增长抵消；原因仍需第三支柱的量/组合/方法桥。
5. **流动性（印刷42页/PDF第44页）：** HQLA958,739除30天净流出707,036得135.5997%，原表135.60%；两者差251,703属于监管加权口径差额，不是自由现金，不能直接支付任意债务。
6. **结论与反证：** 以上证明取数勾稽和算术；未证明准备充分、存款稳定或资本在压力下足够。主动补拨可能改善未来韧性，RWA上升也可能来自模型/范围变化，均需保留替代解释。
7. **继续执行：** 向风险/财务请求分阶段迁徙、SICR/PD/LGD/EAD及overlay、核销回收台账；从第三支柱取资本扣减/RWA变动；向资金部门取客户集中、HQLA质押和日度现金梯级。先执行B3/B4/B6可得步骤，把未取得项标为awaiting_data；独立人员从原页重取最大变动与一项反常项，不能仅复核本例相加。

## 银行：B1 → B5 → B3/B2 → B4 → B6/B7 → B8

### B1 经营环境、商业模式与暴露

1. 从分部、贷款行业/地区、证券投资、存款客户和同业业务取规模、收入、风险暴露；对分部合计与报表差额记录内部抵销。
2. 建“环境变量—暴露—传导”表：例如当地房地产销售下降→开发贷现金回款/抵押品→违约迁徙与LGD→ECL及资本。行业和地域重叠项不能相加为总风险。
3. 计算同范围业务增速、份额、集中度；把量增与定价、客户风险变化并列。集中度的分母写明贷款、信用风险暴露或收入，不能互换。

**反证与补证：** 收入增长同时信用成本上升、单一政策客户依赖或低价吸存，均挑战“竞争力增强”。向业务/风险负责人索取前十大关联集团、行业迁徙和客户分层定价，公开资料缺失时只判断可见集中度。**产品/复核：** 暴露传导表；复核人选最大暴露重追来源，并检验同一冲击是否在利润、准备和资本中重复计损。

### B5 量价、拨备前利润与成长质量

1. 从平均余额/收益率表复算`利息净收入=利息收入−利息支出`、`净息差=利息净收入/同口径平均生息资产`。年内口径按实际天数年化；优先用已披露日均/月均余额，不静默用期初期末均值代替。
2. 对每类资产或负债，使用未舍入隐含收益率`r=利息/平均余额`。按固定顺序分解`Δ利息=(V1−V0)×r0+V1×(r1−r0)`；负债支出在净利息收入桥取负号。该顺序分配交互项，必须披露，不能声称唯一归因。
3. 从收入逐项扣业务费用、税金、其他经营成本，得到自定义且明确命名的“减值前营业利润”；再扣信用/其他减值，加营业外，扣所得税，核对净利润及少数股东损益。
4. 将手续费、投资损益、资产出售、税项和拨备转回单列。只有能够证明金额及税影响时才给可比调整；同时保留报告利润，不把“经调整”当事实替代。

**反证与补证：** 收入增长可能来自卖债或更高风险承受，利润减少可能来自主动补拨。索取产品定价、新客账龄、贷款批次损失和费用归属；缺失则不能断言新增业务已经成熟盈利。**产品/复核：** 量价桥、拨备前至归母利润桥；复核人用未调整利润表闭合，再挑战最大调整。

### B3 准备滚动与ECL

1. 先按贷款/债券/同业/表外承诺分别勾稽：`期末准备=期初准备+当期净计提−核销及转出+直接进入准备的回收±其他`。符号及回收记账位置以原表为准；有的回收进损益，不能再加一次。总准备与摊余成本贷款抵减项存在FVOCI、应计利息或范围差别时另做桥。
2. 按Stage 1/2/3分别计算`准备/对应账面毛额`及阶段占比；以当期同类资产净计提/平均同类资产毛额计算信用成本。期末准备增减不是信用成本。不良覆盖率使用匹配的贷款准备和不良贷款余额。
3. 取得模型后，固定资产池和情景，区分规模、阶段迁徙、参数、情景权重、管理层叠加、核销回收及汇率影响。逐笔ECL可按`Σ情景权重×Σ时间段[边际违约概率×EAD×LGD×贴现因子]`重算；若输入是条件PD，先乘存活概率，不能把各年累计PD直接相加。
4. Stage 1限制的是未来12个月内可能发生的违约事件，事件引起的现金短缺仍涉及整个存续期；Stage 2使用存续期，Stage 3按适用政策核对现金流短缺与贴现。POCI等特殊资产另按准则处理。验证原始/适用实际利率、担保回收时点、抵押处置费用与实现概率；同一风险不得同时计入模型和overlay。
5. 只有汇总公开表时，执行滚动、覆盖、方向一致性及情景挑战，结论标为“公开数据合理性分析”，不能写“模型验证完成”或“准备充足”。

**反证与补证：** 经济恶化而Stage 2下降、叠加大额转回、抵押估值过旧均需追加。向风险模型/财务索取SICR规则、迁徙矩阵、PD/LGD/EAD期限结构、情景权重、回收台账及overlay批准记录。**产品/复核：** 准备桥和参数归因表；复核人从毛额和模型输入独立选取重大样本重算，不能只复核公式相加。

### B2 资产质量、分类与处置

1. 各建五级分类、阶段分类、逾期天数表，分别核对总额。正常贷款可能包含正常类及关注类；不能按表面名称重复相加。
2. 复算`不良率=(次级+可疑+损失)/贷款毛额`。列关注、90天以上逾期、重组/展期/无还本续贷，各自有范围与重叠标记。
3. 有迁徙台账时做`期末不良=期初+新形成+购入/范围变化−现金收回−核销−转让−上调±其他`；只有净余额时不反推“新生成不良”。对转让核查价格、追索、继续涉入，核销不代表借款人风险消失。
4. 只有逐笔ID或可核对的交叉披露时，才把Stage 2/3与关注/不良/逾期交叉。按同一借款集团聚合表内外信用资产，检查不良是否藏在债权投资、资管计划或应收款。

**反证与补证：** 分母快增或核销可降低不良率；还款来自新增借款不证明偿债改善。索取逾期合同、重组前后偿付计划、转让回款及期后履约，追最大异常资产池。**产品/复核：** 分类差异表、不良形成处置桥；复核人重算比率，选一笔跨分类和一笔核销/转让回穿合同及现金。

### B4 会计权益、监管资本与RWA

1. 从权益至监管资本逐项列普通股/留存、OCI、少数股东、商誉/递延税等扣减、其他一级及二级工具；记录监管并表与会计并表差别。账面“其他权益工具”不自动是CET1。
2. 分信用、市场、操作风险核对RWA，复算CET1、一级、总资本比率及监管杠杆率。对两期资本率`c=K/R`，精确分解`Δc=(K1−K0)/R0+K1×(1/R1−1/R0)`；前者资本金额贡献，后者分母贡献，尚不等于业务量/模型变化的进一步归因。
3. 向第三支柱取RWA变化来源、风险权重/内部模型、过渡安排。用同实体、同日期、已核实的总要求`h`计算金额余量`K−h×RWA`，分别处理各层资本约束；不抄固定监管红线，也不将一个资本层级余量代表所有约束。
4. 压力中先把减值、市场/OCI、税与监管扣除传至资本，再按风险迁徙、规模和适用权重重算RWA。分红、资本发行、到期减额逐项进入；未批准或未到账的资本措施另列条件情景。最后算各资本率、金额余量与约束最紧项。

**反证与补证：** 比率上升可由低RWA资产替换、模型变化或其他一级工具驱动，未必由核心留存增强。索取RWA桥、ICAAP、发行到账及分红计划；没有参数只给静态敏感性，不能称完整监管压力测试。**产品/复核：** 权益—资本—RWA—压力桥；复核人移除未落实措施重算，检查资本损失与ECL是否重复。

### B6 资金来源、流动性与可融资性

1. 复算LCR的HQLA/净流出、NSFR的可用/所需稳定资金；两者口径直接来自适用披露。先区分期末比率、日比率的简单平均、平均分子除平均分母，后三者通常不相等；平均LCR需要匹配日序列才能闭合，不能把差异判为错报或倒填“其他”。监管加权金额、会计余额及无条件可用现金分列。
2. 按法律实体、币种和日内/日/周/月建立来源用途表。存款按保险覆盖、客户集中、期限、渠道与价格敏感度分组；债券、同业存单、回购及同业拆借逐笔记录到期和续作条件。
3. 每一期间计算`期末可用现金=期初+可靠流入+该期可执行融资−到期付款−流失−保证金/承诺提用`。资产出售/质押融资扣处置折价、已有质押和执行时滞；同一资产只选一种资金来源。生存期是首次可用余额为负的时点，并同时报告最小余额。
4. 压力设定需有历史流失、客户结构、合同或监管依据，显示基础/压力的变化原因；信用额度按承诺性、先决条件及提供方相关风险筛选，跨币种换汇也需可执行。

**反证与补证：** 高期末LCR不能否定日内、单币种或大客户提款缺口。索取日度峰值、前十大存款、抵押资产台账和备用额度合同。**产品/复核：** 时间阶梯与应急动作表；复核人检查最大流入是否可在付款前到账，并删除重复担保品。

### B7 IRRBB、债券浮亏与ALM

1. 从第三支柱分别取ΔEVE、ΔNII，写明币种、曲线、冲击、期限、是否静态资产负债及行为假设；2026国际参数须先确认本地实施和报告期适用性。
2. 取得重定价现金流后按情景重新折现资产/负债及表外现金流，算`ΔEVE=EVE压力−EVE基准`；按约定预测窗口逐期重算利息收付，算ΔNII。无现金流时使用原披露敏感性，不用总资产×利率变化伪造结果。
3. 分AC/FVOCI/FVTPL及套保，将价值变化映射至损益、OCI、资本和抵押/被迫售损。存款beta、提前还款与无到期存款行为期限各做可解释改变；不要把ΔEVE与当期会计亏损相加。

**反证与补证：** AC未实现亏损不入当期损益仍可影响变现；历史存款稳定不保证未来beta。索取重定价梯级、提前还款/存款回测及套保有效性。**产品/复核：** EVE/NII与现金联动表；复核人验证冲击符号、对冲边界和行为假设，VaR不能替代该程序。

### B8 自身实力、支持与债项层级

1. 先汇总B1–B7形成自身偿债能力判断，再分别取支持方的能力、意愿、历史行为、合同及制度。持股比例、系统重要性或名称均不是自动支持承诺。
2. 逐项读取存款、优先债、处置债、T2/AT1条款，登记发行主体、清偿顺位、担保覆盖、减记/转股触发、利息取消/递延、赎回批准和法定到期。
3. 如需对标某机构，锁定该机构在该行动日适用的完整方法，从其自身评估到支持、主体、债项依次解释；不可拼接S&P的资本指标、Moody’s的支持框架和Fitch的级差生成自有评级。

**反证与补证：** 救机构可能不保护资本工具；首个赎回日不是到期。索取正式支持/保证及最终发行条款，缺失就保留支持或债项判断条件。**产品/复核：** 实体—债项责任表；复核人逐条定位合同，不能沿用别行固定级差。

## 保险：业务 → 合同负债/利润 → 资本 → ALM/再保/流动性 → 责任层级

### I1 新业务、续期与风险价格

1. 寿险按产品/渠道取新单、续期、趸交/期交、继续率、退保、保证和分红条款；保费现金、保险服务收入、APE、NBV、新业务CSM各立定义及计算范围。财险/再保按险种取暴露量、单价、条款、限额和分出比例。
2. 同口径拆规模变化和价格/结构变化；新业务利润率只用发行人定义的分子分母。将增长同获取成本、保证成本、新业务资本耗用及客户留存配对；不能把NBV计入会计利润。

**反证与补证：** 趸交冲量、低价承保或高佣金可带来规模而非价值。索取保单批次、续期现金及定价利润测试；缺失时把“增长”与“成长质量未验证”分别写。**产品/复核：** 产品/渠道增长收益表；复核人在一产品上重算量价/利润率并核对定义。

### I2 准备、CSM、服务与金融损益

1. 确认适用CAS/IFRS 17或其他准则及过渡方法，按GMM/VFA/PAA、原保险/持有再保险、剩余保障/已发生赔款分表。PAA及不适用该准则的业务不能强造CSM。
2. 使用合同组原始调节表：`期末CSM=期初+新增+利息±未来服务估计/适用金融变动±汇兑/转入−服务释放`；亏损合同的损失组成部分、风险调整RA、履约现金流另滚动。不能把所有估计变动都归为未来服务，VFA与GMM处理需按政策辨认。
3. 核对CSM释放的保障单位、当期服务量和未来服务期间；若只知道释放/摊销前CSM，可给描述性释放率，不能反推所有合同组实际摊销因子。
4. 将保险服务收入、服务费用、再保险净结果连接服务业绩，再单列保险金融损益、对应投资损益与OCI、其他收入费用和税，勾稽净利润。投资成分不作为保险服务收入；服务费用之差不自动等于最终保险服务结果。
5. 向精算取得现金流/折现/死亡疾病发生/退保/费用/赔款通胀假设和经验分析，分假设改变、经验偏差、亏损合同和RA释放。无合同现金流时只完成桥和方向挑战，不能确认准备充分。

**反证与补证：** CSM增减可能由金融假设、汇兑或收购驱动；CSM不是现金或可直接分配权益。**产品/复核：** 合同负债与CSM桥、服务/投资/金融利润桥；复核人检查一合同组的释放和负债滚动及最大假设变动，不能只看总额闭合。

### I3 财险/再保承保与赔款发展

1. 分事故年/日历年、毛额/净额、险种和长短尾建立已付/已发生赔款三角；把最新对角线与赔款准备/已付余额核对，记录收购、汇率、再分类。
2. 仅在费用率、赔付率同范围同分母时复算综合成本率；拆本事故年、往年准备金发展及巨灾贡献。保险服务费用/保险服务收入通常不能替代披露综合成本率。
3. 数据适用时以累计赔款`C(i,j)`计算量加权发展因子`f(j)=ΣC(i,j+1)/ΣC(i,j)`，各和使用相同事故年；逐步推终极赔款，`未付准备=终极赔款−累计已付`。已发生三角与已付三角不能混算；不稳定业务、结构变化、负发展、稀疏巨灾或长尾需要另择方法与专家判断，不能默认链梯法适用。
4. 尾部因子、通胀和大案按证据设敏感性；将估计区间与已计准备比较，解释方法与参数不确定性，不能将单一差额直接确认为会计少提。

**反证与补证：** 较低成本率可能依赖往年释放或有利再保。索取事故年三角、大案清单、结案速度和司法变化。**产品/复核：** 承保归因与赔款发展底稿；复核人用相同数据独立重算因子，并挑战尾部/业务稳定性。

### I4 核心资本、综合资本与最低资本

1. 从同实体偿付报告取核心资本、实际/综合资本、最低资本及风险类别，与会计权益做准则、估值、限额、工具和扣除桥。
2. 复算适用的核心/综合充足率；按原制度核对最低资本聚合、分散效应和控制风险调整，不把各项资本简单相加替代监管公式。
3. 把新业务、留存利润、分红、利率/市场、信用、再保、工具和过渡政策分别传导至分子和分母，再算压力比率及金额余量。只拥有敏感性时报告局部冲击范围，不假称整体ORSA。

**反证与补证：** 比率改善可能依靠资本债、过渡安排或最低资本下降。索取偿付资本明细、ORSA/计划及下拨限制。**产品/复核：** 权益—资本—最低资本桥；复核人排除未落地措施、核对受限性。监管风险综合评级“BB”等是另一体系，不作为外部信用级别。

### I5 投资与资产负债匹配

1. 分保险人承担/保户承担投资风险的账户取投资、信用等级、期限、币种、流动性、关联/另类及估值层次，核对穿透后暴露与账面额，未知穿透部分保留未知。
2. 与保证、分红、满期、赔付及保单选择权现金流配对。先做逐期现金流缺口，再用同口径资产/负债价值与久期分析；线性近似`Δ净值≈−DA×VA×Δy+DL×VL×Δy`仅用于小幅平行利率敏感性，不适用非线性选择权、曲线变化或不匹配口径。
3. 一致情景分别计算投资损益、OCI、保险金融损益/OCI及监管资本变化；把对冲追加担保品需求送入I7，不能把账面盈利当现金。

**反证与补证：** 久期相近仍可能现金时点/币种错配。索取资产穿透、负债现金流、套保及保证收益测试。**产品/复核：** 投资暴露与ALM双视角表；复核人追最大集中和最大不匹配，检查同一损失不会重复入资本。

### I6 再保险的实际风险转移

1. 将毛承保风险、分出条约、再保险资产/负债、净暴露逐项连接；再保佣金、摊回赔款及持有再保CSM按适用政策单列，不从原保险负债随意净掉。
2. 对重大条约读取免赔、限额、除外、复效保费、经验账户、追索/recapture、抵押及争议条款，计算`可摊回=按条约约定作用于各次/累计损失的赔付`，按层扣免赔和限额，而非统一损失×分保比例。
3. 检查再保应收账龄、对手集中、信用损失及抵押可用性；分别设置对手不履约和回款延迟，重算净损失、资本和现金。资产密集型/关联再保核对资产控制及撤回风险。

**反证与补证：** 降低账面资本耗用不证明经济风险已转出。索取原条约及结算/抵押证明；没有条约不确认压力时可回收金额。**产品/复核：** 毛—分出—净损失及回款桥；复核人挑一个大赔案逐层重做，检查同向风险。

### I7 退保、满期、巨灾与现金生存期

1. 寿险从保单现金价值和满期分布估算退保/保单贷款现金需求，财险/再保从大案、巨灾付款曲线及摊回时滞取用途；赔付准备账面额不等于本期现金付款。
2. 按实体、币种、时间段使用B6的现金余额递推；把资产折价、衍生品保证金和I6回款压力同步加入。退保冲击先验证适用保单群、现金价值和基准行为，不能对全部负债任乘统一退保率。
3. 将最小现金余额、首次缺口与可执行资产出售/融资/业务措施并列；偿付能力充足不是现金测试的结论。

**反证与补证：** 利率上升可同时引发退保和债券浮亏，巨灾付款可能先于再保。索取现金价值群组、支付峰值和回款历史。**产品/复核：** 现金阶梯；复核人检查回收先后与资产重复融资。

### I8 保单责任、主体与资本工具

1. 把保单履约能力、经营公司发行人、控股公司发行人和次级资本债分开；读取保户保护/清偿规则、上游分红及资本限制。
2. 对资本工具列法定到期、首赎、利息递延/取消、减记、次级性、担保和赎回条件；股东支持先验证能力与意愿，不能用集团标识替代。

**反证与补证：** 保户优先保护可削弱普通/次级债回收，子公司盈利未必可上划。索取条款和分红批准；缺乏法律意见时限制顺位判断。**产品/复核：** 实体责任和现金上划表；复核人核条款与适用法域，不将偿付率直接映射评级。

## 证券与资管：客户边界 → 盈利 → 交易风险 → 资本和现金

### S1 客户资金、受托资产与自有资产

1. 从客户银行存款、结算备付金、保证金、代理买卖证券款、应付客户结算款与基金合并附注建立权属表；分别列“谁拥有、谁可用、用途限制、对应负债、托管/存管方”。
2. 先算自有与非自有资产负债的报告口径桥，再用同客户群、同币种、同时点存管对账，核`客户权属资产及合法在途项目−对应客户义务`。相关附注不齐时不能以两个总科目之差断言挪用或安全。
3. 自有流动性扣全部客户/受托及受限款；客户证券借贷、抵押和合并基金逐项读取合同和控制依据。不能用客户现金冲减公司债务。

**反证与补证：** 看似净现金可能来自客户交易高峰；净额科目可能隐藏在途差。索取存管确认、客户分类账、未达账和期后清算。**产品/复核：** 权属/可用资金桥；复核人双向追客户总账与银行/结算机构证据，公开披露不足就保留未核对结论。

### S5 收入质量与资本效率

1. 将经纪、投行、资管、自营和利息业务分开；按成交额×净费率、平均收费资产×费率、平均融资余额×净息差解释收入。注意商品贸易等低毛利总额收入，不能直接用总收入比较券商规模。
2. 自营实现/未实现及一次性处置分列；费用按可变与固定证据拆分，核对分部抵销和集团净利润。
3. 将增长同自有头寸、融资、净资本耗用配对；只有分部资本分配方法可验证时计算分部资本回报，不自造分母。

**反证与补证：** 市场上涨、并购或业务出售可改变同比；收入增速快于资本不必然提高风险调整回报。索取量价、项目确认及资本分配。**产品/复核：** 收入和资本效率桥；复核人挑战最大一次性项目及合并范围变更。

### S2 融资融券、回购与衍生品保证金

1. 逐对手/净额协议连接融出、买入返售、借券、卖出回购、衍生品、质押/再质押与到期。名义本金、会计公允价值和信用暴露分别列示。
2. 回购/逆回购根据实际抵押条款算合格抵押价值`Σ市场价值×(1−适用折扣)`；融出风险与折扣后担保差额分列，净额仅在法律和操作均可执行时适用。
3. 压力同时冲击担保品价格、折扣和续作。融资追加担保品/现金需求按合同重算；衍生品按CSA的门槛、最低转移额、初始/变动保证金和结算时点计算，不拿名义本金直接算损失。

**反证与补证：** 高质量国债仍有折扣上升、期限错配；对手和抵押物可同向恶化。索取CSA、净额法律意见和逐笔头寸。**产品/复核：** 交易—抵押—融资联表；复核人追单一最大对手的毛额、净额、担保及现金路径。

### S3 市场风险、估值与尾部

1. 按利率、信用利差、权益、汇率和波动因子归因；区分方向、做市、套利及对冲。将VaR日期、置信度、窗口、持有期和回测异常随数值保存，不能跨定义排名。
2. 有风险敏感度时按其单位和定义计算，如DV01/CS01以每1bp计，冲击必须用bp且核符号；非线性期权用重估或注明有效范围的delta/gamma近似，不把名义本金替代敏感度。
3. 对集中、拥挤、基差失效和不可快速变现头寸追加一致压力，另列第三层次估值、不可观察参数和报价时效；对冲只有在同一情景下才能抵减。

**反证与补证：** 低VaR或期末轻仓不证明尾部风险低。索取年内峰值、回测、限额超标及模型独立验证。**产品/复核：** 因子损失与估值不确定性表；复核人核敏感度单位、符号及对冲两端。

### S4 净资本、杠杆与流动性

1. 从同牌照监管表复算`净资本=核心净资本+附属净资本`、`风险覆盖率=净资本/风险资本准备合计`等适用指标。资本杠杆率分母须取监管调整后的表内外资产，不可用集团总资产反推。
2. 将净资产至核心/附属净资本扣减、次级工具合格性与业务风险资本准备变化列桥；同时对集团自有债务期限和资金可转移性做独立表。
3. 由S2/S3的损失与抵押需求重算自有净资产、监管扣减及风险资本准备，再执行现金阶梯。规则/阈值须按时点和类别核实，2025执行的新计算标准不能倒套2024指标。

**反证与补证：** 次级资本增加可抬净资本但核心资本不变；季末压表可美化比率。索取监管计算表、日度峰值、受限头寸和融资合同。**产品/复核：** 净资本与现金双桥；复核人确认母公司/合并边界并排除客户资金。

### S6 资管人专用程序

1. 建`期末AUM=期初+净流入+市场变动+汇率+并购/其他`桥；收费AUM与非收费AUM、管理和顾问资产分列，未披露净流入不得从两期AUM直接推算。
2. 用同口径平均收费资产和管理费算隐含费率，业绩费按确认/回拨及高水位另析；拆客户、产品、分销和到期集中。
3. 产品赎回/资产变现问题先作用于产品，再据种子资本、担保、流动性支持、回购及赔偿承诺识别管理人现金/资本责任。基金杠杆不是自动等于管理人债务。

**反证与补证：** 行情推高AUM可掩盖净流出；业绩费不具稳定性。索取流量桥、费率合同、赎回及支持承诺。**产品/复核：** AUM—收费—管理人责任桥；复核人追一大客户和一项表外承诺。

### S7 许可、治理、合规与支持

1. 从最终处罚/诉讼/业务限制和年报事件识别生效日、责任主体、受影响业务与整改；将事件转成潜在赔偿、客户流失、融资或资本需求，已确认拨备与未决风险分开。
2. 小额罚款不能替代对系统性客户资产或销售控制缺陷的分析；支持按能力、意愿及可转移资源验证，不能仅看国有股东。

**反证与补证：** 事件已整改、诉讼撤回或客户留存可以削弱最初负面判断，应主动查期后。索取最终文书与整改证据。**产品/复核：** 事件传导及支持表；复核人区分事实、指控、情景和已发生损失。

## FMI：公司经营与清算资源分别计算

### F1 业务地位与收入

1. 分交易、清算、存管、数据/指数取量、费率、未平仓量和收入；核清算投资收益中归会员与归公司的分配，只有公司保留部分进入经营分析。
2. 将经常订阅与交易周期收入、产品/会员集中、替代场所和技术支出连接经营利润与公司自由现金流；并购债务按公司融资分析，不把会员往来作为普通营运资本。

**反证与补证：** 波动带来的量增可掩盖份额下降或收费压力。索取分产品量价、客户流失及收入分配。**产品/复核：** 量价与公司现金流桥；复核人检查会员本金和交易配对资产未进入公司盈利/自由现金。

### F4 公司资产、会员资金与用途受限资源

1. 按公司运营现金、初始保证金、变动保证金、违约基金、会员结算款列权属、资产形式、对应义务、法律实体、币种、使用条件及可用时点。
2. 复算清算资产/负债及各分项；配对交易余额可相等，但其他净差额仍需解释。账面差额不是自动损失或资金挪用证据。
3. 从公司现金扣法定/合同/监管受限、质押和不能上划部分，才得到可用于公司债务的现金。用于某CCP服务的资本和会员担保品均不能跨用途自由调用。

**反证与补证：** 合并现金高可能主要是会员款；净现金计算会被夸大。索取清算账、结算在途、银行/托管确认及资金用途法律依据。**产品/复核：** 会计余额—权属—偿债可用额桥；复核人逐项找资产对应责任，不允许用保证金消除公司债务。

### F2 服务级违约瀑布：先定义损失，再逐层消耗

1. 从同日规则簿和PFMI披露建立每个服务的真实顺序、币种、金额及触发条件。示意层可能为违约成员保证金→其违约基金缴款→CCP自有专用资本→存续成员基金→追缴/恢复工具，但生产顺序必须服从实际规则。
2. 定义`L0`为该情景的平仓/拍卖损失及适用成本，说明是否已经扣除保证金。若披露的是“超过保证金的压力损失”，从下一层开始，不能再扣保证金；违约成员基金已含在总基金内时，从可用共同基金扣除该成员份额，避免重复。
3. 对每层可用资源`Rk`递推：`本层使用Uk=min(max(L(k−1),0),Rk)`；`剩余损失Lk=max(L(k−1)−Uk,0)`。资源先按合同权利、抵押折扣、可变现性及同日汇率调整。各服务分别算，不能将不同服务或币种余额直接相加作为可互用资源。
4. 已缴资源与未缴追缴、损失分摊/VM减记、终止服务分别列；后者是恢复措施，不自动视为初始可用现金。结合相关成员同时违约、抵押物同向风险及市场深度重算。
5. 输出“层/原金额/资格调整/可用金额/使用/剩余/时点/法律依据”。缺成员损失、保证金、其基金份额或汇率时保留变量和请求，停止给覆盖倍数；仍可完成公开资源与顺位核验。

**反证与补证：** 大额担保品总数不代表服务级压力覆盖；Cover 1/2按适用制度与CCP类型确认，不固定为一个通用阈值。索取同日定量披露、成员压力损失、集中/流动性折扣及规则版本。**产品/复核：** 实际规则驱动的瀑布；复核人选一个情景逐层消耗，查重复基金和跨服务误用。

### F3 日内、币种与结算流动性

1. 将F2信用损失另置；按支付币种、结算窗口记录到期义务与可收资金，信用资源足够不代表能按时付款。
2. 用时间递推现金余额，压力包含会员违约、VM峰值、结算银行不可用、抵押品变现/外汇兑换延迟。额度提供方也是潜在违约成员时联动失效，不能当独立缓释。
3. 分别报告日内最低余额、峰值支付、合格流动资源、到账时间及替代通道。年度/季度最大值不同日发生时不能拼成一个未经说明的联合情景。

**反证与补证：** 基金债券未必能在付款前变现，央行安排可能有资格条件。索取支付日志、承诺额度合同及演练。**产品/复核：** 币种/时点现金表；复核人按真实到账时间重排，不能把恢复工具算即时现金。

### F5 模型、运行、恢复与反向压力

1. 取得保证金模型回测、压力模型验证、拍卖/违约管理和灾备演练；区分设计文件、执行记录、异常和整改关闭。
2. 从F2/F3寻找令资源首次不足的可解释组合：成员损失、抵押折扣、市场深度或支付延迟。反向压力是边界条件，不是估计发生概率；不可用历史零违约给出安全结论。
3. 把系统/网络/外包中断连接错过支付、违约处置失败、赔偿及客户流失，记录恢复步骤、责任人与实现时限。仅有制度则结论为设计已披露、运行有效性未验证。

**反证与补证：** 最近真实演练成功或失败与整改均可改变判断。索取独立验证、事件复盘及整改证据。**产品/复核：** 异常—现金/资本传导与恢复任务表；复核人重走一个失败路径及一项整改关闭。

## 写入共享底稿和交付

基础求和、差额、比率、量价乘积与滚动桥可用共享`workpaper.py`/`calculate.py`，把原事实、计算定义、期间规则、来源定位、判断、反证、追加程序和资料请求分别保存。百分数与小数选择一种内部口径并显式显示倍率，bp与百分点不得混用；金额先统一币种与倍率。

共享基础算术不能自动执行逐笔ECL期限结构、合同组CSM、非线性重估、日内现金调度或规则簿瀑布。上述任务应附可重做的专用表/计算步骤、来源和执行记录；未经实际执行的程序保留planned/awaiting_data/limited及原因。不要把人工专业模型的输出伪装成共享脚本已经验证的结果。

交付至少保留本次适用业务的：经营及盈利桥、关键准备/资本桥、资源权属与现金压力、支持/债项责任、影响结论的缺证清单。每个重大结论附能推翻它的证据条件。复核时重取最大风险项和一项反常项，核来源、边界、算式及解释；复算通过只说明该算式/勾稽成立，不证明信用安全、模型校准或全部行业参数已覆盖。
