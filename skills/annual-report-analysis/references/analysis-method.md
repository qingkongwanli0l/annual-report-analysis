# 从年报形成有证据的判断

按用户问题选择深度，不为了填满模板制造结论。默认兼顾投研与财会：解释经营驱动，同时展示口径、勾稽与证据。

## 阅读与比较

先建立公司业务、主要客户和产品、收入模式、竞争位置及报告范围。结合本期与可比期读管理层讨论、分部披露和相关附注。已有三年及以上可靠数据时可分析较长趋势；只有两年就只作两年比较。

同业比较只在用户需要且拿到一致口径数据时开展。不能为了给公司打分任意选择同业、虚构行业均值或用不同财年与准则混算。

## 非金融企业的重点问题

| 主题 | 需要回答的问题 | 主要证据 |
| --- | --- | --- |
| 经营与增长 | 增长来自量价、产品结构、并购还是汇率？ | 业务与分部披露、收购及合并范围附注 |
| 盈利质量 | 利润变化来自主业、费用、补贴、投资收益还是减值？ | 利润表及收入、成本、费用、非经常性损益附注 |
| 利润与现金 | 应收、存货、预收或付款节奏如何影响现金？ | 现金流量表、补充资料、营运资本附注 |
| 资产质量 | 应收回收、存货变现、商誉及长期资产减值假设是否有变化？ | 账龄、减值政策、重要估计与减值测试 |
| 偿债与流动性 | 近期到期债务、可用现金、授信和契约条件如何？ | 借款、受限资金、租赁、担保和承诺附注 |
| 资本配置 | 资本开支、收购、分红及融资与经营能力是否匹配？ | 投资/筹资现金流、权益变动和分配方案 |
| 治理与风险 | 关联交易、集中度、诉讼、会计变更与审计关注有何变化？ | 关联方、或有事项、审计报告及更正公告 |

毛利率、净利率、现金转化、周转和 ROA/ROE 的定义以计算底稿为准。自由现金流仅表示所声明的 `经营现金流 − 资本开支` 分析口径；资本开支包含购建固定资产、无形资产等支付的现金，不默认为包括收购或金融投资。

应收周转天数以全年收入作为赊销收入代理时，要说明这一限制；不同销售模式不作机械比较。存货和应收异常须结合业务节奏、合并范围、会计政策和减值变化解释。

## 结论如何落地

每个重要结论采用“观察 → 证据 → 含义 → 局限/待核实问题”的顺序。用具体数值和原文定位支持关键变化；若没有足够依据就提出问题，不填造因果。

- 披露事实：注明报表/附注位置，可由读者复核。
- 管理层解释：明确这是管理层的说法，并核对数据是否支持。
- 分析推断：说明假设、证据及其他可能解释；区分“风险信号”与“已经发生的损失”。

不要把经营现金流持续偏低、关联交易增加或审计关注自动判断为舞弊；也不要把一项勾稽通过或无保留意见当成没有风险。

## 三种文件共享同一底稿

- Word：主要发现、经营与财务分析、会计事项、问题清单、来源与限制。
- Excel：原始事实、标准化值、可追溯公式、勾稽结果与缺失原因；便于复算。
- PPT：从相同已验证结论中提炼重点，保留关键图表/表格、来源及限制。

三个格式是同一份分析的不同呈现，不是各自生成一套数字。用户追问或更新数据时修改底稿并重新计算、导出，避免手工分别改三份文档。
