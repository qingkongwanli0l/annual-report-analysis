# S&P 企业财务口径与调整工作

在选用 S&P 工商企业形成路径、需要跨准则可比或分析含下列交易的企业时读取。本参考用于建立调整底稿；财务报告仍按企业实际准则保留原值。调整指标不等于法定报表更正、合同契约指标或可立即支付的现金。

依据为 [Corporate Methodology: Ratios And Adjustments](https://www.maalot.co.il/Publications/MT20251223092257.pdf)，2019-04-01 原发、2025-12-17 非重大重发，58页；下列页码为PDF物理页，与印刷页一致。行业、混合资本、控制股东融资、集团及产业内金融的依赖方法须按任务取得并核对在用版本。主方法适用对象见¶2；不能给项目融资和企业证券化直接套此表。

## 1. 从实际事项建立调整底稿

先按实际经营、交易、合并范围及附注检索本参考的适用项，不把调整事项的名称当成已执行程序。每项沿用共同底稿记录：原数及位置、实体/期间、账内或表外、调整触发证据、未计入部分、税与现金时间、调整后数、反方及未决资料。重要的合并范围变化要同时改债务、资产、盈利、现金和内部往来。

¶23–25限制非经常/备考加回的使用。并购年度债务为全年而利润仅含并购后月份时，另做有原始报表支持的全年备考；不把未实现协同和管理层所有“一次性费用”塞进历史 EBITDA。终止经营利润及现金从持续经营趋势中剥离，真实处置现金仍进实际支付预算。

¶31–35的“clearly trivial”预期对有关指标影响低于1%，须同时看汇总效果；¶50–58的情境调整通常以例行调整后的历史指标为基准，超过10%是指引，非硬开关。小于10%但可改变财务档、展望阈值或未来迅速放大时仍要处理；净债接近零时百分比可能夸大意义。无法可靠量化的风险改以明确的情景或方法调整分析，不重复算在财务和定性因素里，也不编造精确负债。

¶35允许在例行调整所需资料不完整时，以分析判断选择补取资料或采用有依据的最佳估计。先区分不适用、已披露值、方法代理和分析估计：只对实际触发事项保留具体差额，以其对相关指标和临界结论的影响决定是否继续取证；可给出注明依据的指标估计及敏感性，不将它冒称报表事实或机构已发布指标，也不因少量未决明细搁置已可完成的分析。

## 2. 先锁定指标，不从同名字段直接搬数

用p2–3、14–17分别建立以下桥，所有加减先核是否已在起点包含：

| 指标 | 底稿实施 |
|---|---|
| 调整债务 | 从逐笔金融债务出发，接租赁、退休/恢复义务、融资交易等适用项，再扣本方法认可的现金；现金抵扣条件见第3节。计量原则为摊余成本，含累积PIK；公允值及或有对价有专门分支。 |
| EBIT、EBITDA | 分别计算。EBIT包括相关权益法收益、利息收入和其他经常非经营项；EBITDA以经营活动为基础，权益法被投资企业改用实收股利、非流动资产减值/转回和股份结算报酬另处理。不能仅用EBIT加全部D&A得到未经解释的S&P EBITDA。 |
| FFO | 从调整EBITDA扣调整现金利息与实际现金所得税；另接行业专属例外。与报表CFO扣营运资本所得的数核差，但不将两者默认为相同。 |
| CFO、FOCF、DCF | 先把收取利息/股利、支付利息及现金所得税归入该方法CFO，再作具体交易的现金分类调整；FOCF=`调整CFO−调整capex`；DCF再扣现金股利（含合并子公司向少数股东分配）和回购。并购现金、偿债、租赁本金及可用性另在支付预算中完整保留。 |
| 应计利息、现金利息 | 应计口径含尚未进入起点的费用化/资本化利息、发行折价/费用摊销、PIK、租赁/退休/恢复义务利息及已实现利率套保；未实现利率衍生品估值另剔除。普通存款利息不冲减应计利息。现金口径独立取实际支付及规定的租赁/混合代理，不将所有应计利息当已支付。 |
| 覆盖与回报 | EBITDA/应计利息；`(FFO+调整现金利息)/调整现金利息`；FFO/债务、CFO/债务、FOCF/债务、DCF/债务分别列。ROC按EBIT/期初期末平均资本，资本为同口径债务加权益。零分母、负分母及不完整年度保留解释。 |

资本化利息、外用研发和其他应属经营活动的资本化现金从capex转CFO时，两者同额下降，FOCF不应凭分类增加。不得把每笔计债调整机械搬到CFO；例如退休计划缴款仍属经营现金。p27的现金利息收入例外只针对FFO，须有重大性或适当反映本主体的理由，不据此把应计覆盖率分母也净额化。

## 3. 例行债务、现金和费用调整

| 事项与原文位置 | 取证、实施和能推翻调整的条件 |
|---|---|
| 可动用现金，¶36–38/86–91，p7–8/17 | 逐法人验证币种兑换、限制、上划、相关税费及第三方所有权；受困于子公司的合格现金最多匹配该子公司债务，不能跨层重复使用。金融赞助方持有或业务风险为weak/vulnerable时通常不净现金；专用于偿还到期债且有证据表明管理层将如此使用者，才核例外。为已计债务债权人保管的escrow可匹配抵扣。预计营运资金需求通常不从这一机构指标现金中扣，实际流动性预算仍必须计需求；异常大量营运中物理占用现金另核。 |
| 租赁，¶92–105，p18–20 | IFRS16与ASC842账面短长租赁义务计债，已入金融债的不重复。IFRS下租赁利息若列投资/融资流则移到CFO。ASC经营租赁成本拆成利息与折旧：利息=`期初期末经营租赁负债均值×披露加权贴现率`；折旧代理=`经营租赁成本−该利息`；EBITDA加全部该成本、EBIT加利息、CFO加折旧代理，FFO用调整EBITDA再扣租赁现金利息代理。不能只加债不改利润，也不能将CFO分类改善当新增现金。 |
| 未资本化租赁、续用和转租，同上 | 依原文7%折现承诺；第五年后总额除以第五年年付额，按最接近的整数年确定尾期，全部付款期最长30年。输入第五年额缺失/为零时不编造尾期。未资本化经营租赁在债务和资产两端补同额现值；利息代理用7%乘期初期末现值均值，租赁费与该利息之差为折旧代理，再按上行同步接EBITDA、EBIT、CFO和FFO，不能套ASC842的披露贴现率。租赁费估计所需两年披露的下一年最低付款额也须取得。仅在期限匹配且转租方达到本方法充分信用条件（通常投资级）时净转租。账面负债低于未来12月承诺三倍是续租调查线索，不是硬补到三倍：资产将退出使用可反证；租赁密集行业可能需要更高。没有隐含capex加项，实际续租和付租另进现金表。 |
| 退休及递延报酬，¶106–115，p20–21 | 汇总设定受益的养老金、医疗及同类递延报酬义务与计划资产，净缺口扣尚未获得且可实现的税益后计债，净盈余不抵债。不能计入设定提存义务，不能凭工资估计缺口。IFRS经营费用仅留当期服务成本；正的净PRB利息转应计利息，净利息收入不减普通债务利息。US GAAP用利息成本减预计计划资产收益确定PRB净利息，不拿实际资产回报替代。实际缴款仍留CFO。 |
| 恢复/退役义务，¶116–120，p21–22 | 核法定义务、时间/折现假设、专用基金、残值和可实现税益；净额才计债。可靠的客户附加收费或第三方承担可能免去该计债，需取合同与可收回证据。折现展开从经营费用转利息时核专用基金收益，保留支付时间；不把所有长期维修准备称为ARO。 |
| 应收等持续生成资产的出售/证券化，¶124–127，p22–23 | 无追索本身不取消融资调整；还原期末未收应收与相应融资负债。CFO只冲回本期初设、增减或终止形成的现金影响，既有额度滚续不再调一次。非日常再生资产、无保留风险/道义支持及或有义务的真实资产出售可能不计债。US GAAP留存受益权益的回款若列投资现金，另转CFO。 |
| 供应商融资，¶64，p12 | 单列向金融中介支付贸易应付的实际期限；超过90天时通常按融资研究债务及CFO调整，微不足道除外。这是S&P触发口径，不能代入Fitch的延长账期比例。原文没有提供该比例公式；根据实际已融资未结余额和现金桥量化，不把全体超过90天普通应付自动计债。 |
| 混合资本，¶128–132，p23–25 | 先用适用混合方法判权益含量和数量上限，再将本金和当期票息分到债/权益、利息/股利，并配对FFO/CFO。中等权益含量本金50%计债；累积递延未付分配全部计债，不再按50%。本篇15%为示例；实际上限与适用对象须接[混合资本方法程序](corporate-credit.md#81-sp混合资本条款数量付款与债项分别形成)，其中企业通常15%票面/资本化分支排除MCS，银行、保险和MLI另有各自限额，不设成所有工具的通用上限。缺分类依赖时保留确定合同现金和条件分支，不自赋权益抵免。 |
| 保证，¶48/134，p9/25 | 第三方/未并表关联方债务保证通常计入，但受保人充分信用、由充分信用的反保证人降低净代偿额等可改变金额；同时核税益。已合并债务不重复。履约保证只在重大代偿有历史或预期时作相应计债，其他风险仍作情景。 |
| 递延/或有收购对价，¶135–137，p25–26 | 现金或不符合权益条件的变股数结算计债；递延对价按摊余成本，负债类或有对价按期末公允值。从EBITDA剔除其未实现重估；实际结算若列CFO则移至投资。持续任职换取的收购后服务报酬不是同一项对价，不能一律计债或加回费用。 |

**构造例A——US GAAP经营租赁。** 期初/末经营租赁负债80/100，加权贴现率5%，经营租赁成本20；已扣该成本的EBITDA100、EBIT60、CFO70，未含租赁的利息和现金付息均10，现金所得税20、capex30，金融债200且未含租赁，满足抵扣条件的现金40。租赁利息4.5、折旧代理15.5；调整EBITDA120、EBIT64.5、利息14.5、FFO85.5、CFO85.5、FOCF55.5、净调整债260。净债/EBITDA为2.1667倍，现金息覆盖为100/14.5=6.8966倍。实际租赁付款没有因此减少，支付预算仍列全额。

**构造例B——税与养老金。** 义务200、计划资产150，缺口50；仅当25%未来税益尚未取得且可实现时计债37.5，否则50。若另一个计划有盈余20且符合汇总口径，净缺口变30，不是继续计50；仅在同样适用25%尚未实现税效时税后为22.5，不同计划/法域须分别核税效后汇总。现金缴款15仍减少CFO，不能以“已计债”为由加回15。

## 4. EBITDA不是所有非现金项目的加回总和

按¶72–81、121–123、223–225（p14–15、22、44–45）把费用性质和已包含状态逐行写清。普通企业经营存货/应收减值、重组和并购服务费用保留；非流动资产减值与转回从EBITDA剔除，但EBIT的处理另判断。股份结算的股份支付可加回，现金结算不靠“股份支付”名称加回。权益法收益从EBITDA排除，改入实收股利；若已按比例合并该被投资企业，不再重复加股利。

合同取得/履约等资本化合同成本的摊销是经营成本；先从总D&A加回数里剥除，现金支出若在投资活动则移CFO并从capex剔除。研发费用化桥保留现有“当期资本化支出与既有摊销”双路径，不能双加摊销；自用软件资本化通常不反转，外售软件研发另核可分明细。无法分清时记录具体缺口和敏感性，不按全部无形资产变动替代本期研发。一般未实现公允值变化和融资性汇兑从EBITDA/FFO剔除，经济套保只留本期实现结果；商品交易商例外见第8节。

**构造例E——D&A组成。** 营业利润100已扣普通折旧30、合同成本摊销6、非流动资产减值20、应收减值8、股份结算报酬5，且含普通投资物业未实现估值收益7；另有符合调整的外售研发资本化10（不含自用软件，本例没有当期研发摊销），没有其他调整。EBITDA=`100+30+20+5−7−10=138`，合同成本6与应收减值8均不加回。若把它们混进非现金加项将错报152；真实回款与支出仍由CFO桥说明，138并不证明现金可用。

## 5. 少数权益、结构化资本与税收应收协议

先执行[特殊结构第4节](special-credit-structures.md#4-非控股权益少数股东与结构化jv)的控制、支持和现金边界。¶26–30（p6–7）所述少数损益代理只在子公司没有重大债务等适用事实下用于近似比例去并表的EBITDA；不能删除子公司债务却保留所有现金/盈利。

¶62后无编号段及¶63–71（p11–13）要求逐合同识别融资支持和最终现金风险：

- 已收前期款或其他对价，同时承担支持出资方/第三方融资的或有保护，需要检查隐含融资，不等到名义保证被调用。全并结构化JV中，注入已获益资产、少数投资款上划、除不可抗力外不可撤销的MVC，且其降低投资者量风险之外的经营利益很少，这些事实的组合可能构成融资；按适用合同最低额/罚款以7%折现计债并配套盈利调整。普通尚待交货采购合同不因长期或保底量就直接计债。
- 全并子公司少数权益的赎回不受发行人控制（例如投资者put）时，核应计债务；只有明确事实支持极不可能行权时另作判断，发行人自己的call不等同投资者put。对非普通股先判断是否永不要求现金且不会带来发行人控制外的信用压力，再核合同是否同时不存在约定收益、实质期限、持有人现金赎回权、契约/违约触发、担保或抵押，并在所有债务之后受偿；全部条件满足才适用¶68不计债分支。满足上述条件后的清算优先、仅宣布分红才分配的优先权或无保护的目标回报，不单独推翻该分支；带可递延股利的工具转混合资本方法，不论是否累积。投资者put一般计债，仅能转换为普通股的put另按¶70例外判断，不能把可选择现金结算的工具归入该例外。控股股东提供的工具转适用的控股股东融资方法，不凭本篇豁免。
- TRA先对账内义务、加速/结算条款和已宣布和解取证。通常计入已记负债且有相关条款的义务；投资其他企业为经营模式，且加速/结算历史有限或极不可能时，核该例外。已宣布但未入账的协商结算用协商额；其他未记录TRA负债的情形不单凭加速条款加债。方法未计债不证明未来支付为零，现金风险仍列实际情景。
- 已发生的结构化争议和解义务与普通采购承诺分开；适用时按有据现值计债，不因未来分期支付就不计，也不把尚无法量化的争议上限当确定金额。

**构造例C。** 已证实属于上述融资MVC，尚未计债的每年期末最低付款10、剩余10年，则NPV=`10×[1−(1.07)^−10]/0.07=70.2358`。基础债100、已扣当年该付款的EBITDA40，若整笔10已确认属融资回报且没有其他调整，则债170.2358、EBITDA50、杠杆3.4047倍；只加回10会误报2倍。需保留未到期合同10年现金，不能把NPV70.2358当今年支付。

**构造例D。** 报表TRA负债60、有加速条款，但没有投资经营模式例外证据，基本分支计60；若随后正式宣布完整结算45且尚未改账，按协商额45分析，不能重复计105。若适用投资经营模式例外，则明确60未进入方法债务的证据和仍可能发生的付款，而不从不计债推导无需偿付。

## 6. 情境调整先确定对哪个指标有效

¶147（p26–27）触发项逐一查本主体，而不是统一打折：重大PPA存货增值随售出摊入成本可能需从EBITDA反转；重大诉讼、工伤、自保险和多雇主计划义务需取得可分配暴露及税益；多雇主计划不能用本企业当前缴费推算全部退出责任。债务初始计量、并购承接、困境修改/交换、公允值变动须核原融资现金、有效利率和未付息；账面负债随信用恶化而下降不等于偿付本金减少。外币本金套保用锁定本金或有证据的套保价值调整，不能一面调债一面把同一衍生资产再扣现金。现金利息收入的FFO例外见第2节。

## 7. 产业内金融：S&P拆分与Fitch拆分不互换

¶259–267与后续计算（p50–54）覆盖贷款、融资/经营租赁、短长租赁、原出租产品再销售及有关金融服务。先用适用Captive Finance方法确认重要性及路径；本篇本身不能填出未取得的组合质量/ALR参数。

从分部及独立财报建立集团、产业和金融三张表，修正内部交易及管理表外证券化。金融范围债务不净其现金；合并债/资本比率原则上也不抵金融现金，只有取得可实际还债证据的少见情形才按¶267另判。金融债纳入与产业端第三方融资实质对应的内部资金，产业无外部借款却以自有资金贷给金融子公司的情形另分；金融债不超过调整合并债。不能把双方内部借款再当两笔集团外部债务。

资料优先级为已披露/发行人实际提供，少数缺项才用有理由估计；若大部分金融指标都要估计，则按原文保留合并财务确定产业FRP。债务缺失时所需杠杆由Captive Finance方法表2中组合质量对应的medium ALR区间决定，不用Fitch4倍等参数代替。金融减值不能用无依据的比例估算；租赁资产折旧/减值即使列在产业分部，也按经济归属划回金融端。权益法金融企业的收益和股利从产业调整利润/现金剔除；全并金融与产业间股利通常也不列产业调整现金的新增来源。

金融业务利润已含融资利息为经营费用，估计金融CFO时不能再全扣一次：从金融EBITDA扣现金税，并只校正其已计利息费用与实际现金付息的差额，再扣贷款/融资租赁应收及经营出租资产的净投放；经营出租资产变动按新增与转存货/售出资产价值衔接，不拿整笔出售现金代替转出资产价值。期初/末平均有收益资产、适用资金成本、当地税率、折旧寿命和实际减值各留证据，允许的估计不伪称报告事实。产业承担的利率/残值补贴留产业成本，不能随金融去并表一并消失。

## 8. 按实际行业触发附录3的专属桥

下表用于定位与执行差异；有重大事项时读取链接原文所列段落，实际数值/合约不足则保留受影响指标未完成。它不替代行业业务、治理、流动性、主权、支持和债项方法。

| 航天国防，¶149–153，p28–29 | 按可回收退休成本的政府合同收入占比，再区分成本加成/固定价格，校正PRB计债；固定价格不能认同成本加成全额回收。方法比例关系为`政府合同收入占比×(固定价格占比×50%+成本加成占比)`，合同类型占比的分母均为相关政府合同。其他国家须有等效机制。 |
| 农业及商品食品，¶154–155，p29 | 生物资产估值损益从盈利指标剔除；商品交易对正常化EBIT/EBITDA/毛利贡献超过10%时再核ARMI。存货为加工用途不因流动性好而自动抵债。 |

| 品牌非耐用品，¶163，p30–31 | 仅对代消费者收取且已毛额计入的消费税配对扣收入和销售成本；不把所有企业税费净掉。 |
| 商品贸易，¶164–170，p31–32 | 匹配交易及衍生品的已/未实现损益均可能构成核心盈利；不能照普通企业一律剔未实现。ARMI逐项核已套保/预售、30日内可变现且能平掉套保、非加工、无损业务及所得可还债；扣平仓现金后按适用商品风险类别10%/25%折扣。此抵债不用于债/债加权益补充比率，普通现金在业务地位弱或交易风险管理/风险头寸支持较差时不抵债，ARMI抵债不因此取消；二者分开留底稿。另查租船、仓储及其他固定资产服务承诺的租赁调整。商品类别须取实际行业方法。 |
| FMI，¶171–173，p32 | 将清算结算义务、相关客户资产及其现金变动成套剥离，受监管最低资本/吸损要求约束的现金不作自由现金；继续完整分析参与者违约与流动性瀑布，剥离不等于无风险。 |
| 林纸，¶174–176，p32–33 | 成本计量林地以有依据市场价值差调整权益用于可比杠杆/ROC，EBIT不同时上调；IFRS账内林地重估收益也不当经营利润。 |
| 房企开发商，¶177–182，p33–34 | 土地购买承诺接预测融资和现金，不另简单计债。被证为非经常的开发库存减值可加回EBITDA/EBIT/FFO，与一般存货例外分开；未实现重估另剔除。本期进入销售成本的以前年度资本化利息加回利润，本期新增资本化利息进本期利息；不能把同一两者混成一数。重大权益法杠杆按支持与控制证据作比例或全并，相关股利不得双计。 |
| 酒店，¶183–184，p34–35 | 合同指定代报销收入与对应成本分别剔除；两者当期时差会影响EBITDA，不能假定始终相等从而只调收入。 |
| 传媒，¶185–186，p35 | 内容/节目成本摊销及减记保留经营成本，资本化现金从投资转CFO并从capex去除。并购内容库PPA增值若造成重大失真另按情境证据校正，不加回整库摊销。 |
| 上游矿业，¶187–192，p35–37 | streaming先核替代借款、现金返还/追索/加速及覆盖等融资特征；计债余额按未摊义务及必要隐含息滚动。合理利息已入账时不再改收入/息；未计息时配对增量收入和复合利息。首期前收款移出CFO，后续不按非现金收入摊销重复冲现金。 |
| 油气勘探开发，¶193–204，p37–40 | royalty与VPP分开。royalty核融资特征、未摊义务及相关息，首期款移CFO；成功费用法勘探支出加回至EBITDAX但FFO再扣回。未来产量未实现套保损益剔除。高保障VPP依未来交付量、当期远期曲线、地点质量差和有担保融资率求现值，匹配隐含息、剩余储量及成本单位；VPP实际前收现金还须从CFO和FFO剔除；隐含利息以期初期末VPP义务均值乘有担保融资率，不能只调债务。低超额担保的VPP另评实质风险转移，保留交付前运营成本。不得把固定前收款永作剩余债，也不把高油价只当利润利好。 |
| 炼油，¶205，p40 | 从经营盈利与FFO中剔除有证据的LIFO层清算收益，不以全部存货余额变动替代。 |
| 油服，¶206，p40 | 多客户地震数据本期资本化支出按经营成本处理，配套下调EBITDA/FFO/CFO与capex；EBIT扣本期投入与既有摊销差，避免重复加回。 |
| 经营出租，¶207–208，p40–41 | 融资租赁实收本金作为偿债来源加入FFO并按经营现金对齐；正常旧出租设备出售损益进EBIT但不进EBITDA/FFO。本金回收不等于收入确认，出售总价不是出售利润。 |
| REIT，¶209–211，p41–42 | 重大直线租金按实际现金租金校正收入与盈利；JV比例/全并同时替换股利。排除困难非追索子公司债还需不会损害发行人融资可得性、无交叉违约/加速等证据；仅有“非追索”不足。资本化利息同本期费用桥。 |
| 受监管公用事业，¶212–220，p42–44 | 通胀本金增量即便未付也扣FFO，已含在债务的累积增量不重复；通胀互换对应部分同查。PPA只按资本替代、费率回收、既有租赁及有据风险系数/贴现率确定负担。天然气季节短债只有采购成本可在一年内传递、没有非微不足道的不予回收历史，且库存/融资与其他交易业务分账时才核扣除。法定成本证券化另须宪法授权主体划定回收、不可撤销且用户不能绕开的收费、资产真实转移与第一顺位权益、定期true-up和短期储备，并同步移除债务、收入、折旧、利息及本金相关CFO。 |
