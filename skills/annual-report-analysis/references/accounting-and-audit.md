# 会计判断与审计支持操作参考

用于报表重建、盈利及现金质量、资产负债计量、交易分析和审计支持。只执行影响当前问题的章节。银行信用模型、保险精算和金融监管资本使用独立金融参考，本文件不将工业企业指标推广到金融机构。

方法与版本依据核实至2026-10-02。法规、准则或公司政策决定结论时，重新确认具体报告期适用版本。以下数值例均为假设例，金额单位在各例内一致，不是行业阈值。

## 1. 开始工作：确定口径和实际能执行的程序

在底稿开头写明实体、合并/母公司、期间/时点、币种单位、报表版本、正式重述、会计基础、审计报告声明的准则、报表批准日、审计报告日、公开发布日期和分析资料截止日。香港发布不等于HKFRS，美国20-F不等于US GAAP；后续更正不得悄悄进入“当时可知”的分析。

分开保存：原报数、正式重述数、分析者调整数。每个参与判断的事实保留文件及页/附注/表行定位；计算保留输入、公式、假设、结果和差额；每个问题保留支持证据、替代解释、实际程序、结论及关闭条件。缺失不填零，未取得不等于未披露。

| 当前资料 | 立即执行 | 仍需记录的下一步 |
|---|---|---|
| 完整年报和公开公告 | 四表/附注核对、政策比较、滚动与现金桥、公开假设敏感性、审计报告和其他信息核对 | 合同/账簿/外部证据才能区分的解释，逐项列资料和程序 |
| 另有台账、合同、预测或模型 | 先对账验证完整性和准确性，再复算交易、估计或选取项目检查 | 外部回函、实物/履约证据、模型参数及范围覆盖缺口 |
| 另有实际审计证据 | 按程序目的评价证据，汇总例外和错报，形成项目结论支持 | 不足之处追加；书面声明、专家签章或原审计意见不能自动填补 |

准确使用动词：“年报记载原审计师实施函证”与“本次已收到并核实回函”不同；“已计划检查”与“已检查”不同；“本范围未发现异常”不等于证明不存在错报。

**版本示例。** 中国1211/1321及一致性修订自2023-07-01施行；ISA240新版、ISA570（2024修订）通常适用于2026-12-15及以后开始期间，不能自动套入2026日历年度。PCAOB新版函证按2025-06-15及以后结束财年适用，技术辅助分析修订按2025-12-15及以后开始财年适用。中国2026年发布的列报新规有分批实施安排，IFRS18/HKFRS18通常从2027年开始；都须核实实际提前采用及过渡政策。规则发布日不能替代生效规则。[中国审计修订](https://cicpa.org.cn/xxfb/news/202301/t20230103_63903.html)、[ISA570](https://www.iaasb.org/publications/isa-570-revised-2024-going-concern)、[PCAOB按期间目录](https://pcaobus.org/oversight/standards/auditing-standards)、[中国列报正式通知](https://kjs.mof.gov.cn/zhengcefabu/202608/t20260805_3994927.htm)、[IFRS18](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-18-presentation-and-disclosure-in-financial-statements/)、[HKFRS18](https://www.hkicpa.org.hk/en/Standards-setting/Standards/New-and-major-standards/New-and-Major-Standards/HKFRS18)

## 2. 交易政策判断：从经济事实到会计影响

先按业务流写清：交易各方与关系→承诺/权利义务→谁控制资产或服务→定价和结算→关键日期→风险由谁承担。然后选择适用准则、公司的政策和估计，逐项判断确认、计量、列报与披露。没有合同关键条款时，写出条件分支及所需条款，不猜交易实质。

列内部资料请求前，先沿年报附件索引、交易公告和交叉引用查找已公开的签署协议、修订、交割公告及备考报表，只补读影响当前结论的定义和条款。公开资料已给出的价格调整、契约定义或备考桥应先完成分析；未公开附表、最终结算、合规证书和逐笔台账再列缺口。备考假设日、原报时点、实际交割和披露日分别记录；假设出售产生的现金、偿债和利息变化不能当作实际收付。会计终止经营范围也不自动决定契约EBITDA范围，应核当时有效协议对待售但尚未处置业务的定义。

底稿逐笔或按同质合同组列：经济事实与证据、适用规则/版本、现行处理、判断及备选处理、金额/期间影响、拟调整分录或分析调整、需补证据。会计更正与为比较而作的调整分栏。解释转回或重估原因前，先对照该事项的政策、合同条件及数量/金额变化：例如股份支付需区分服务、业绩和市场条件，观察到股价变化本身不能代替转回原因证据。相邻附注的交易或估值参数不自动适用于本事项。

| 重要交易 | 实际步骤与所需证据 | 可推翻初判的解释；关闭条件 |
|---|---|---|
| 客户合同收入 | 取得合同及变更，识别客户与履约义务；判断时点/时段、总额/净额；检查可变对价、退货、质保、融资及捆绑分配；将确认日期追到履约证据 | 验收条款可能实质或仅形式，开票/收款本身不决定收入。须核实控制转移、对价及截止，重大例外已量化处理 |
| 存货/固定资产/在建 | 先区分取得资产、消耗与达到可用状态；核对原值、成本分配、资本化、折旧/摊销、减值；取得用途、验收、成本和寿命证据 | 延迟转固可能因真实未完工，也可能少提折旧。须证实可用日期、必要成本及计量，不以付款代替实物/权利证据 |
| 研发、软件、数据资源 | 按适用规则逐项目判断阶段和资本化条件，明确开始日期、可归属支出、寿命和可回收性；研发投入与费用、资本化及摊销作桥 | 项目成熟可支持资本化，但专利/投入增长不证明商业化；有价值不自动符合资产确认。条件及日期未经证实时保留情景，不改成确定资产 |
| 金融资产转让/票据/供应链融资 | 读追索、回购、差额补足、收益保留、控制及付款安排，按适用规则判断终止确认或融资；核对P&L、现金流和表外披露 | “无追索”名称不排除其他保留风险；应收减少可能是融资。关键风险、合同现金流及现金来源必须对齐 |
| 租赁、借款、或有义务 | 核实使用控制、租期/续租、利率、费用、担保、契约；分开账面值、合同未折现现金流和分析债务；诉讼/质保结合事实及法律证据 | 可撤销/未开始租赁承诺不等于已确认租赁负债；担保已入账部分不可再全额计为表外新增。确认、计量和披露三项分别结论 |
| 企业合并/投资 | 判断业务或资产收购、控制及取得日期、同一/非同一控制；复算对价/可辨认净资产/商誉；权益法收益与分红另作桥 | 持股比例不等于控制全部证据；CAS同控处理不能照搬IFRS。关键协议、范围、日期和计量足够才关闭 |

**收入工作例。** 已核实适用投入法且履约条件成立，合同价120，累计合格投入30，预计总成本100，累计收入36；前期已确认20，本期应确认16。若本期账面收入30，先调查预计总成本、合同变更和合格投入，不能直接把14称错报。只有复算输入与政策已证实时，才提出本期收入减少14；履约条件本身未满足时，应重新判断方法，而非只调进度百分比。

**资本化工作例。** 设备经证实7月达到可使用状态，成本120、残值0、适用寿命10年且按月直线折旧。若政策规定自次月计提，本年度8—12月折旧为5。账面仍在建且未折旧，则量化转固与折旧影响；不能不问适用起提政策就机械按半年计6。

## 3. 四张报表、附注及比较期重建

先逐张抄取原表，再将关键附注接回主表。必须同时保留总额/准备/净额、合并/归母/少数股东、持续/终止经营，不能只留一个“净利润”字段。

关键判断取自横向或跨页变动表时，先回看完整表头与目标行，把各列原名、原符号和空白列位置对应后记录到 evidence；再按该行的增减口径复算期初至期末。滚动闭合不能代替列位置核对，同符号项目互换也可能闭合。分红事实保留“宣告”或“实际收到”的原动作；相关比率的分子分母取同一投资集合。宣告分红只能说明已宣告分配，现金实收另取收款或现金流证据。

| 检验 | 复算与处理 |
|---|---|
| 资产负债 | 资产−负债−权益；归母权益+少数股东权益=总权益 |
| 损益及综合收益 | 合并净利润=归母净利润+少数股东损益；综合收益=净利润+OCI，分别核对归属 |
| 权益滚动 | 期初权益+综合收益+股东投入−股东分配±具体其他直接权益变动=期末权益；拟议分红与已确认分红分开 |
| 现金滚动 | 期初现金及等价物+CFO+CFI+CFF+汇率影响=期末；另用附注连接货币资金、受限资金、定存和现金等价物 |
| 资产/准备滚动 | 期初+新增/计提+并表±汇兑/重分类−处置/核销−折旧摊销−减值等=期末，按对象逐项定义符号 |
| 分部/附注 | 外部收入、内部交易及抵销接集团；分部利润经未分配项目接集团利润；附注明细、EPS股数和非经常损益回到原表 |
| 比较期 | 原披露→正式重述→分析可比调整，分别记录原因；政策变更、估计变更、差错更正、重分类分别判断适用方式 |

发现差额时先暂缓异常定性：另起记录，不复制原录数，重新从带表头的原页逐行录入有符号金额，保存原值/重取值及页图位置，用重取值独立加总；再核单位、版本、合并范围、OCI和重分类。舍入范围依据披露精度及参与加总项数；不能设“差额小于收入1%即通过”。确认是录入错误就修正下游判断及请求；仍无法解释的差额保留数值、证据和具体未决项，不倒挤“其他”。一句“已回看”或重复运行旧输入不能完成这项程序。

准备余额滚动和当期损益另列两条桥。**构造例：** 存货准备期初10＋计提6−转回1−随销售结转4＝期末11；在无其他影响的假设下，减值净损失为5，不是准备净增加1，也不是`6−(1+4)=1`。附注只给“转回或转销”5时，可验余额滚动，却无法拆出当期减值净损失；须另取转回/转销明细及损益对应行。CAS存货第14条的已售准备结转和第19条的价值恢复转回是不同路径，按实际政策接回损益列报。[财政部准则原文](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/200806/t20080618_46216.htm)

**工作例。** 货币资金150，其中存款30已按适用准则及条款核实不属于现金及等价物，另有不满足定义的定存40、货币资金之外符合定义的短期投资10；若不存在重复或其他项目，现金及等价物为90。现金流表若为95，记录差额5并追查，不能把150或强制倒挤95用于现金桥。

不能仅凭“受限”标签作上述扣除。[IFRS解释委员会2022年4月议程决定](https://www.ifrs.org/content/dam/ifrs/supporting-implementation/agenda-decisions/2022/demand-deposits-with-restrictions-on-use-arising-from-a-contract-with-a-third-party-apr-2022.pdf)的情形中，第三方合同用途限制未改变可随时向银行支取的活期存款性质。若例中30符合这一情形且无其他排除，现金及等价物为120，其用于特定债务的可调度现金仍可能为零。会计现金、报表列示/披露及信用用途限制分别判断，并核实适用准则，不能相互替代。

**关闭条件。** 关键等式重算一致或差额有证据；前后版本及范围一致；未闭合项不会被下游当作已证实输入。数学闭合仅证明所列数据关系，不能证明交易真实性。

### 3.1 债务分类与偿债日期分别判断

借款分类、契约、违约豁免或期后再融资影响结论时，取当时有效合同及修订，分别记录报表日、约定到期日、契约必须遵循的日期及计量期间、实际核验日、补救/宽限期限、豁免生效日和批准报出日。保留原报分类、按适用准则的判断、合同现金义务及所选信用方法的分析债务，不以其中一种替代其他口径。

CAS按适用CAS30与解释17，仍适用IAS1的主体按69—76、76ZA：先核报表日是否存在实质延期权（CAS为推迟至报表日后一年以上，IAS1为至少十二个月），再核其他流动分类条件。贷款安排要求在报表日或之前遵循的条件，即使期后才核验，也影响当日权利；真正只在期后才须遵循的条件，不据此改变当日分类。对仍列非流动、延期权取决于未来一年契约的贷款，核条件性质/遵循时间、账面额及可能难以达标事实的披露，并将潜在加速接入现金情景。

报表日或之前违约导致贷款人可随时要求偿还，原则上列流动；贷款人在报表日或之前已同意并给予有效宽限，且覆盖所需期限的，还须满足期间能够改正违约、贷款人不能即时追偿等条件。期后才取得豁免或新签长期再融资，不回补报表日缺失的延期权；报表日已存在的展期权另判。反过来，满足非流动条件的债务，不因管理层拟在一年内或期后实际主动提前清偿就改列流动。期后事件按适用规则披露；截至分析日已生效的融资、豁免及实际付款，仍按各自日期更新信用现金表。

**构造例。** 2025-12-31账面贷款100，正常到期2028-09-30，其他非流动条件满足。若契约要求年末杠杆≤4.0、实际4.3且违约即有权要求偿还，无有效豁免，则年末列流动；银行2026-03才核验不改变判断。若合同仅要求2026-06-30符合4.0，则上述年末4.3本身不把贷款改列流动，但须核未来契约风险披露和六月可能加速的现金压力。

**日期反例。** 贷款80在2025-12-20违约后可被随时追偿，2026-02-10才获有效豁免，即使早于3月报表批准日，CAS/IAS1年末仍列流动；若贷款人在2025-12-29已同意并给予有效宽限，且其他非流动条件满足、宽限覆盖至2027-02-28、期间可以补救且贷款人不得即时追偿，则该分支可支持非流动。另一笔次年4月到期贷款20，年末无展期权、次年2月才落实长期再融资，年末分类也不因此变更。实际现金表保留有效豁免、借新还旧与原到期的日期和金额，不直接复制会计分类作为债务日历。

执行期间与原始依据见[会计适用表](sources-and-standards.md#会计适用表)。US GAAP的豁免、宽限和再融资须核报告期适用的现行ASC470及交叉引用；未取得相关正文时保留分类未决和具体合同/规则缺口，不套用上述CAS/IAS1结论。

## 4. 盈利、客户现金、供应商现金与资本投入的桥

### 4.1 合并净利润到经营现金流

用与合并CFO同口径的合并净利润起步，逐项加减非现金损益、列在投资/融资现金流的损益、递延税以及经营性资产负债变化。资产负债表期末差额先剔除并购、处置、汇兑、重分类、核销和非现金交易，才可解释CFO调整。税、利息、股利及租赁分类先按准则和公司政策核对。

先按附注原行名和带符号金额，分别写出增加与减少CFO的调节项，再形成现金质量结论；解释CFO同比变化时，用两期对应调节项的差额。本期正向调节也可能同比减少。经营性应付项目未取得分解时，解释停留在该合计层级。应付账款、合同负债和供应商融资的余额变化另列观察，取得新增、结算、非现金与范围变动的桥后，才归因到供应商、客户或融资现金；实际付款周期另需合同及结算证据。

**例。** 合并净利润100+折旧20+减值5−处置收益8−经营应收增加30−存货增加10+经营应付增加15=92。公司CFO为90时，剩余−2必须定位税、其他项目或取数差异。归母净利润80不能替代起点100。闭合后仍要辨别CFO来自当期经营、旧账回收、预收增加或延期付款。

### 4.2 收入到客户收款

以权利义务滚动为主，分别处理应收原值、票据、合同资产、合同负债、退款负债、税和非现金结算：

`期末应收原值=期初+本期形成债权−现金回收−核销−终止确认转出±其他有证据变动`。

合同资产转应收是重分类；收入不等于含税债权发生额；核销、票据背书给供应商不是回款。有追索融资流入不能自动算客户现金。年报缺少这些项目时，只给公开部分桥、量化残差及需要的台账，不硬造万能收现公式。

**例。** 期初应收100+经核实含税债权113−现金80−核销3−终止确认转出10=期末120。不能用收入100−应收增加20=80来证明收现，因为两者只是本例巧合；改变核销或转让后仍必须按滚动复算。取期后回款时匹配发票/项目、付款人和来源，防止把新预收或循环资金当原应收回收。

### 4.3 成本到采购，再到供应商付款

先从存货成本滚动识别采购和生产投入，拆出人工、折旧及制造费用；再从采购、应付、预付、税、资本性应付和非现金结算桥到现金。`营业成本+存货增加`通常不是采购。

**例。** 期初存货50+材料采购100+生产人工20+制造折旧10−销售耗用120=期末60。应付期初30+同口径采购100−现金90=期末40（假设无税、预付、资本性采购及其他变动）。营业成本120+存货增加10=130是总投入，不是采购100。若存在供应链融资，还要重新评价负债及现金流分类。

应付薪酬用期初+当期计提−现金支付±其他=期末；计提可能进入存货/在建，不全是当期费用。关闭前核实采购/成本和现金所覆盖业务一致，避免折旧或工资重复加减。

### 4.4 正常盈利与QoE

涉及集团与归母归属的调整后净利润，先确认期间和调整定义，在现有底稿中按“集团、归母、少数股东”三列排列“报告净利润、税后调整项、调整后净利润”三行。先从利润表取起点，再从公司调整明细按原符号连接税前项目、所得税影响和税后少数股东影响，纵向复算每种归属，横向用集团减归母接少数股东列；另从目标披露页取数核对终点，保留舍入残差，缺少拆分时停在有证据的层级。正文和资料请求据已对齐的终点及剩余差额形成，先将已解释的归属差异写入口径说明。各类调整仍逐项记录原金额/出处、方向、经济理由、适用的税及归属影响、现金属性、重复性、期间及重叠关系，按各自定义展示报告值→公司调整值→分析者正常化值。公司扣非/Non-IFRS利润、分析者正常利润与交易QoE分别保留定义；未来协同不加入已实现盈利。

先从公司非经常损益表及其说明，将参与判断的项目逐项对应到利润表科目和附注明细，分别记录已纳入金额、明确未纳入金额及尚不能拆分的部分；“其他”行与说明一并读取。一个科目可能含不同性质交易，披露只说“部分”或只给混合合计时保留原类别名及税前/归属范围，可能机制另作假说，不能具体化成整项重估收益、非现金收益或母公司净贡献。完成公司口径映射后再做分析者正常化，避免把整科目全额剔除或重复扣减同一收益。分类按交易性质、业务模式和适用规则判断，科目名称本身不足以决定。[证监会2023年非经常性损益规则](https://www.csrc.gov.cn/csrc/c101954/c7451398/content.shtml)

**例。** 税前利润100，含处置收益20和有证据支持的一次性重组费8，则该分析口径正常税前利润88。若经证实两项均适用25%税率、无少数股东影响，净利润75−15+6=66。若重组每年反复发生或税收不可抵扣，须重判加回或税影响，不能沿用66。

加回损失时对称处理收益。股份支付、常态重组和必要维护支出不因非现金或管理层称“一次性”就全部剔除；减值即使在某利润展示中单列，经济损失仍留在资产质量与资本回报分析中。

写“增长更依赖某项收益”前，把同一定义用于两个期间，分别保存报告利润、调整项、正常化利润及增速，再比较方向。**构造例：** 报告税前利润100→130，均按已证实同类处置收益20→5调整，正常化利润80→125，增长56.25%，高于报告增长30%。存在处置收益本身不能推出“主业增速更低”；税和少数股东未拆出时，这仍只是税前比较。金额比重也须先对齐税前/税后、集团/归母及交易集合。

### 4.5 营运资本、资本支出、租赁与净债务

把会计新增与现金支出经资本性应付、预付、并购取得、非现金租赁和其他变化调节。转固是内部移动，不是新增投资。只有证据支持才拆维护/扩张资本开支，不能以折旧直接替代维护投资。

`CFO−现金购建长期经营资产`可以作为明确定义的简易现金指标；须另说明租赁本金、资本化利息、并购、资金限制和必要现金，不称其天然等于FCFF或可分配股东现金。

交易NWC先定义经营项目，再用覆盖季节周期的月度/季度数据判断正常范围；仅年末两点不能可靠确定交割目标。净债务区分账面债务、租赁、债务性质项目和可用现金，按合同定义逐项处理。DPO若用营业成本代理采购必须说明偏差，DSO若用总收入代理赊销也须说明。

**例。** 工程应付12若已作为债务性质项目从股权价值扣减，就不得再次作为经营NWC缺口扣12。递延收入等争议项列协议口径与金额影响，不能把交易惯例写成会计准则。

### 4.6 股利：分配决定、往来余额与实际现金

付款方按`期初应付股利+本期已确认分配±已核实其他变动−期末应付股利=本期结算额`作桥，再分现金、代扣代缴及非现金结算；与付款证据、现金流和实施公告核对。收款方按同一投资集合建立`期初应收股利+本期已确认收取权利±其他变动−期末应收股利=本期结算额`，再核实实收现金。尚待批准的方案单列，不进入已确认或已付事实。权益法收益、宣告分配、母公司可分配利润和可调度现金分别判断。

**构造例。** 假定无税款、汇兑及非现金变动：应付期初6、本期宣派20、期末4，则实付22；只用当期权益分配20会漏掉跨期现金。某投资组合当期权益法收益30，宣告股利8，应收期初3、期末5，则实收6。`8/30`只能称宣告分配/当期收益比，不能叫现金兑现率；若实收所属投资或利润期间不同，`6/30`也仅为有限比较。缺拆分时保留已知分配和现金总额，勿用含利息的现金流合计倒填现金股利。

## 5. 估计、资产质量和敏感性

每个重大估计按“确认/计量目标→方法→重大假设→数据→披露”执行：

1. 将总额、准备和净额对至附注，明确计量日及对象边界；先判断用哪种计量基础，而非先选容易计算的模型。
2. 选择测试管理层过程、构造独立点估计/合理区间、使用计量日后证据的一种或组合；对输入数据完整性和准确性取证。
3. 复算模型，检查币种、期间、税前/税后、名义/实际和现金流/折现率一致，比较历史预测与实际，区分当时可知情况和新事件。
4. 对真正影响结论的参数做有依据的单项及组合情景，求临界条件；独立区间只包含有证据支持的结果，不扩大到刚好包住账面值。
5. 评价假设间一致性、管理层偏向、模型变化及披露。专家工作还需检查资格/客观性、范围、方法和基础数据，不能以签章替代测试。

| 对象 | 执行与工作例 | 追加资料、替代解释与关闭 |
|---|---|---|
| 普通企业应收准备 | 总额/准备分别滚动；期初准备10+计提5−核销4=期末11，不可称当期信用成本1。按经验证账龄和适用简化法重算矩阵，区分客户结构和损失率变化 | 低计提可能是信用改善，也可能少提；取逐笔账龄、争议、期后回款和损失率依据。只有公开余额时不声称验证完整ECL模型 |
| 存货NRV | 10件成本每件100，可靠预计售价97、销售费用5、无其他完工成本，NRV每件92，待比较跌价额80。分别记录转回和随销售转销 | 取库龄、期后售价、订单、完工/销售费用；仅价格下跌不一定决定原料应减值，须按用途及适用规则判断。数量/产权/成本另有认定程序 |
| 长期资产/商誉（按准则及对象分流） | CAS8/IAS36范围内先核资产组边界、账面值、VIU及FVLCD。该分支例：两年末现金各60，之后稳定年现金60，折现率10%、增长0，VIU=60/1.1+60/1.1²+600/1.1²=600；若有效FVLCD为620、账面650，则可收回620，差额30。US GAAP持有使用的有限寿命长期资产按ASC360先核未折现现金可收回性，未通过时再按账面超过公允价值计量损失；ASC350商誉常规定量路径比较reporting unit账面与公允价值，损失受分配商誉金额上限约束；无限寿命无形资产的定量测试另按其账面超过公允价值计量，不套上述VIU例 | 本例须有终值持续性、资本开支和税/折现口径支持才能提出减值30；若缺支持，仅为场景。先核各类测试对象、适用定性筛查/替代政策及税效；US GAAP同时测试长期资产与商誉时，先完成长期资产测试，未折现可收回不保证商誉无减值。订单下降、扩大资产组、持续预测失误可能推翻结论。CAS8、IAS36及US GAAP的转回与计量规则不混用；[来源索引](sources-and-standards.md#会计适用表)区分官方历史摘要、修订文件与现行全文取得边界，具体条件仍核报告期适用原文 |
| 折旧/摊销与研发 | 按可用日期、残值、寿命复算；将资本化对当期利润及未来摊销的影响单列，失败项目检查减值 | 取验收、项目条件、费用归属和可回收证据。寿命延长可能真实也可能延迟费用，不能从利润提升直接推舞弊 |

## 6. 重大错报风险：让风险直接决定程序

每条风险写成“事实/事件→可能错误处理→报表项目和认定→错报方向/范围→程序”。财报层风险（诚信、财务压力、普遍控制问题）与认定层风险分开；固有风险考虑复杂性、主观性、变化和不确定性，控制风险依据实际了解/测试，不能凭年报自评设低。

认定按所用准则表达。针对每项实际风险选择主认定，写明什么观察会构成错报或控制偏差、须如何量化；其他认定由相应程序覆盖，不在每项程序复制全部认定名称。例：从期后付款反查已收货未入账，主认定是负债完整性及截止；若付款对应本期末前已形成且未入账的义务，才形成需量化的例外，次年才收货则是反证。余额核对一致不覆盖所有认定。对金额重大但未识别具体风险的项目回看一次；新证据出现即修订风险和程序。

**工作例。** 收入增长30%，应收原值增长95%，合同资产增长150%。支持“提前确认/进度高估/减值不足”三个待核假说；并购、年末季节性、真实工程履约结算慢是竞争解释。先量化并表与结构变化；再取项目收入、合同、进度、验收、预计成本、期后回款/冲回，针对发生、截止、准确性及计价执行。仅凭这些同比不得写成已证实虚增收入。

问题关闭须说明哪项证据排除了哪个解释、剩余认定如何覆盖。风险评分若没有校准依据不冒充舞弊概率；不得“指标正常”即省略重要认定。[中国1211号](https://cicpa.org.cn/ztzl1/Professional_standards/xxzztx/zyzz/sjzz/202105/P020240412543439237956.pdf)

## 7. 重要性、总体与样本

有项目已经批准的重要性，引用其版本与期间；没有时提供候选基准/范围及选择理由，不能冒充项目已确定重要性。分别处理整体重要性M、特定类别/披露重要性、实际执行重要性PM和明显微小错报临界值。PM不是固定比例，明显微小不等于不重大；亏损、利润波动、契约和敏感披露影响判断。

选取之前定义总体、期间、抽样单元，核对总账/子账/合并包并验证完整性。区分全查、风险定向特定项目、统计或非统计抽样：

- 对重大、异常及相关高风险项目作特定选取，单列覆盖金额、选取理由和剩余总体。
- 对剩余总体依据风险、可容忍错报、预期错报及其他证据确定方法和规模；随机选择保留可重做标识，非统计也须解释规模。
- 记录抽样误差与非抽样误差；特定项目结果不能直接外推剩余总体，发现错误时调查机制并决定扩大范围/推断。

**例。** 项目已给M=5、PM=3，总体100，定向查最高风险项目40。发现错报1不能直接推断总体错报2.5，也不能声称已覆盖100；对40追查同类机制，再为剩余60设计程序。仅年报有总体合计100时不能编造交易级样本。小额错报改变契约或盈亏边界仍需定性分析。

**关闭条件。** 总体可靠、选择逻辑与风险一致、实际样本有证据、例外已处理、剩余总体有充分覆盖。不得写“抽查若干均正常”省掉总体和结果。[重要性指南](https://www.cicpa.org.cn/ztzl1/Professional_standards/Professional_guidelines/yifabu/201904/W020210421541566957063.pdf)

## 8. 控制和分析程序：分别实现程序目的

### 8.1 控制理解与测试

取流程、权限、审批记录、异常处理、配置/变更和系统报表逻辑。穿行一笔交易从发起到披露，用询问加检查/观察确认设计与实施；计划依赖控制或仅实质程序不足时，另测试拟依赖期间的运行。样本覆盖频率、人员变化和相关期间，检查复核精度及例外是否解决。自动控制需理解权限、变更、接口和所用报表。

**例。** 控制要求财务经理每月复核毛利异常。十二张签字表只证明签字，须检查月度总体、异常识别阈值是否足够精细、调查依据及纠正。仅观察12月一次不能证明全年运行。若发现异常未追查，评价控制缺陷并改变依赖/实质程序，不以财报没有发现错报证明控制有效。

记录控制目的、责任人、频率、证据、设计/实施、运行结果、偏差、依赖决定。财报审计中的控制工作与整体内控审计意见分开。

### 8.2 实质性分析与总体分析

风险评估分析发现异常；实质性分析须对具体认定获得证据；结束分析检验总体一致性。一项程序有多种目的时分别满足目的。

执行实质性分析前记录：认定→可预测经济关系→可靠独立输入→预期公式/区间→精度→调查阈值T（依据重要性和风险）→差异调查。禁止用账面结果反推参数消掉异常。

**例。** 经验证的租金合同面积、月费率和有效期间形成预期，并单独处理免租/变更及适用确认政策；若预期120、账面132，差异12超过事先确定T，则逐项核实新增租约、调价或错误。管理层“租金上涨”须转成带合同证据的金额桥。每月出现+15与−15不能只因全年相抵就关闭。

年报只有全年总额时，可完成趋势分析；不能不验证独立数据和预期精度就称实质性程序完成。[中国1313指南](https://www.cicpa.org.cn/xxfb/tzgg/202304/W020230410260829914094.pdf)、[PCAOB AS2305](https://pcaobus.org/oversight/standards/auditing-standards/details/AS2305)

## 9. 重点认定的实际取证程序

| 风险/认定 | 执行步骤与底稿 | 例外、反证与关闭条件 |
|---|---|---|
| 收入发生、完整与截止 | 从销售账追合同、发运/履约/验收查发生；从发运或验收总体追入账查完整；按业务周期确定期末前后窗口，检查退货/折让和合同变更 | 12月开票1月实质验收需调查截止；验收可为形式条款需合同反证。样本逐笔记录实际履约日期、金额、证据和调整 |
| 应收存在/计价与现金权利 | 控制函证对象、内容、地址、发送/直接接收和回函评价；未回函作适配替代程序；匹配期后回款到原债权及付款来源；另查质押、担保、现金池和账户完整性 | 公司转交回函、异常来源或金额错误仍“相符”须调查；回款也可能是循环资金。余额相符不关闭受限或减值认定；没有回函不自动通过 |
| 存货存在/完整/权利 | 从账到物、物到账双向检查，覆盖相关仓库和第三方保管；盘点日非期末时桥接收发；成本/NRV另测 | 盘点正确但客户寄存商品不应自动视为公司资产；只有年报不得写已监盘。未覆盖地点和数量差异明确未决 |
| 负债完整、资本化与截止 | 从期后付款、未匹配收货、供应商对账、法律/担保资料反查账；工程对实物进度、验收、资本化条件和转固；不能只从已入账应付抽样 | 次年付款对应上年已收货可揭示漏计；付款/发票不证明工程存在。待确认义务与已计负债避免重复 |
| 舞弊/管理层凌驾 | 分录总体对总账/试算表，覆盖结账后、合并调整和相关期间；按风险选异常用户、科目组合、冲回、交易对手及门槛交易，逐笔检验目的/证据；回顾估计偏向和非常规交易 | 周末或整数分录可有正常解释；完整导出有缺口时不能称全量测试。分析工具预警是线索，必须逐笔调查，未选总体也需考虑 |
| 关联方/资金占用/担保 | 比对披露名单、工商/控制、人员、银行/律师、会议和合同；把销售、采购、投资、资产转移与资金往来接到对手方，核查商业实质及审批/披露 | 同地址不单独证明关联；市场化声明不证明公允；已清偿后转回、迂回采购占用须追资金。匿名客户不猜身份 |

**串通工作例。** 销售合同、物流单、客户回函及回款齐全，但回款前企业通过异常供应商转出等额资金。重新评估四份文件是否来自同一串通链，追最终需求、运输能力、资金来源和隐藏条款；不能按“证据四份”累加可信度。不存在独立佐证时保留发生与商业实质未决。[中注协问题解答18/19](https://www.cicpa.org.cn/xxfb/tzgg/202501/t20250123_65228.html)、[中国银行函证指引](https://kjs.mof.gov.cn/zhengcefabu/202402/t20240206_3928340.htm)

## 10. 集团、收购和合并抵销

先建立实体—控制依据—并表日期—准则/政策差异的范围表，区分分部、法人和减值资产组。按风险及适用集团准则决定组成部分工作，金额小但特别风险成分不能仅因比例小而略过。

**范围变动的期间规则。** CAS33第32–33、38–44、49条区分：同控合并调整期初及比较报表，并按最终控制起点等适用条件纳入当期期初起的损益和现金流；非同控增加不追溯调整期初，仅纳入购买日起的损益和现金流；处置并丧失控制不改期初，保留期初至处置日的损益和现金流。不丧失控制的股权变动不能当作移出合并范围。原报、发行人正式重述、分析者按目标范围重建分别保存；有证据的分析重建也不冒称正式重述，缺组成部分明细或抵销时保留缺失和未知；选用条件输入时另标分析假设。其他准则另核，不能直接套用CAS同控规则。[财政部CAS33原文](https://www.mof.gov.cn/gp/xxgkml/hjs/201402/t20140220_2512607.htm)

**累计披露到单季的范围桥。** 先定义目标实体集合、纳入期间、政策及现金流分类；对每个参与判断的收入、成本或毛收付款项目X，按原表行名建立有符号调整，包含新增/剔除实体及纳入期间、内部抵销和其他已核口径差异。子公司单体现金流不能不经抵销直接加进集团。期间P的总调整记作ΔX_P：

```text
X_P_目标 = X_P_原报 + ΔX_P_实体及期间 + ΔX_P_抵销 + ΔX_P_其他口径
Q2_X_目标 = (H1_X_原报 - Q1_X_原报) + (ΔX_H1 - ΔX_Q1)
```

九个月减半年、全年减九个月同理，须逐项核对两份累计表的版本与范围，不由报表名称相同推定可减。两套完整现金口径还应满足`ΔCCE_期末−ΔCCE_期初=ΔCFO+ΔCFI+ΔCFF+Δ汇率影响`，这里Δ均指同一期间“目标口径减原报”的差，不是期内增减。期初现金差只能进入对应存量桥，不能分配成全期客户收款、采购付款或某季度调整；两版净CFO相等也不能证明各毛收付款相等。缺明细时保留原报、净额约束及未闭合分项，由[量化接入方法](quantitative-analysis.md#先把真实企业接入模型)检验其对预测和判断的影响，不倒填分项。

取得合并包、政策调整、抵销分录、购并/处置协议和组成部分工作；复算内部余额/交易、未实现利润、投资与权益、购买价分摊、汇率和现金流抵销。记录组成部分审计师沟通、能力/独立性、范围/重要性、实际复核及追加工作；本地无保留意见不等于已满足集团政策和重要性。

**工作例。** 母公司将成本80的商品以100卖给子公司，期末全部未对外出售且无其他差异。合并收入/成本中的内部交易应抵销，存货还应剔除未实现利润20；再评价递延税等影响。若已对外售出60%，不能仍按全额20抵销，要核实剩余内部利润8及存货状态。年报没有交易明细时仅列需验证的抵销，不能虚构分录已复核。

收购时对价、非控股权益、原持权益与可辨认净资产依适用规则桥到商誉；同控/非同控处理分开。增长桥单列并表贡献，权益法利润单列现金分红。关闭需范围和抵销有支持、组成部分未决已汇总、聚合风险已评价；收入/资产覆盖率本身不能证明证据充分。中国1401现行版与ISA600新版/PCAOB其他审计师规则按法域分别核实。

## 11. 持续经营：把缓解措施放进现金预测验证

分开判断：会计基础适当性、重大不确定性、披露、证据充分性。按适用规则锁定起算日和覆盖期间；中国1324目前涉及报表日起至少十二个月，ISA570新版改为报表批准日起至少十二个月，PCAOB AS2415又有自己的期间规定，不统一写成模糊“未来一年”。

执行步骤：

1. 列出尚未考虑缓解措施的亏损、违约、契约、到期和经营压力；取得逐月/更细现金预测、合同、回款计划及管理层评估。
2. 按实体/币种区分可用与受限现金，计算 `期末可用现金=期初可用现金+经营收款−经营付款−必要资本开支−到期本息+有证据支持的可用融资`。
3. 测基本、下行及相关因素组合场景，给最低余额、缺口时点、契约余量及使余量耗尽的临界条件；不以全年现金流为正掩盖月度缺口。
4. 检验计划的意图和能力：续贷条件、已承诺额度、处置限制、支持方财力和支持条款。口头意向、历史续贷或支持函签章不能当现金已可用。

**例。** 账面现金80，受限30，期初可用50；下月收款40、经营付款70、到期本息60、经验证可提款融资20，则缺口20。拟新增贷款40若仅为意向，可另列“落实后”情景，不能据此关闭缺口。须取得可执行承诺、修订付款/收款的真实依据或其他可行措施，并重新检查压力情景。

产出现金期限表、假设证据、情景、缓解措施可执行性、披露与意见分支；仅有公开资料时明确哪些预测仍不能验证，不用Z分数或资产负债率替代上述程序。[中国1324指南](https://cicpa.org.cn/xxfb/tzgg/202304/W020230410260829949768.pdf)

## 12. 期后事项、期初余额和其他信息

**期后事项。** 建表记录事件发生日、获知/披露日、是否反映报表日既有状况、金额/披露影响、证据及适用责任期间。报告日前程序与报告后获知事实分别处理。取最新管理报表、收付款、会议、诉讼、融资与重大交易，不以网上没有新闻证明没有事项。

**例。** 1月客户破产：若12月已严重逾期且经营困难，可能提供年末减值证据；若由1月独立灾害首次造成，则不能仅因破产日期就把全部损失调整进上年，但仍评价披露及其他影响。结论以报表日前事实和适用准则为依据。

**期初/比较信息。** 首次业务取前任沟通及期初余额证据；上期非标事项逐项跟踪对本期余额、损益和比较数的影响。正式重述逐行桥接，管理层称已整改不等于历史影响消失。关闭必须说明旧事项已解决的证据及仍延续的金额。

**其他信息。** 把董事会报告/经营讨论中的重要量化和定性主张对到报表或可靠运营资料，复算同比及非GAAP调节，判断不一致来自报表、其他信息还是口径。例：董事会称经营现金改善，报表CFO由50降至20，先核实其是否指不同指标；若无合理定义与调节，提出明确更正事项。年报中的其他信息不自动属于财报审计意见覆盖范围。

## 13. 错报汇总、报告意见与沟通

把待核异常与已识别错报分开；错报区分事实、判断、抽样推断，逐项记录本期/前期、已更正/未更正、受影响科目、税/少数股东/现金影响、重叠关系及披露影响。来自不同程序的同一错报只计一次；未经支持的有利差异不拿来抵销不利差异。

将最终重要性与单项、汇总及定性因素一起评价；重新看相关认定的证据、控制缺陷、未决事项和结束分析。书面声明不替代其他合理可取得证据。输出结案支持备忘录与治理层沟通草稿，报告事实、金额、原因、回应、未决动作及决定事项。

**例。** 已证实存货跌价少计2、应计费用少计1，均提高本期税前利润，合计影响3；两项分别被成本分析和负债测试发现，不能重复合计6。另有无法取得凭证的收入余额10，不能把全部10自动加作已知错报，但须单独评价可能错报范围、重要性及广泛性。

| 证据及影响 | 意见形成支持路径 |
|---|---|
| 充分适当证据支持财报按适用基础编制、无重大错报 | 可支持无保留方向；“没有取得反证”不满足此条件 |
| 已知错报重大、不广泛 | 保留方向 |
| 已知错报重大、广泛 | 否定方向 |
| 缺乏充分适当证据，可能影响重大、不广泛 | 保留方向 |
| 缺乏充分适当证据，可能影响重大、广泛 | 无法表示方向 |
| 持续经营基础适当、存在重大不确定性且充分披露 | 按适用持续经营准则单独报告，不自动改为非无保留 |
| 持续经营基础不当、披露不足或证据不足 | 分别走基础错报、披露错报或范围受限路径，不能统一塞入强调事项 |

广泛性不是统一金额百分比。KAM/CAM分别按所适用准则判断，既不是单项审计意见，也不替代非无保留；强调事项和其他事项也不能替代。读取已发布审计报告时提取其意见、基础、KAM/CAM、持续经营、强调/其他事项及上年变化，并说明对本次分析的影响；不得从无保留推导无舞弊、无风险或所有经营数据真实。

只有公开年报时，可以提出上述条件分支和证据缺口，不能生成声称本次实施了未执行程序的签字审计报告。[中国1502号](https://www.cicpa.org.cn/ztzl1/Professional_standards/xxzztx/zyzz/sjzz/202105/P020210507610953191495.pdf)、[PCAOB AS2810](https://pcaobus.org/oversight/standards/auditing-standards/details/AS2810)

## 14. 交付时让未决工作可以继续执行

每个未决项写成一句可操作指令加关闭条件，例如：“请收入负责人提供项目A的合同变更、截至12月31日进度确认和期后验收；审计负责人将其与累计收入及预计总成本逐项复算，确认是否跨期及量化差异；差异完成更正或完成重要性评价后关闭。”不要只写“关注收入真实性”或“建议进一步核查”。

交付按当前任务合并成必要底稿：口径/事实定位、关键计算和桥、会计判断与估计、实际审计程序及例外、错报与未决/意见支持。复核关键计算和会改变结论的假设即可，不为了专业外观增加无关检查。

结束前确认五件事：关键数能回到原件并重算；调整没有重复计入或改写原报数；重要解释有支持也处理了反证；实际完成与待执行明确；另一位专业人员凭资料请求及关闭条件能继续工作。无法区分两种解释时，准确写出未决及决定性证据，本身就是有效工作成果。

主要规则入口：[财政部会计准则/解释](https://www.mof.gov.cn/zaixianfuwu/zxcx/kjzz/)、[CICPA现行审计准则](https://www.cicpa.org.cn/ztzl1/Professional_standards/xxzztx/zyzz/sjzz/)、[IFRS已发布准则](https://www.ifrs.org/issued-standards/list-of-standards/)、[IAASB正式发布](https://www.iaasb.org/standards-pronouncements)、[PCAOB审计准则](https://pcaobus.org/oversight/standards/auditing-standards)。正式准则优先于实施示例；专业方法不等于法律条款，发行人披露不等于独立验证。网页超时或完整准则需授权时记录访问状态，引用已实际取得的内容，不能声称完成未读取文本的核查。
