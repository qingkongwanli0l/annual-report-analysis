# 会计口径与财务核对

本文件提供分析约束，不替代准则原文。先读取被分析企业的编制基础、实际采用的会计政策与生效期间；处理具体会计争议时核对对应期间的主管机构文件。核验日期：2026-10-02。

## 准则与期间

- A 股默认从年报披露的中国企业会计准则（CAS）出发。不能仅由上市地点推定准则，也不能把 CAS、IFRS、HKFRS、US GAAP 数据直接视为同口径。
- 财务报表至少覆盖资产负债表、利润表、现金流量表、所有者权益变动表和附注。审计报告另行记录，不能用三张表或摘要替代完整财务报告。[财政部 2014 年修订 CAS 30](https://kjs.mof.gov.cn/zhengcefabu/201401/t20140128_1040393.htm)
- 财会〔2026〕11号修订 CAS 30：境内外同时上市及通知规定的境外上市企业自 2027-01-01 执行；其他境内上市企业自 2029-01-01 执行；执行 CAS 的非上市企业自 2030-01-01 执行，允许提前执行。应依据企业类型、分析期间和实际提前执行披露确定适用版本；不得把新格式追套到尚未执行的旧报告。新旧利润表分类和小计变化须有披露调节才能比较。[财政部正式通知](https://kjs.mof.gov.cn/zhengcefabu/202608/t20260805_3994927.htm)
- 保险合同、金融工具、收入、租赁等政策存在首次执行或变更时，读取过渡安排和可比期处理；不要只凭政策名称推定全年可比。保险企业的 CAS 25 实施状况以实际披露及适用通知核对。[财政部准则入口](https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/)
- IFRS 18 适用于 2027-01-01 或之后开始的年度期间，允许提前采用；HKFRS 18 的生效年度起点同为 2027-01-01。核对企业实际采用情况和比较期调节，不仅看年报发布日期。[IFRS Foundation](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-18-presentation-and-disclosure-in-financial-statements/)、[HKICPA](https://www.hkicpa.org.hk/en/Standards-setting/Standards/New-and-major-standards/New-and-Major-Standards/HKFRS18)
- IFRS/HKFRS/US GAAP 报告先保留其报告基础，不自动换算为 CAS。涉及跨准则差异时查官方原文；缺少调节数据则明确不可直接比较。

## 报表身份与比较基础

- 合并资产、收入、现金流不能与母公司单体利润混用；合并净利润、归母净利润、少数股东损益分别记录。总权益与归母权益也必须分开。
- 存量指标记录资产负债表日；期间指标记录开始日和结束日。区分年度、半年度、季度和滚动期间。非完整年度不默认年化。
- 核对币种、元/千元/万元/百万元以及百分比/百分点。先保留原始值和单位再换算；不要对不同币种直接求和。
- 优先使用同一报告中按当期政策列示的可比数据。更正、追溯重述、合并范围变化、终止经营和收购影响应单独解释；原披露值不得悄悄覆盖。
- 非经常性损益按适用版本的证监会要求读取，分析企业已披露的扣非调节和税收、少数股东影响。不得把所有非现金项目或一次性项目直接认定为扣非项目。[证监会 2023 年修订公告](https://www.csrc.gov.cn/csrc/c101954/c7451398/content.shtml)
- EBITDA、自由现金流、调整后利润等是分析口径或企业自定义指标，并非通用法定利润项目。保留定义、调节和局限，与原报表利润并列；不能用它们替代原数。

## 勾稽与解释

| 检查 | 使用口径 |
| --- | --- |
| 资产 − 负债 − 权益 | 同一主体、日期、币种与单位 |
| 合并净利润 − 归母净利润 − 少数股东损益 | 同一期间合并利润口径 |
| 期末现金及现金等价物 − 期初余额 | 与经营、投资、筹资净现金流及汇率变动影响合计核对 |
| 期末权益 − 期初权益 | 与综合收益和已披露所有者交易等权益变动项目核对 |

“货币资金”不当然等于现金及现金等价物；受限资金等差异要依据现金流量表附注解释。没有汇率影响披露不能自动补零。权益桥缺项就标记无法完整核对，不能把差额写成虚构的所有者交易。

舍入容差以原报表显示精度为基础，不能用资产总额的任意百分比掩盖差异。勾稽通过只说明指定数据关系成立，不能证明没有错报。

ROA/ROE、资产周转等使用一致口径的期初期末平均余额；这只是明确标注的分析口径，不冒充企业披露的加权平均净资产收益率。缺少期初数据不以期末余额偷偷替代。负利润、负权益和零分母需限制比率解释。

## 审计、附注和风险表述

分别记录审计意见类型、形成意见的基础、持续经营重大不确定性、强调事项和关键审计事项。无保留意见附持续经营段不等于保留意见；关键审计事项不等于错报或造假证据。

对收入确认、应收与减值、存货、商誉、研发资本化、关联交易、担保和诉讼，至少区分：披露事实、会计判断或估计、数据异常、待核实问题。没有完整交易与政策证据时，不下“违反准则”或“财务造假”的定论。
