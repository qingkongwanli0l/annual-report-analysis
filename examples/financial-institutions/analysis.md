# 金融机构真实数据工作例

银行及华泰证券案例的信息截止日为2026-06-30，其余案例为2026-10-02；来源核验截至2026-10-06。目的：演示如何把公开披露转成能复算、能反证、能继续取证的金融分析。以下是相互独立的主体案例，不能将不同企业的资本、合同负债、客户资金或清算资源拼成同一实体模型。程序索引见 [金融机构操作参考](../../skills/annual-report-analysis/references/financial-institutions.md)。

本例实际执行了公开正文取数、算术复算和部分跨表核对；银行案例进一步连接自身信用、支持和具体资本工具的履约风险。未执行客户存管确认、逐笔ECL/精算模型验证、完整监管压力测试或清算会员违约压力测试；银行的VR及资本债基准是下文明确判断条件下的研究结果，主体支持仍有未决分支；其余案例未形成字母级建议。这些公开分析不构成机构正式评级、模型校准或审计保证。

## 一、民生银行：从年报到自身信用、支持和资本工具

本例以2025年末为主要财务观察时点，用2022–2025年完整年度及截至2026年六月已知的一季报，按FB26区分自身生存能力、外部支持和指定债项。自身信用研究中央VR为bb；以此和实际合同为锚，两只资本债基准分别B+、B−。主体并列典型支持、银行特定中性时BBB+与额外弱一档假设时BBB，尚未选定无此条件的唯一主体级别；主权与国家上限已核至6月15日行动，6月16—30日完整变更历史未取得。未用机构已发表的民生主体、VR或因素分数校准这些研究判断，也未将国内尺度换成国际尺度。

执行及结果：

1. `222,855−122,729=100,126`；同比`100,126/98,690−1=1.4551%`。净息差`100,126/7,148,910=1.4006%`，与披露1.40%相符。
2. 以2024隐含贷款收益率为固定基准，量贡献`(4,444,801−4,414,436)×(174,559/4,414,436)=+1,200.72`；价格贡献`4,444,801×(152,010/4,444,801−174,559/4,414,436)=−23,749.72`；合计`−22,549`，恰等于贷款利息收入变动。量、价交互按本顺序分给价格项；这不是使用已舍入3.42%/3.95%做出的近似。
3. 本例定义“减值前营业利润”为收入扣业务管理费、税金及附加和其他业务成本，2025为`142,865−51,006−1,701−2,604=87,554`；2024为80,284，增加7,270。它是本例定义的小计，不冒称评级机构PPOP原指标。
4. `87,554−53,950−761−584=32,259`（税前）；再减1,677得30,582；减少数19得归母30,563。2025利润桥残差0。

**判断MS-F1（有支持但有边界）：** 净利息收入改善与利息支出下降有关，贷款利息的价格压力仍明显；减值前小计增加7,270，但信用减值增加8,476，不能从营收增长直接推导净利润质量提高。**反证：** 主动提高风险覆盖可改善未来韧性；低收益贷款占比变化也可压低隐含收益率，不一定全是单一客户降价。**追加MS-P1：** 向财务/业务取得产品和客群平均余额、定价与迁徙，固定组合重算量价，区分结构和纯价格；结果未取得前保留两种解释。

MS25印刷120页/PDF122还显示：摊余成本金融资产终止确认收益由1,867升至6,553，公允价值变动由损失1,353转为收益3,356；印刷46页/PDF48解释主动债券交易及市场价格回升的影响。FB26 p52的OP需要从税前利润逐项判断非经营调整；本例保留税前32,259及报表营业利润32,843，分别除期末RWA6,011,048得0.5367%及0.5464%，均不冒称最终Fitch OP比率。投资/交易业务可能持续，不能机械剔除全部投资收益；会计“营业外”标签也不能替代该方法的非经营判断。

### 2. 准备桥闭合，但不等于验证ECL模型

MS25印刷41页/PDF43的贷款准备表：

| 人民币百万元 | 2025 |
|---|---:|
| 期初准备 | 93,129 |
| 本期净计提 | +47,901 |
| 核销及转出 | −52,477 |
| 收回已核销贷款 | +7,759 |
| 其他 | −2,346 |

`93,129+47,901−52,477+7,759−2,346=93,966`，残差0；期末仅增加837。印刷196页/PDF198附注把回收及其他合计列为5,413，`7,759−2,346=5,413`，因此第二种表述`93,129+47,901−52,477+5,413`亦闭合。不能两种表述同时相加。

以原表贷款平均余额计算本例贷款信用成本`47,901/4,444,801=1.0777%`，不是`837/平均贷款`。它仅覆盖本表贷款净计提，不能用集团信用减值53,950替换分子还称同一指标。

**判断MS-F2：** 大量核销/转出与回收影响准备余额，837不能代表当年损失费用。**反证：** 桥闭合仅证明披露勾稽，不能说明PD、LGD、抵押回收及前瞻假设充分。印刷250–251页/PDF252–253披露信用减值定义、PD/LGD/EAD框架及GDP等前瞻变量，尚未给出可逐笔重算的参数和权重。**追加MS-P2（awaiting_data）：** 在下述公开阶段余额基础上，向信用模型/财务索取阶段迁徙与核销转出台账、SICR执行记录、具体情景权重和overlay；复核最大迁徙池及最大核销资产的分类、回款和模型重算。

### 3. 分类及资本共同检验

MS25印刷37页/PDF39的2025年末数据：贷款毛额4,430,610；正常类4,243,261；关注类121,195；次级13,879、可疑10,939、损失41,336；不良合计66,154。先算`4,243,261+121,195+13,879+10,939+41,336=4,430,610`，再算：

- 不良率`66,154/4,430,610=1.4931%`，披露1.49%；关注率`121,195/4,430,610=2.7354%`，披露2.74%。
- 准备覆盖率`93,966/66,154=142.0413%`，披露142.04%。
- 2024不良65,610，净增加544；没有形成/回收/上调全桥，不把544称“新生成不良”。五级分类不能凭汇总表自动映射Stage 2/3。

方法第 3、7—8 页规定的六因素权重依次为：业务 20%、风险 10%、资产质量 20%、盈利 15%、资本 25%、资金流动性 10%。经营环境（OE）决定适用矩阵与限制，不另占第七个权重。除资本用最近可用时点外，核心财务指标以可得四个完整年度的简单均值起步；比率先逐年计算再平均，不将四年分子、分母合并。指标先落到不含 +/- 的 implied 档，再结合前瞻与定性证据确定含 +/- 的 assigned 分数。

第 8 页的计分为 `aaa=1, aa+=2, …, a=6, a-=7, bbb+=8, bbb=9, bbb-=10, bb+=11, bb=12, bb-=13, b+=14, b=15, b-=16, ccc+=17, …, c=21`。加权数四舍五入至相邻整数；精确半档取较小数、较好评级。因此 11.50→11→bb+，12.50→12→bb。该公开规则足以计算研究 implied VR，不需要臆造内部委员会参数。

### 9. 支持如何到主体等级

CN26第1页明确中国外币/本币长期主权 `A`、展望稳定及国家上限 `A` 均获维持；第19页的2026-06-15签署日期与Press Release ID 10349249确认该次行动身份，不只依赖URL日期。该表补足六月行动的原始评级字段，未取得的关联公告正文及6月16—30日完整变更历史仍是资料缺口。以下主体分支以这些国家输入在截止日仍适用为条件，不因取得主权评级就认定民生获得相同级别的支持。方法第16—18页由政府能力、整体支持倾向和银行特定倾向判断GSR；在支持倾向高的条件下，A类主权对应典型D-SIB通常低1—2档，故研究起点区间为 `a-`—`bbb+`。

[人民银行2026-02-13官方名单](https://www.pbc.gov.cn/huobizhengceersi/214481/3868581/3868587/2026021318433023031/index.html)将民生列入2025年度国内系统重要性银行第一组。这足以支持系统重要性研究，不要求额外达到10%全国市占率。[财政部2025-03-31注资安排](https://www.mof.gov.cn/zhengwuxinxi/caizhengxinwen/202503/t20250329_3961036.htm)展示对系统银行资本补充的政策行动；发布日期取正文，不取URL中的29日。该安排针对所列国有银行，**不是民生的注资承诺**。系统体量与财政潜在责任支持保留典型范围较低端bbb+，但这仍是研究选择，尚非已量化证明政府只能支持到此级别；a-较强端并列保留。

方法p17要求负债结构的负向影响同时有高级债权人受损在政治上可接受、且不会威胁金融稳定的依据。年报的企业/市场融资占比说明资金结构，尚未证明这些债权人比典型中国D-SIB更可被要求承担损失，亦未证明跨行传染较小。资本工具PONV只证明资本层可吸损，不能替代高级债层证据。因此本例将**典型bbb+、银行特定因素中性→GSR bbb+→主体BBB+**与**额外假设高级债支持弱一档→GSR bbb→主体BBB**同等列示，后者不再称为已核实的中央决定。无控股股东、大家系持股及保险保障基金背景既不构成无条件担保，也不足以单独支持负向所有权调整。具体高级债处置政策、及时救助记录、债权人构成及传染差异，才是区分这些路径的后续证据。
