# 金融机构真实数据工作例

银行案例的信息截止日为2026-06-30，其余案例为2026-10-02；来源核验截至2026-10-03。目的：演示如何把公开披露转成能复算、能反证、能继续取证的金融分析。以下是相互独立的主体案例，不能将不同企业的资本、合同负债、客户资金或清算资源拼成同一实体模型。程序索引见 [金融机构操作参考](../../skills/annual-report-analysis/references/financial-institutions.md)。

本例实际执行了公开正文取数、算术复算和部分跨表核对；银行案例进一步连接自身信用、支持和具体资本工具的履约风险。未执行客户存管确认、逐笔ECL/精算模型验证、完整监管压力测试或清算会员违约压力测试；银行的VR及资本债基准是下文明确判断条件下的研究结果，主体支持仍有未决分支；其余案例未形成字母级建议。这些公开分析不构成机构正式评级、模型校准或审计保证。

## 一、民生银行：从年报到自身信用、支持和资本工具

本例以2025年末为主要财务观察时点，用2022–2025年完整年度及截至2026年六月已知的一季报，按FB26区分自身生存能力、外部支持和指定债项。自身信用研究中央VR为bb；以此和实际合同为锚，两只资本债基准分别B+、B−。主体并列典型支持、银行特定中性时BBB+与额外弱一档假设时BBB，尚未选定无此条件的唯一主体级别；主权与国家上限仅核至1月公开原件，六月最新性未核实。未用机构已发表的民生主体、VR或因素分数校准这些研究判断，也未将国内尺度换成国际尺度。

执行及结果：

1. `222,855−122,729=100,126`；同比`100,126/98,690−1=1.4551%`。净息差`100,126/7,148,910=1.4006%`，与披露1.40%相符。
2. 以2024隐含贷款收益率为固定基准，量贡献`(4,444,801−4,414,436)×(174,559/4,414,436)=+1,200.72`；价格贡献`4,444,801×(152,010/4,444,801−174,559/4,414,436)=−23,749.72`；合计`−22,549`，恰等于贷款利息收入变动。量、价交互按本顺序分给价格项；这不是使用已舍入3.42%/3.95%做出的近似。
3. 本例定义“减值前营业利润”为收入扣业务管理费、税金及附加和其他业务成本，2025为`142,865−51,006−1,701−2,604=87,554`；2024为80,284，增加7,270。它是本例定义的小计，不冒称评级机构PPOP原指标。
4. `87,554−53,950−761−584=32,259`（税前）；再减1,677得30,582；减少数19得归母30,563。2025利润桥残差0。

**判断MS-F1（有支持但有边界）：** 净利息收入改善与利息支出下降有关，贷款利息的价格压力仍明显；减值前小计增加7,270，但信用减值增加8,476，不能从营收增长直接推导净利润质量提高。**反证：** 主动提高风险覆盖可改善未来韧性；低收益贷款占比变化也可压低隐含收益率，不一定全是单一客户降价。**追加MS-P1：** 向财务/业务取得产品和客群平均余额、定价与迁徙，固定组合重算量价，区分结构和纯价格；结果未取得前保留两种解释。

MS25印刷120页/PDF122还显示：摊余成本金融资产终止确认收益由1,867升至6,553，公允价值变动由损失1,353转为收益3,356；印刷46页/PDF48解释主动债券交易及市场价格回升的影响。FB26 p52的OP需要从税前利润逐项判断非经营调整；本例保留税前32,259及报表营业利润32,843，分别除期末RWA6,011,048得0.5367%及0.5464%，均不冒称最终Fitch OP比率。投资/交易业务可能持续，不能机械剔除全部投资收益；会计“营业外”标签也不能替代该方法的非经营判断。

### 2. 准备桥闭合，但不等于验证ECL模型
