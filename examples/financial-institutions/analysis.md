## 一、民生银行：收入增长如何传至准备、资本和流动性

### 1. 先复算经营与利润，再问增长质量

从MS25印刷28–29页逐行取数，不混集团净利润和归母净利润：

| 人民币百万元，年度流量除平均余额外 | 2025 | 2024 |
|---|---:|---:|
| 营业收入 | 142,865 | 136,290 |
| 利息收入 | 222,855 | 251,086 |
| 利息支出（正数列示成本） | 122,729 | 152,396 |
| 利息净收入 | 100,126 | 98,690 |
| 业务及管理费 | 51,006 | 51,318 |
| 税金及附加 | 1,701 | 1,780 |
| 其他业务成本 | 2,604 | 2,908 |
| 信用减值损失 | 53,950 | 45,474 |
| 其他资产减值损失 | 761 | 466 |
| 营业外收支净额 | −584 | −259 |
| 所得税费用 | 1,677 | 1,363 |
| 集团净利润 | 30,582 | 32,722 |
| 归母净利润/少数股东损益 | 30,563 / 19 | 32,296 / 426 |
| 贷款平均余额 | 4,444,801 | 4,414,436 |
| 贷款利息收入 | 152,010 | 174,559 |
| 平均生息资产 | 7,148,910 | 7,077,785 |

执行及结果：

1. `222,855−122,729=100,126`；同比`100,126/98,690−1=1.4551%`。净息差`100,126/7,148,910=1.4006%`，与披露1.40%相符。
2. 以2024隐含贷款收益率为固定基准，量贡献`(4,444,801−4,414,436)×(174,559/4,414,436)=+1,200.72`；价格贡献`4,444,801×(152,010/4,444,801−174,559/4,414,436)=−23,749.72`；合计`−22,549`，恰等于贷款利息收入变动。量、价交互按本顺序分给价格项；这不是使用已舍入3.42%/3.95%做出的近似。
3. 本例定义“减值前营业利润”为收入扣业务管理费、税金及附加和其他业务成本，2025为`142,865−51,006−1,701−2,604=87,554`；2024为80,284，增加7,270。它是本例定义的小计，不冒称评级机构PPOP原指标。
4. `87,554−53,950−761−584=32,259`（税前）；再减1,677得30,582；减少数19得归母30,563。2025利润桥残差0。

**判断MS-F1（有支持但有边界）：** 净利息收入改善与利息支出下降有关，贷款利息的价格压力仍明显；减值前小计增加7,270，但信用减值增加8,476，不能从营收增长直接推导净利润质量提高。**反证：** 主动提高风险覆盖可改善未来韧性；低收益贷款占比变化也可压低隐含收益率，不一定全是单一客户降价。**追加MS-P1：** 向财务/业务取得产品和客群平均余额、定价与迁徙，固定组合重算量价，区分结构和纯价格；结果未取得前保留两种解释。

### 2. 准备桥闭合，但不等于验证ECL模型

MS25印刷41页的贷款准备表：

| 人民币百万元 | 2025 |
|---|---:|
| 期初准备 | 93,129 |
| 本期净计提 | +47,901 |
| 核销及转出 | −52,477 |
| 收回已核销贷款 | +7,759 |
| 其他 | −2,346 |
| 期末准备 | 93,966 |

`93,129+47,901−52,477+7,759−2,346=93,966`，残差0；期末仅增加837。印刷196页附注把回收及其他合计列为5,413，`7,759−2,346=5,413`，因此第二种表述`93,129+47,901−52,477+5,413`亦闭合。不能两种表述同时相加。

以原表贷款平均余额计算本例贷款信用成本`47,901/4,444,801=1.0777%`，不是`837/平均贷款`。它仅覆盖本表贷款净计提，不能用集团信用减值53,950替换分子还称同一指标。

**判断MS-F2：** 大量核销/转出与回收影响准备余额，837不能代表当年损失费用。**反证：** 桥闭合仅证明披露勾稽，不能说明PD、LGD、抵押回收及前瞻假设充分。**追加MS-P2（awaiting_data）：** 向信用模型/财务索取分阶段毛额和准备迁徙、核销转出台账、SICR、情景权重和overlay；复核最大迁徙池及最大核销资产的分类、回款和模型重算。本例未宣称已获取。

### 3. 分类及资本共同检验

MS25印刷37页2025年末数据：贷款毛额4,430,610；正常类4,243,261；关注类121,195；次级13,879、可疑10,939、损失41,336；不良合计66,154。先算`4,243,261+121,195+13,879+10,939+41,336=4,430,610`，再算：

- 不良率`66,154/4,430,610=1.4931%`，披露1.49%；关注率`121,195/4,430,610=2.7354%`，披露2.74%。
- 准备覆盖率`93,966/66,154=142.0413%`，披露142.04%。
- 2024不良65,610，净增加544；没有形成/回收/上调全桥，不把544称“新生成不良”。五级分类不能凭汇总表自动映射Stage 2/3。

MS25印刷41页监管并表集团数据：

| 人民币百万元，期末 | 2025 | 2024 |
|---|---:|---:|
| CET1净额 | 563,554 | 546,689 |
| 一级资本净额 | 689,364 | 642,503 |
| 总资本净额 | 784,943 | 752,993 |
| 信用RWA | 5,669,106 | 5,514,242 |
| 市场RWA | 86,959 | 72,720 |
| 操作RWA | 254,983 | 255,754 |
| 总RWA | 6,011,048 | 5,842,716 |

1. 三类RWA相加6,011,048，残差0；资本率依次为9.3753%、11.4683%、13.0583%，舍入为披露9.38%、11.47%、13.06%。
2. CET1率变化精确拆为资本金额贡献`(563,554−546,689)/5,842,716=+0.288650个百分点`，RWA贡献`563,554×(1/6,011,048−1/5,842,716)=−0.270108个百分点`；合计`+0.018542个百分点=+1.8542bp`。披露两位小数的9.38%−9.36%=2bp是舍入后的差。
3. 报告印刷41页明确该主体该报告期含缓冲的CET1要求为7.75%；仅在此范围内，静态金额余量`563,554−6,011,048×7.75%=97,697.78`。它不是普适红线或可直接释放现金，也没有纳入新增损失、RWA迁徙、分红或未来监管变化；一级/总资本等仍须分别检查。

**判断MS-F3：** CET1金额增加几乎被RWA增加抵消，比率温和上升并不等于扩张资本消耗很小。**反证：** RWA变化可能来自模型、权重、范围和组合，不能只归因于信用恶化。**追加MS-P3：** 从同年第三支柱取得RWA量/组合/方法桥、资本扣减、分红和工具变动；与风险部门联动重算损失及RWA压力。不用净资产或集团总资产代替上述监管分母。

### 4. 流动性比率下降意味着继续查什么

MS25印刷42页2025 HQLA958,739、30天净流出707,036；2024分别1,086,316及670,628。复算2025 LCR135.5997%，与135.60%相符；2024按已舍入金额复算161.9849%，原表161.99%，保留0.0051个百分点差异，不强改原数。

两期按金额复算的LCR下降26.3851个百分点；2025 HQLA减净流出为251,703。该差额仅是监管加权口径的静态差，不能称“可自由支配现金”。2025年NSFR原表104.85%，本例未取得并复算其可用/所需稳定资金分子分母，因此标为“披露指标”。

**判断MS-F4（有限）：** 披露LCR缓冲收窄，值得追存款集中、HQLA受限和日内峰值；年末高于该报告所述要求并不能证明各币种压力资金充裕。**反证：** 若下降主要来自有意优化闲置缓冲且资金更稳定，风险含义会不同。**追加MS-P4：** 向资金部门取存款分层及前十大客户、HQLA质押清单、30天每日流出与可用额度合同；先排除同一债券重复出售/质押，再按日期递推现金，完成后才给生存期。

本例银行支持/债项条款尚未读取最终募集说明书，因此不输出支持提升级数、债项等级或赎回预测。下一步按B8取得本次被分析债项的发行主体、顺位、减记及赎回条件。

## 二、保险：CSM、承保和资本分别闭合

### 1. 平安寿险及健康险：CSM减少如何解释

PA25第56页，人民币百万元：

| 项目 | 2025 | 2024 |
|---|---:|---:|
| 期初CSM A | 731,312 | 768,440 |
| 新业务贡献 B | 36,688 | 35,405 |
| 新业务保费现值 C | 440,940 | 395,481 |
| 预期利息 E | 22,801 | 24,051 |
| 调整CSM的估计变更 F | +2,505 | −25,444 |
| 摊销基础 G | 793,306 | 802,452 |
| 摊销 H | −68,187 | −71,140 |
| 期末CSM I | 725,119 | 731,312 |

1. `A+B+E+F=731,312+36,688+22,801+2,505=793,306`；再减68,187得725,119，两层残差均0；2024期末等于2025期初。
2. 2025新业务利润率`B/C=8.3204%`，原表8.3%；2024为8.9524%，原表9.0%。B同比增长3.6238%，但利润率下降，不能只看贡献额增长。
3. `期末−期初=−6,193`；新业务、利息和估计变更合计61,994，小于释放68,187。描述性释放率`68,187/793,306=8.5953%`，新业务/释放53.8050%；这些是本例聚合描述，不是每合同组保障单位摊销率或监管指标。

**判断PA-F1：** CSM下降可以由释放与各类增量共同解释，不能直接断言获客失败；同时新业务利润率下降构成对“价值改善”的反证。原表脚注明确F包含适用VFA业务的保险合同金融风险变动，因此本例不把2,505全部称为运营假设改善。

**追加PA-P1（limited）：** 向精算/财务取得合同组和分部经审计CSM/RA/履约现金流调节、保障单位、亏损合同、新业务与金融假设拆分，再将服务释放连接保险服务收入/费用、持有再保结果及保险金融损益/OCI。演示稿数据不足以完成整个利润桥、验证准备充分或将CSM转成资本；本例未将725,119当现金/权益，也未将B/C误叫NBV利润率。

### 2. 太平财险：承保比率与投资、偿付资本

以下更换为TP24的太平财险2024年，不能与平安CSM相接。人民币亿元，除比率外：保险服务收入302.09、保险服务费用290.86；综合赔付率68.74%、费用率31.09%；净利润7.33；PDF第14页投资表利息收入6.54、投资收益−4.61、公允价值变动10.30、利息支出1.37、投资收益净额原表10.87。

- 综合成本率`68.74%+31.09%=99.83%`。`302.09−290.86=11.23`仅为这两行的差，不是完整保险服务业绩，更不是净利润；还需再保、金融及其他项目。
- 已取得投资四项合计`6.54−4.61+10.30−1.37=10.86`，与原表10.87相差−0.01。保留差额，要求底层明细/精度；不把10.30未实现变动自动当持续现金回报，也不把原表信用减值项再次无依据扣入该小计。
- 只凭99.83%无法判断事故年准备充分；往年准备金释放、分保变化和险种结构均可能改变表现。

TP24 PDF第15页2024年末：认可资产506.67、认可负债383.67、实际资本123.00、核心一级资本88.71、最低资本51.49；账面权益96.88，上一年83.54；原报告核心/综合充足率172.30%/238.91%。

1. `506.67−383.67=123.00`。实际资本与会计权益差`123.00−96.88=26.12`，不是自动可分红盈余；需要认可估值/资本工具/扣除桥。
2. `88.71/51.49=172.2859%`；`123.00/51.49=238.8813%`。假设各金额按0.01亿元四舍五入，核心比率的可能区间约[172.2594%,172.3123%]，综合约[238.8484%,238.9143%]，均覆盖原表比率。结论是“与已披露精度兼容”，并非已经核实原始监管计算正确；核心资本完整构成仍需原表确认。
3. 权益增加`96.88−83.54=13.34`；仅以净利润7.33及股利0.28解释后，未解释余额为`13.34−7.33+0.28=6.29`。不能随意全归OCI，须取完整权益变动表。
4. 报告载未分配利润转增实收资本5.00、另发行资本补充债30.00。5.00属于权益内部转列，不给总权益增加5.00，也不产生新现金；资本债可能增加监管资本但不是普通权益。原评级文字对转增的资本补充描述不能替代会计分录检验。
5. PDF第14页可快速变现资产142.32、资产428.01，`142.32/428.01=33.2516%`；保险合同负债232.29。33.25%是资产分类占比，不是对未来赔款现金的覆盖率，也不证明这些资产无折价和用途限制。

**判断TP-F1（条件性）：** 投资公允价值及资本工具需要与承保表现分开；公开比率改善不能单独证明准备或ALM更稳健。**反证：** 若事故年亏损改善、再保有效且资产现金流匹配，则经营改善可能成立。**追加TP-P1：** 取得2024偿付报告原表、认可估值/资本明细、权益滚动、赔款三角、巨灾与再保合同及赔付现金曲线；按I3/I6复算净损失，再按I4/I7联动资本和现金。报告中保单/普通负债优于资本债的说明还需最终募集条款核验，不能从偿付率直接给资本债等级。

## 三、华泰证券：母公司资本与合并客户资金分别分析

HT24以2024年末为观察时点。PDF第18–19页母公司监管数据：核心净资本691.02、附属净资本250.40、净资本941.42、净资产1,608.86、风险资本准备259.80亿元；风险覆盖率362.37%，资本杠杆率18.05%。

1. `691.02+250.40=941.42`；`941.42/259.80=362.3634%`。与362.37%相差−0.0066个百分点。按两项金额各±0.005亿元传播，可能区间[362.3545%,362.3723%]，与原表362.37%的舍入范围相容；仍保留原数及精度说明。
2. `941.42/1,608.86=58.5147%`，与原表58.51%相容。资本杠杆率18.05%本例只记录披露值：缺监管调整表内外资产分母，不能用合并总资产“复算”。
3. PDF第17页合并负债6,223.77、自有负债4,339.54，`非自有=6,223.77−4,339.54=1,884.23`。代理买卖证券款1,845.87，差`1,884.23−1,845.87=38.36`是尚未映射的其他非自有负债，不是客户缺口。
4. 合并债务3,403.00，其中短债2,238.26、长债1,164.73；两项合计3,402.99与总额差−0.01，保留舍入差；短债比`2,238.26/3,403=65.7731%`，原表65.77%。卖出回购1,210.48需连抵押物/到期，不是额外再加一遍到总债务。

**判断HT-F1：** 监管资本覆盖、短债依赖与客户资金权属是三个不同问题。现有公开表足以复算部分比率和非自有负债桥，不能证明客户资金逐日足额隔离，也不能把客户款1,845.87抵减公司债务。

**反证：** 若短债由稳定可执行融资和低期限错配资产支持，风险可能较低；若客户资产与负债范围不同，简单差额会误导。**追加HT-P1（awaiting_data）：** 财务提供母公司净资本扣减及监管分母；资金/运营提供客户分类账、第三方存管/结算备付金对账、未达账、回购及CSA逐笔清单；先分权属，再按价格/折扣/续作压力重算追加担保品及现金。年报敏感度不足时不虚构VaR或自营压力亏损。未取得最终债券条款前，不将母公司净资本充裕等同次级债可无条件兑付。
