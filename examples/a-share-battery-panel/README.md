# 真实披露案例：四家A股电池企业

本例使用宁德时代、亿纬锂能、国轩高科和欣旺达2022—2025年官方年报，演示取证、版本判断、固定时间分割、毛利率模型与可编辑交付。**实际留出样本中，简单的上期值基准优于OLS。** 不根据结果替换公司、调参或更换目标。

这是一项事后历史流程演示，研究者此前已读过部分后期披露。它不是前瞻注册实验、完整同业研究或部署预测表现证明。所有精确历史字节可得性仍未证明，官方公告日期与当前文件的对应关系及已见版本风险分别记录。

## 从原报告保留什么

16条年度记录包含48个金额：营业收入、营业成本、期末资产总计。保留原始数字、单位倍数、人民币元基础值、合并范围、会计准则、期间、物理页与印刷页、官方PDF链接、SHA256、公告日期依据及版本限制。全部采用当年报告本期栏；后年重述写入`comparability_notes`，不覆盖历史数据。金额原值与基础值使用十进制字符串。

两类真实问题对分析有直接影响：

- 亿纬2022年报的当前官方PDF显示2024-01-10生成，而原公告日是2023-04-18。没有找到可核实的原始版本，故`available_at=null`，保留当前内容但不纳入历史模型。不得从URL日期推定该字节版本当时已可用。
- 2024年保证类质量保证成本重分类改变营业成本与销售费用的列报。宁德2024年报第162—163页、亿纬第140页、国轩第183页、欣旺达第172页给出相关依据。模型采用原始披露毛利率，其变化不能直接解释为经济利润变化。欣旺达另有2022年末资产的后续递延所得税重述；宁德从万元改为千元时也产生显示舍入。

完整官方来源与逐项页码见[sources.json](sources.json)，例如[宁德2024年报](https://static.cninfo.com.cn/finalpage/2025-03-15/1222806982.PDF)。本仓库不整体转载年报。PDF元数据用于发现矛盾，不能证明没有替换历史文件。

## 固定研究与实际结果

在模型运行前固定公司、年度、方法与截止点。训练截止为2024-10-02零点（+08），评价截止为2026-10-02零点（+08）；仅掌握日级公告日期时，使用公告次日零点作为保守可用边界。

| 分类 | 记录及处理 |
|---|---|
| 训练 | 宁德、国轩、欣旺达2022→2023，共3对 |
| 输入前排除 | 亿纬2022，历史版本时间未核实，共1条 |
| 模型内排除 | 四家公司2023→2024，共4对；训练截止时目标未公布，起点也不属于截止后的留出 |
| 留出 | 四家公司2024→2025，共4对 |
| 待标签 | 四家公司2025起点，共4条，截止时未有2026年度结果 |

因此独立全量记录分类为3训练、5排除、4留出、4待标签；模型接收15条输入，内部排除数为4，两者不是矛盾。

固定模型：下一年毛利率 = 截距 + 斜率 × 当年毛利率。独立复核先以Decimal和闭式公式封存预期，再运行既有NumPy OLS实现。截距约−0.031277977，斜率约1.229815562；不裁剪预测值，也不据留出结果重新拟合。

| 企业 | 预测2025毛利率 | 2025原披露计算毛利率 | OLS绝对误差（百分点） | 上期值误差（百分点） |
|---|---:|---:|---:|---:|
| 宁德时代 | 26.9349% | 26.2728% | 0.6621 | 1.8280 |
| 亿纬锂能 | 18.2872% | 16.1724% | 2.1148 | 1.2408 |
| 国轩高科 | 19.0129% | 16.1749% | 2.8380 | 1.8284 |
| 欣旺达 | 15.5358% | 13.9407% | 1.5950 | 1.2352 |
| 平均绝对误差 | — | — | **1.8025** | **1.5331** |

当前同业表另列毛利/期末资产及四家公司中的百分位。分母明确为期末资产，不能称为平均资产ROA；产品结构、资本投入和合并范围差异仍须解释。

## 复现

安装仓库声明的Python与Node依赖后，在仓库根目录运行：

```bash
python examples/a-share-battery-panel/rebuild.py
python skills/annual-report-analysis/scripts/export.py examples/a-share-battery-panel/workpaper.json --output output/battery-panel
```

`rebuild.py`从唯一来源清单生成15条模型输入、模型结果以及含48事实和36计算的同源底稿。Node不在PATH时向导出命令传入`--node /absolute/path/to/node`。此示例脚本不联网抓取数据，也不自动增加公司或调整历史口径。

修改数值后重跑脚本可同时更新三种成果。Excel的`Q1Records`是模型输入快照，编辑它会重算固定样本的模型；`Facts`是原始会计取证表，两处不会互相回写。改变来源、单位、时间、版本或样本必须修改来源清单并重新运行，不能仅编辑Excel后宣称时点验证仍有效。
