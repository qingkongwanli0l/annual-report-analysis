# 科顺股份及科顺转债：公开资料信用研究案例

资料截止2026-06-30，以2025年报、2024年报、2026年一季报、募集说明书及截止日前补充公告为依据。按披露的CAS分析，合并、母公司、现金等价物和用途限制分别记录。42项来源保留正式链接、页码和可取得的SHA256；不转载年报或评级方法全文。

可编辑源文件为[研究底稿](workpaper.json)和[简报脚本](create-brief.cjs)。[10页研究简报](deliverables/research-brief.pptx)、[Word完整研究](deliverables/report.docx)、[Excel底稿](deliverables/workbook.xlsx)和[完整PPT讨论材料](deliverables/presentation.pptx)使用同一份底稿生成；简报读取共同导出数据。

## 研究结论与成立条件

案例形成主体和普通无担保直接债项均为 **BBB+、负面展望的条件性研究建议**。这是分析者根据联合资信公开方法进行的研究适配，不是联合资信或其他机构发布的评级，不是其内部委员会结果，也不是经统计校准的违约概率。

从实际经营及财务因素进入C/F4指示区间，解释较弱端选择、个体调整、支持约束、债项条款以及展望和变化条件。主路径将同定义年度指标先按30/70加权、再按公开阈值分档，财务研究代表值为3.73625；先权会计金额再算比率也落F4。原方法通常采用三年20/30/50，仅存在近两年报表数据时采用30/70。本企业已公开三年以上报表，缺完整同控重述细项并不当然适用两年例外，故仍为明示研究适配。

固定资产质量2.80、再融资4.65两项定性研究分，量化因素按原公开档内边界形成[3.46125,4.01125)，跨F5/F4。BBB+是中点代表值及已列证据支持的条件建议，不能称为公开参数唯一等级；有依据的择分或补充资料若支持C/F5，应按已列BBB-分支重评。底稿另用已核2023重述余额约束三年权益、杠杆及现金覆盖输入，没有给缺失盈利和利息细项补值，也不把四项输入边界冒称完整三年等级范围。

建议以付款日前可调度资金及用途安排足以覆盖、未证实到期不支付为条件。历史毛现金流的合并范围桥、母公司未来资金、逐笔银行到期、募集资金实际占用及持续承诺的合同后果尚待补证。范围桥未完成时，条件情景的具体金额不能证明实际付款覆盖。发现实际付款困难时，应退出常态矩阵并重新判断，不能依靠模型分数维持原结论。

## 复现

在仓库根按README安装依赖后执行：

```bash
python skills/annual-report-analysis/scripts/export.py examples/keshun-2025/workpaper.json --output output/keshun
node examples/keshun-2025/create-brief.cjs output/keshun/presentation-data.json output/keshun/research-brief.pptx
```

第二条命令要求当前Node环境能解析PptxGenJS；若仅按仓库安装依赖，可将`NODE_PATH`指向`skills/annual-report-analysis/node_modules`。Node不在PATH时，第一条命令可用`--node`指定解释器。

专门结果的完整artifact及输入快照已保存在主底稿的`quantitative`中；导出命令会在`output/keshun/`生成完整JSON。Excel基础计算可重算，但修改Excel不会同步改写报告叙述或外部专门模型。改变研究数据或假设后，应更新底稿、重新执行相关模型并统一导出，不能直接修改简报数字。
