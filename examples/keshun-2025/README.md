# 科顺股份及科顺转债：公开资料信用研究案例

资料截止2026-06-30，以2025年报、2024年报、2026年一季报、募集说明书及截止日前补充公告为依据。按披露的CAS分析，合并、母公司、现金等价物和用途限制分别记录。38项来源保留正式链接、页码和可取得的SHA256；不转载年报或评级方法全文。

先看[10页研究简报](deliverables/research-brief.pptx)，再查[Word完整研究](deliverables/report.docx)、[Excel底稿](deliverables/workbook.xlsx)和[完整PPT讨论材料](deliverables/presentation.pptx)。完整材料包含证据、假设和待核事项，不宜直接作为短会演示。四个文件使用同一份[研究底稿](workpaper.json)；简报由[案例脚本](create-brief.cjs)读取共同导出数据生成。

## 研究结论与成立条件

案例形成主体和普通无担保直接债项均为 **BBB+、负面展望的条件性研究建议**。这是分析者根据联合资信公开方法进行的研究适配，不是联合资信或其他机构发布的评级，不是其内部委员会结果，也不是经统计校准的违约概率。

从实际经营及财务因素进入C/F4指示区间，解释较弱端选择、个体调整、支持约束、债项条款以及展望和变化条件。两年30/70财务合成为明示研究适配：本企业并非仅存续两年，不能冒称符合原方法短存续分支。缺失的完整三年重述细项、定性择档和计算顺序对结论的影响分别保留。

建议以付款日前可调度资金及用途安排足以覆盖、未证实到期不支付为条件。母公司未来资金、逐笔银行到期、募集资金实际占用及持续承诺的合同后果尚待补证。发现实际付款困难时，应退出常态矩阵并重新判断，不能依靠模型分数维持原结论。

## 复现

在仓库根按README安装依赖后执行：

```bash
python skills/annual-report-analysis/scripts/export.py examples/keshun-2025/workpaper.json --output output/keshun
node examples/keshun-2025/create-brief.cjs output/keshun/presentation-data.json output/keshun/research-brief.pptx
```

第二条命令要求当前Node环境能解析PptxGenJS；若仅按仓库安装依赖，可将`NODE_PATH`指向`skills/annual-report-analysis/node_modules`。Node不在PATH时，第一条命令可用`--node`指定解释器。

完整输入快照随结果JSON保存；Excel基础计算可重算，但修改Excel不会同步改写报告叙述或外部专门模型。改变研究数据或假设后，应更新底稿、重新执行相关模型并统一导出，不能直接修改简报数字。
