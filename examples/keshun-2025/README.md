## 研究结论与成立条件

案例的历史因素代表值支持主体和普通无担保直接债项均为 **BBB+、负面展望的条件性研究分支**；定性中心未唯一选定。未来经营、税款和融资条件另行计算，不能将某一预测矩阵值视为实际评级调整。这是分析者根据联合资信公开方法进行的研究适配，不是联合资信或其他机构发布的评级，不是其内部委员会结果，也不是经统计校准的违约概率。

从实际经营及财务因素进入C/F4指示区间，解释较弱端选择、个体调整、支持约束、债项条款以及展望和变化条件。主路径将同定义年度指标先按30/70加权、再按公开阈值分档，财务研究代表值为3.73625；先权会计金额再算比率也落F4。原方法通常采用三年20/30/50，仅存在近两年报表数据时采用30/70。本企业已公开三年以上报表，缺完整同控重述细项并不当然适用两年例外，故仍为明示研究适配。

固定资产质量2.80、再融资4.65两项定性研究分，量化因素按原公开档内边界形成[3.46125,4.01125)，跨F5/F4。BBB+是中点代表值及明示判断下的条件建议，资产质量和再融资择分仍有相邻分支，不能称为公开参数唯一等级；有依据的择分或补充资料若支持C/F5，应按已列BBB-分支重评。底稿另用已核2023重述余额约束三年权益、杠杆及现金覆盖输入，没有给缺失盈利和利息细项补值，也不把四项输入边界冒称完整三年等级范围。

建议以付款日前可调度资金及用途安排足以覆盖、未证实到期不支付为条件。历史毛现金流的合并范围桥、母公司未来资金、逐笔银行到期、募集资金实际占用及持续承诺的合同后果尚待补证。同为2025年末，年报未用银行借款额度10.8亿元与跟踪报告未用授信47亿元的差额仍未解释；两者均未作为已落实现金，再融资4.65只保留为待验证条件分支。范围桥未完成时，条件情景的具体金额不能证明实际付款覆盖。发现实际付款困难时，应退出常态矩阵并重新判断，不能依靠模型分数维持原结论。

原2023对照将现金流补充表所列类别的EBITDA桥与纳入投资性房地产折旧的完整DA桥分列；2024/2025的对应现金流行已包含该项，不再重复加回。两种原范围对照均不进入主盈利评分，也不能补齐最新同控重述三年。

## 经营、现金和融资的条件链

材料涨价从收入、成本和采购条件出发，经现金、融资利息、债务与权益进入评级因素。2026年为实际Q1加后三季预测，观察窗延至2027-06-30。所得税、其他经营收现、材料AP及VAT分别滚动，融资不是在现金缺口后简单加一个没有成本的数字。

年报PDF39—41的防水材料毛利由2024年的12.852445亿元增至2025年的13.356557亿元。收入减少6.826313亿元、直接材料成本减少6.646507亿元，燃料、人工、制造费用和运费合计贡献0.683917亿元，合计毛利增加0.504111亿元。2025材料成本27.959496亿元的同量加价5%为1.3979748亿元；这是历史敏感性，未当作2026预测金额。[2025年报](https://disc.static.szse.cn/disc/disk03/finalpage/2026-04-24/8d1711bc-c88b-410a-8b72-7bae6b960a12.PDF)

模型的共同条件如下，均不代表发行人已承诺的预算：

- 后续收入为季节锚的98%，业务结构、原成本及费用率沿2025；客户回款和普通采购付现同步乘98%。地区收入区间表作为另一项独立敏感性，不混入此链。
- 材料加价自2026Q2持续至2027Q2，不转嫁售价、不增加库存数量；增量采购等于耗用，80%当季付、20%次季付，余额进应付。2026后三季增量成本1.053803亿元，净付款0.993013亿元、年末增量应付0.060790亿元，冲击只计一次。
- 减值强度分别取2026Q1与2025全年，保留两条路径；非现金计提不再额外改回款是短期条件，并不证明坏账没有现金影响。折旧按2025全年数按日预算；Q1折旧及资本化息仍是代理。
- 其他经营收现按2025公开构成拆分。存款利息3,757.62万元和补助/手续费1,225.84万元作构成锚，未来预算现金与收益同季确认；另有两类均不发生、现金与收益同时剔除的分支。未拆其他收现从预测剔除。保证金、受限资金和员工款回收单列混合账面池7.681665亿元，按剩余余额限额扣减，不直接另加现金；它只是可回收上限代理，不能证明变现或发行人可用。年报PDF203、206及[Q1报告PDF6—7](https://static.cninfo.com.cn/finalpage/2026-04-24/1225172706.PDF)。
- 2025合并亏损仍有当期税5,838.66万元，未来以此按日预算，不用集团亏损自动归零；不确认未来递延税收益。Q1所得税应付以2025年末1,421.66万元作代理，已经包含于Q1应交税费，不再加一次负债。毛现金税预算先按当期税/全年现金税比例剔除代理所得税，再换入本模型支付；该比例并非披露的实际税款拆分。主展示本季支付上季应付，另列同季支付与零新增税边界，零新增税仍支付期初应付。年报PDF193、205—206。
- 材料进项VAT13%同季抵现金税与全部递延分别计算；同季抵扣能力未被公开数据证明，未付款材料的开票/抵扣亦递延。VAT与所得税分别桥接，不在毛现金税上重复加支出。
- 旧融资3.5%、新贷款4.5%，债券账面息以3.63%作研究代理；后者来自年报借款费用资本化率，不能当债券精确EIR。未来利息全部费用化。新贷款季初到位、三年期且窗口内不摊还；旧长期新增转流动为零。Q1短借和一年内项目14.436178亿元的季度清偿预算含可能应计息/租赁成分，未称合同本金。
- 15天经营付款底线；U=6.5亿元、P=0且2026年末提前预留至1月9日。实际U/P、合同D/X、版本修正Δ_A/Δ_H/Γ、银行提款及发行人A仍未知；47/10.8亿元未用额度不进现金。全部现金为集团池，不能替代发行人调度证明。

每季新融资为 `F=max(0,(经营底线+用途准备−无本季新增贷款的期末现金)/(1−新贷款本季利息系数))`，由此把新增贷款利息放回资金需要。利润进入权益，债券摊销进入债务；现金、债务和资产负债关系同时核对。

## 复现

在仓库根按README安装依赖后执行：

```bash
python examples/keshun-2025/economic_chain.py examples/keshun-2025/workpaper.json examples/keshun-2025/economic_parameters.json --output output/keshun/economic-results.json
python skills/annual-report-analysis/scripts/export.py examples/keshun-2025/workpaper.json --output output/keshun
node examples/keshun-2025/create-brief.cjs output/keshun/presentation-data.json output/keshun/research-brief.pptx
```

Node命令要求当前环境能解析PptxGenJS；若仅按仓库安装依赖，可将`NODE_PATH`指向`skills/annual-report-analysis/node_modules`。Node不在PATH时，导出命令可用`--node`指定解释器。

经营融资CLI读取共同事实、已有季节现金预算和情景参数，输出逐季及年度结果；`source_input_sha256`标记实际读取的规范化输入快照及参数，结果可与底稿`ks_econ_q_chain.artifact.calculation`比较。CLI不自动改写底稿；改变输入后须同步结果、文字判断和各项导出。

专门结果的完整artifact及输入快照已保存在主底稿的`quantitative`中；导出命令会在`output/keshun/`生成完整JSON。Excel基础计算可重算，但修改Excel不会同步改写报告叙述或外部专门模型。改变研究数据或假设后，应更新底稿、重新执行相关模型并统一导出，不能直接修改简报数字。
